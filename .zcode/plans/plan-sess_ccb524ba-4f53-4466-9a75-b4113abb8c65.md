Intent classification با keyword matching (بدون LLM):
- `halt` → delegate به /halt استودیو
- `capacity` → delegate به flow ظرفیت

- `content` (ست/رنگ/لاک) → پیشنهاد + ثبت درفت
- `random` → هدایت نرم به منو

## 🔒 قواعد ایمنی که رعایت می‌کنم

1. **هر تغییر config-only اول** — قبل از هر کد، budgets.yaml رو با verdict اعمال می‌کنم
2. **fail-soft همه‌جا** — اگه saba_brain crash کنه، saba_studio به fallback قدیمی برمی‌گرده
3. **PII guard همیشه** — هیچ متن خامی به cloud LLM نمی‌ره بدون redact
4. **rollback-able** — هر تغییر با flag یا file delete قابل برگشت
5. **commit بعد از هر فاز** — با پیام فارسی-انگلیسی واضح
6. **branch قبل از کار** — روی branch جدا کار می‌کنم، نه مستقیم master
7. **قبل از delete، read** — برای هر فایلی که حذف می‌کنم، اول محتوا رو نشون می‌دم
