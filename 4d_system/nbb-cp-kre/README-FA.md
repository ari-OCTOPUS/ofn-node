# 🔬 موتورِ واقعیتِ دانش — Knowledge Reality v0.2

یک داشبوردِ **زنده** که vault (مخزنِ Obsidian) را فقط‌خواندنی اسکن می‌کند، گرافِ واقعیِ
`[[wikilink]]ها` را می‌سازد، و آن را به **۱۸ شکلِ گرافیکیِ متفاوت** نمایش می‌دهد — دو‌بعدی،
سه‌بعدی، انیمیشنی، آماری، و ماتریسی.

> **vault هرگز نوشته نمی‌شود.** این یک قول نیست، یک گاردِ کد است (`kernel/guard.py`). هر
> تلاش برای نوشتن زیرِ ریشه‌ی vault استثنا پرتاب می‌کند. همه‌ی خروجی‌ها در `F:\kre-out`
> می‌نشینند — بیرون از vault.

وقتی vault تغییر کند، نوارِ زردِ «📡 vault تغییر کرد» بالای داشبورد پدیدار می‌شود.

## 🎨 ۱۸ نمایش گرافیکی

پنج تب در داشبورد. تبِ پنجم — **«نمایش‌ها»** — گالریِ کامل است:

### 🕸 شبکه‌ای (۶)
1. **گرافِ فشاری ۲بعدی** — spring layout، رنگ = فولدر
2. **گرافِ فشاری ۳بعدی** — بچرخانید تا خوشه‌ها پدیدار شوند
3. **چیدمانِ حلقوی** — نودها روی دایره، یال‌ها به‌صورت قوس
4. **درختِ سلسله‌مراتبی** — ساختارِ فولدر/زیرفولدر
5. **نمودارِ قوسی (Arc)** — یال‌ها به‌شکل نیم‌دایره
6. **دوجهتهٔ فولدر↔نود** — توزیعِ نوت‌ها در فولدرها

### 🧭 تعبیه‌شده / سه‌بعدی (۴)
7. **تعبیهٔ طیفی ۳بعدی** — سه ویژگیِ اولِ لاپلاسین گراف
8. **تعبیهٔ t-SNE دوبعدی** — خوشه‌های معناییِ نهفته
9. **تعبیهٔ Isomap دوبعدی** — MDS روی فاصله‌ی ژئودزیک
10. **کرهٔ ۳بعدی** — نودها روی یک کره (pydeck/plotly)

### 📊 تحلیلی (۵)
11. **توزیعِ درجه (Power-law)** — آیا vault از قانونِ قدرت پیروی می‌کند؟
12. **ماتریسِ مجاورت** — مرتب بر اساس خوشه، بلوک‌بندی را نشان می‌دهد
13. **Treemap خوشه‌ها** — هر فولدر یک مستطیل
14. **حرارتیِ فولدر↔فولدر** — یال‌های بین‌فولدری
15. **رادارِ hubها** — مقایسه‌ی ۵ hub برتر

### ⏳ زمانی / انیمیشنی (۳)
16. **رشدِ انیمیشنی** — گراف فریم‌به‌فریم رشد می‌کند (دکمه‌ی ▶ پخش)
17. **Sunburst فولدرها** — سلسله‌مراتبِ خورشیدی
18. **Sankey جریانِ فولدرها** — حجمِ اتصالِ فولدرها

## 🏛 جایگاه در اختاپوس

این اپ یک **ماژولِ read-only** از NBB Control Plane است. کد در `4d_system/nbb-cp-kre/`
نشسته — کنارِ پکیج‌های `nbb_cp` موجود. ساختارِ لایه‌بندی همان است:

```
kernel/    ← stdlib خالص (guard، types) — هرگز numpy/networkx
adapters/  ← هر چیزی که با دنیا سروکار دارد
  vault/   scanner، linkgraph، watcher (زنده)
  kre/     representations (ریاضیِ مسابقه)
  viz/     ← جدید: data، registry، network، embeddings، stats، temporal
app/       pipeline، live (چوک‌پوینتِ اجرا)
ui/        streamlit_app (داشبورد)
```

جهتِ وابستگی: `kernel ← adapters ← app ← ui` — **همان قاعده‌ی CLAUDE.md**.

### Invariantها (INV-2, INV-4, INV-9, INV-11, INV-12)
- **INV-2** (کارِ برگشت‌ناپذیر ⇒ verdict انسانی): خروجی فقط `LinkProposal` با `status=proposed`.
- **INV-4** (یک choke-point): همه‌ی نوشتن‌ها از `ReadOnlyGuard.open_write` رد می‌شوند.
- **INV-9** (متنِ عبورکننده از مرز = داده): بدنه‌ی هر نوت در `QuarantinedText` بسته می‌شود.
- **INV-12** (fail closed): out_dir داخل vault ⇒ استثنا، نه هشدار.
