# 🩹 ترمیمِ خود (Self-Heal) — راهنمای اجرای ۲۴/۷ با تلگرام

> هدف (تصمیمِ مالک 2026-07-12): لپ‌تاپ همیشه روشن، ارتباط فقط از تلگرامِ ساده،
> سیستم خودش را ارتقا می‌دهد، و اگر چیزی بیفتد **خودش بلند می‌شود**.

## چه چیزی ترمیم می‌شود و چه چیزی هرگز

| وضعیت | رفتار supervisor |
|---|---|
| daemon یا telegram_bot **کرش** کند (exit ≠ 0) | ✅ راه‌اندازیِ دوباره با backoff (۱۰s→۱۵min)، حداکثر ۵ بار در ساعت |
| فرایندِ خودش **هنگ** کند (زنده ولی heartbeat کهنه) | ✅ terminate + راه‌اندازیِ دوباره |
| **HALT حفاظتی** (نقضِ لنگرِ ریاضی 0.135073) | ⛔ هرگز — فقط خبر به تلگرام؛ تصمیم با توست |
| `outputs/daemon.stop` حاضر باشد (توقفِ عمدی) | ⛔ هرگز — نیتِ مالک مقدس است |
| خروجِ **تمیز** (exit 0) | ⛔ restart نمی‌شود — توقفِ تمیز یعنی خواسته |
| فرایندِ بیرونی (که supervisor نساخته) هنگ کند | ⛔ نمی‌کُشد — فقط خبر می‌دهد |
| سقفِ ۵ کرش در ساعت پر شود | 🟡 تسلیم + خبرِ فوری به تو (crash-loop یعنی باگِ واقعی) |

هر اقدام (حتی ردشده) با rollback صریح در
`outputs/control_plane/supervisor_log.jsonl` ثبت می‌شود.
لاگِ خروجی فرزندها: `outputs/control_plane/logs/`.

## راه‌اندازی — سه قدمِ مالک

1. **تلگرام** (اگر هنوز نکرده‌ای): token از BotFather طبق `TELEGRAM_SETUP.md`
   در `.env` — این کار فقط با دستِ توست، ایجنت هرگز token نمی‌سازد.
2. در `.env` این‌ها را روشن کن:
   ```
   CONTROL_PLANE_SELF_HEAL=1
   SELF_CODE_ENABLED=1          # برای خودارتقایی (پیشنهاد؛ apply فقط با تأییدِ تو)
   ```
3. **autostart**: روی `scripts\install_supervisor_task.bat` دوبار کلیک کن
   (یک task در Task Scheduler می‌سازد که با هر logon، supervisor را بالا می‌آورد).
   یا برای اجرای دستی: `scripts\start_supervisor.bat`.

از این به بعد چرخه‌ی کامل بدونِ مراقبت می‌چرخد:
daemon پژوهش/خودارتقایی می‌کند → پیشنهادهای کد در صف می‌مانند → تو از تلگرام
approve/reject می‌کنی (`باهم تصمیم می‌گیریم`) → اگر چیزی افتاد supervisor بلندش
می‌کند → اگر چیزِ جدی شد (HALT/crash-loop) تلگرام خبرت می‌کند.

## توقف

- کلِ پایش: فایلِ خالیِ `outputs/supervisor.stop` بساز (فرزندهای سالم زنده می‌مانند).
- daemon: `outputs/daemon.stop` یا تلگرام یا تبِ Control Plane (v4 — flag لازم).
- حذفِ autostart: `schtasks /Delete /TN "4d_system_supervisor" /F`

## آزمایشِ بدونِ ریسک

```
python -m control_plane.supervisor --dry-run   # فقط تصمیم‌ها، هیچ اجرایی
```

> صداقت: بدونِ sandbox سیستم‌عامل، اجرای کدِ approved مهارِ مطلق ندارد — مرزِ
> نهایی همان تأییدِ آگاهانه‌ی توست. supervisor این مرز را عوض نمی‌کند؛ فقط
> زنده‌ماندن را تضمین می‌کند.
