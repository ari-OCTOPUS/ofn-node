
---

## مراحل استفاده (گام به گام)

### ۱. باز کردن پروژه
- پوشه `lunarcrush-scraper` رو توی VS Code باز کن
- روی `index.html` راست کلیک → **Open with Live Server**
- اگه Live Server نداری: از Extensions در VS Code نصبش کن

### ۲. API Key
- برو به: https://lunarcrush.com/developers/api/authentication
- Login کن → API Key رو کپی کن
- توی فیلد "API Key" پیست کن

### ۳. تنظیم تعداد ارزها
- عدد ۵۰ = ۵۰ ارز برتر (پیشنهاد اول)
- عدد ۱۰۰ = ۱۰۰ ارز (کمی بیشتر طول می‌کشه)
- حداکثر: ۱۰۰۰

### ۴. کلیک روی "شروع دریافت داده"
- صبر کن تا نوار پیشرفت به ۱۰۰٪ برسه
- حدود ۳۰-۶۰ ثانیه طول می‌کشه

### ۵. خروجی گرفتن
سه نوع خروجی داری:
- **JSON**: همه داده‌های خام
- **CSV**: جدول ارزها (برای Excel)
- **تحلیل ماینینگ**: گزارش سیگنال‌های خرید/فروش

---

## داده‌هایی که دریافت می‌شن

| داده | توضیح |
|------|-------|
| coins_list | لیست کامل ارزها با قیمت، حجم، market cap |
| galaxy_score | امتیاز LunarCrush (۰-۱۰۰) |
| alt_rank | رتبه‌بندی بر اساس سوشیال |
| social_volume | حجم پست‌های سوشیال |
| coins_detail | جزئیات کامل top 20 ارز |
| coins_timeseries | تاریخچه ۱ هفته top 20 ارز |
| topics_list | ترندهای سوشیال |
| categories_list | دسته‌بندی‌ها (DeFi، Layer1 و...) |
| creators_list | اینفلوئنسرهای برتر کریپتو |

---

## سیگنال‌های ماینینگ / معامله

| سیگنال | شرط |
|--------|-----|
| 🟢 خرید | Galaxy Score ≥ 60 و AltRank ≤ 50 و تغییر ۲۴h مثبت |
| 🔴 فروش | Galaxy Score ≤ 35 یا تغییر ۲۴h کمتر از -5% |
| 🔵 نگه‌دار | بقیه حالات |
