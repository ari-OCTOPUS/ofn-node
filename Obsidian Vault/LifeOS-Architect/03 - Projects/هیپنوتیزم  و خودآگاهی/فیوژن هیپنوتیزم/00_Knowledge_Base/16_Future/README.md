# 16_Future — افق‌هایِ بلندمدت و کارهایِ عمداً معوق

## آیتمِ ۱ — مسیرِ مهاجرت به Kubernetes (۲۰۲۸–۲۰۳۵)
منبع: `SERVER_ARCHITECTURE.md`. عمداً «باز گذاشته‌شده»، نه برنامه‌ریزی‌شده — Docker Compose به‌عنوانِ سکویِ فعلی انتخاب شد دقیقاً چون مسیرِ مهاجرت به k8s را بدونِ قفل‌شدن باز نگه می‌دارد (portable, low lock-in).

## آیتمِ ۲ — IGK-as-kernel-process (fusion-mvp, دایجست)
معوق، با ارزشِ ۳ از ۹؛ تصمیمِ صریح: «برایِ single-operator بدونِ auto-execution، over-engineering است؛ فقط اگر threat model عوض شد (multi-operator یا auto-execution با پول) بساز.» نمونه‌یِ خوبِ تصمیمِ آگاهانه‌یِ «نه، نه الان».

## آیتمِ ۳ — Self-model سبک با epistemic floor (fusion-mvp, دایجست)
بعد از Grounding، ارزشِ ۵؛ `SystemState` با capability boundaries و برچسبِ «UNCERTAIN:» به‌جایِ نتیجه‌گیریِ کاذب. هشدارِ ثبت‌شده: «confidence بدونِ calibration = theater.»

## آیتمِ ۴ — Silabi-Bot فازِ ۴ (همیشه‌روشن)
فقط بعد از فازِ ۳ (که خودش بعد از فازِ ۲ است). گزینه‌ها: Orange Pi یا سرورِ ابریِ ارزان (~$۵/ماه). عمداً معوق تا ارزشِ ربات با داده‌یِ واقعی تأیید شود.

## آیتمِ ۵ — پیوستِ راستی‌آزماییِ Hamfazi Qodrat
