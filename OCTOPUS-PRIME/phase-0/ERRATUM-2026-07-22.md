# ERRATUM — تصحیح گزارش قبلی Phase 0 (به‌درخواست مالک)

سه ادعای گزارش قبلی بیش‌ازحد قطعی بود. بدون بازنویسی تاریخی، اینجا تصحیح می‌شود:

## E1 — «live tree حتی یک بایت تغییر نکرد» → نادرست/overclaim

ساختِ branch + worktree + دو commit، از `.git` **مشترکِ** `F:\backup` استفاده کرد و در
نتیجه **objects/refs/metadata مخزنِ زنده را تغییر داد**. عبارتِ دقیق:

- runtime state paths checked: no observed change (mtime یکسان)
- live source **working tree**: no intended source edit
- live **Git metadata**: **changed** توسط ساختِ branch/worktree/commit
- proof of zero mutation across ALL live files: **not yet established**
- external operational effect: none observed
- production behavior: unchanged (چون هیچ merge/restart رخ نداد)

**اقدام اصلاحی:** از این پس کارِ پیاده‌سازی در مخزنِ **مستقلِ** `F:\octopus-phase0-isolated`
انجام می‌شود که `.git` جدا دارد (اثبات: `git rev-parse --git-common-dir` داخلِ همان
مخزن است، نه `F:\backup\.git`). worktreeِ مشترک `F:\octopus-blocker-wt` **FROZEN** است.

## E2 — mtimeِ یک پوشه اثباتِ zero-mutation نیست

درست است. تغییرِ محتوا می‌تواند بدونِ تغییرِ mtimeِ پوشه رخ دهد. از این پس اثباتِ
عدمِ نوشتن بر **tripwireِ barrier** (شمارشِ attempted writes زیرِ `F:\backup`) استوار است،
نه mtime. mtime فقط شاهدِ لازم-نه-کافی گزارش می‌شود.
