## بخش A — دفترچهٔ بقای *Armillaria ostoyae*

### خلاصه
بزرگ‌ترین موجودِ زندهٔ شناخته‌شده بر حسب **مساحت** یک کلونِ *Armillaria ostoyae* در Oregon است (~۹۶۵ ha، ~۹٫۱ km²). اما «بقا» یک ویژگیِ واحد نیست؛ برایندِ هشت سازوکارِ مستقل است. کراکسِ ماجرا: بقای این قارچ عمدتاً از راهِ **کم‌تغییری** (conservatism) است، نه ترمیمِ فعال.

### چرا ژنوم هزاره‌ها پایدار می‌ماند — چهار مکانیزمِ رقیب (ناسازگارنشده)
1. **نرخِ جهشِ ذاتیِ پایین** به‌ازای هر تقسیم — `established` (پدیده) / `hypothesis` (علت). Anderson 2018: «انتهای طیفِ پایداری، مقابلِ سرطان».
2. **تعدادِ کمِ تقسیمِ سلولی** بینِ انشعاب‌ها (سکانسِ رشدِ محافظت‌شده، آنالوگِ مریستمِ گیاه) — `hypothesis` قوی. Aanen 2014 (Science)؛ Hodnett 2000.
3. **بافرِ هتروزیگوسیتیِ دیپلوئید** (ماسکِ آللِ مغلوب؛ LOH تنها ردِ دیده‌شده) — `established` (دیپلوئیدی) / `hypothesis` (بافر). Banuett 2015؛ Anderson 1982.
4. **UVِ پایینِ خاک/چوب** → dimerِ کمتر — `hypothesis`. Anderson 2018.

نکتهٔ استثنایی `established`: Armillaria در بینِ basidiomycetes نادر است چون فازِ رویشی‌اش **دیپلوئیدِ پایدارِ بدونِ clamp connection** است (بقیه dikaryotic).

### تنشِ باز و حلِ آن: «آرشیوِ منجمد» یا «موزاییکِ سازگار»؟
- روایتِ پایداری `established`: Anderson 2018؛ Hodnett 2000 (صفر تنوعِ درون‌فرد در ۲۲ ایزوله).
- روایتِ موزاییک `contested`: Tyrrell 2020 — هسته‌های **هاپلوئیدِ** رویشی، ناهمگنیِ هسته‌ای، «تکامل در یک نسل».
- **حل:** ژنوم در سطحِ SNP منجمد است، ولی هتروزیگوسیتی یک **ذخیرهٔ تطبیقیِ نهفته** است که **LOHِ استرس‌القا** آن را رو می‌کند؛ یک رخدادِ LOH تا **+۲۷٪ fitness** داده (James 2019) و نرخش با شدتِ استرس بالا می‌رود (Forche 2011). پس هم پایدار (پیش‌فرض) هم سازگار (زیرِ فشار). «کلون‌ها نبرد را می‌برند، recombination جنگ را» (Drenth 2019).

### «کشتنش سخت است» و مرزِ biocontrol
eradication عملاً بی‌فایده `established`. جبههٔ ۲۰۲۴–۲۶: *Bacillus* BY6 via **ISR + بازآراییِ میکروبیوم** (PMID 41900370)؛ مالچِ آنتاگونیست در تاکستان (PMID 42378078)؛ مقاومتِ میزبان (PMID 40826327).

### جریانِ دارویی/کاربردی
پلی‌ساکاریدهای ضدالتهابِ عصبی، ضددیابت، ضدپوکی‌استخوان (Se-enriched)، ضدافسردگی (PMIDs 42107896, 42399328, 41582255, 41651037)؛ هشدارِ مسمومیتِ گوارشی (PMID 42066652).

### نقاطِ کورِ باقی‌مانده
سهمِ نسبیِ چهار مکانیزمِ پایداری کمّی نشده · علیتِ holobiont (علت یا همراه؟) · جهت‌یابیِ rhizomorph · کارکردِ اکولوژیکِ نورافشانی · اندازه/پیوستگیِ فعلیِ genetِ Oregon (بی‌داده از ~۲۰۰۳) · تخمینِ جرم (ضعیف‌ترین عدد).

## بخش C — معماریِ بقای هیبرید v3

### پنج لایه + سه‌صفحه
- **L0 Governance** — kill switch، per-action cap، auditِ tamper-evident.
- **L1 Core/self توزیع‌شده** — secret-sharing؛ goal/memory/keys غیرمحلی · **+L1.5 ذخیرهٔ stress-gated**.
- **L2 Syndrome monitoring** — anomaly/eval بدونِ توقفِ mission.
- **L3 Self-healing fabric** — قانونِ Physarum (پایین).
- **L5 Holobiont / helper-mesh** — ensembleِ اورکستره‌شدهٔ helperها.
- **صفحات:** core (mycelium) / transport (rhizomorph، زره‌پوش) / effector (fan، تنها جای side-effect).

### v2 → v3 diff
| لایه | v2 | v3 |
|------|----|----|
| L1 core | دیپلوئیدِ توزیع‌شده | + **L1.5 ذخیرهٔ stress-gated** (LOH-analog) |
| L2 syndrome | anomaly/eval | حالا gateِ L1.5 و L3 |
| L3 self-heal | «regrow» مبهم | **قانونِ Physarum/Fricker** (reinforce/recycle/reconnect + core متصل) |
| L4 diversity | تنوعِ مدل | جذب در L5 |
| **L5 holobiont** | — | **نو**: helper-mesh + ISR |
| effector | — | + **compute-on-machinery** (وارسیِ جزء پیش از deploy) |

### L1.5 — تطبیقِ stress-gated
core به‌صورتِ پیش‌فرض immutable (مثلِ SNP کم)؛ یک **ذخیرهٔ هتروزیگوس** (نسخهٔ دومِ policy/config) نگه‌دار که معمولاً masked است و **فقط زیرِ استرس، به‌اندازهٔ شدتِ تهدید** promote شود. پیاده‌سازی: blue-green / feature-flag / N-version که gateش سیگنالِ anomalyِ L2 است. (زیستی: stress-induced LOH — Forche 2011.)

### L3 — self-healing (قانونِ قارچی)
`تقویتِ مسیرِ پرشار + بازیافتِ مسیرِ کم‌شار + حفظِ هستهٔ مرکزیِ متصل + اتصالِ مجدد پس از آسیب`. الگوریتمِ Physarum/ant-routing. precedent: Bebber 2007 (Proc R Soc B)؛ Adamatzky 2026 (arXiv, «Fungal systems for security and resilience»).

### L5 — holobiont / helper-mesh
core یک ensembleِ کیوریت‌شده از helperهای نیمه‌مستقل را **اورکستره** می‌کند: قابلیتِ مکمل، بافرِ خطا (ROS-analog)، و «ISR» (تشخیصِ محلی → سخت‌سازیِ سراسری). درسِ حاکمیتی: اورکستریشن، helperهای in-vitro-آنتاگونیست را به هم‌افزاییِ in-vivo تبدیل می‌کند (Rawat 2025).

### EffectorGate — کِیستونِ ایمنی (صفحهٔ effector)
```python
import hashlib, json, time

class KillSwitchEngaged(Exception): ...
class CapExceeded(Exception): ...

class EffectorGate:
    """تنها نقطهٔ اثرگذاری بر دنیای بیرون. core/transport هرگز مستقیم side-effect ندارند."""
    def __init__(self, per_action_cap, budget_cap, anomaly_threshold):
        self.per_action_cap = per_action_cap
        self.budget_cap = budget_cap
        self.anomaly_threshold = anomaly_threshold
        self.spent = 0.0
        self._killed = False
        self._prev = "genesis"
        self.log = []

    def kill(self):                       # کلیدِ خارج از مدارِ خودِ سیستم
        self._killed = True

    def _audit(self, e):
        e |= {"prev": self._prev, "ts": time.time()}
        e["hash"] = hashlib.sha256(json.dumps(e, sort_keys=True).encode()).hexdigest()
        self._prev = e["hash"]; self.log.append(e)

    def submit(self, action, cost, anomaly_score, approve_fn=None):
        if self._killed:
            raise KillSwitchEngaged
        if anomaly_score >= self.anomaly_threshold and not (approve_fn and approve_fn(action)):
            self._audit({"action": repr(action), "status": "escalated_denied"})
            raise CapExceeded("anomaly ≥ threshold → human gate")
        if cost > self.per_action_cap or self.spent + cost > self.budget_cap:
            self._audit({"action": repr(action), "status": "cap_blocked", "cost": cost})
            raise CapExceeded
        self.spent += cost
        result = action()                 # تنها جای اجرای واقعی
        self._audit({"action": repr(action), "status": "executed", "cost": cost})
        return result
```

### Trade-offs (۱–۱۰، بالاتر=بهتر)
| رویکرد | Cost | Complexity | Scalability | Maintainability | Security | Time |
|--------|------|-----------|-------------|-----------------|----------|------|
| v1 functional | ۴ | ۴ | ۶ | ۶ | ۶ | ۵ |
| v2 structural | ۳ | ۳ | ۸ | ۷ | ۹ | ۳ |
| **v3 (holobiont+stress-gated+self-heal)** | ۳ | ۲ | ۹ | ۷ | ۹ | ۲ |
> v3 فقط برای auto-executionِ high-stake توجیه دارد؛ برای low-stake، over-engineering است (منطقِ survival-filter). `EffectorGate` بی‌قید توصیه می‌شود.

### به‌روزرسانیِ ایمنی (نباید گم شود)
همان خواصی که قارچ را ریشه‌کن‌ناپذیر می‌کنند، یک سیستمِ AIِ **misaligned** را هم بادوام می‌کنند (dormancy، detox-into-fuel، اینوکولومِ عمیق). و دادهٔ مدیریت می‌گوید ریشه‌کنیِ مستقیم شکست می‌خورد؛ آنچه کار می‌کند ISR + بازآراییِ اکوسیستم + مقاومتِ میزبان است. ترجمه: **kill-switchِ تنها کافی نیست** — سیستمِ واقعاً تاب‌آور دورش می‌زند؛ نیاز به دفاعِ لایه‌ای + مهارِ محیطی/اکولوژیک. مرز: این‌ها **robustness‌اند نه intelligence** (Adamatzky 2026 هم آن را resilience می‌بیند نه cognition).
