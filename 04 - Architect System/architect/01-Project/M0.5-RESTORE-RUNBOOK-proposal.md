# M0.5 — runbookِ بکاپِ off-box + restoreِ اثبات‌شده (germline insurance)

**milestone:** M0.5 (دوقلوی M0، هر دو L0) · **گلوگاه:** BACKLOG-10 · **مهلتِ kill-switch:** ۱۲ ژوئیه ۲۰۲۶.
**چرا:** vault (`F:\backup`) تنها rollbackِ قابل‌اتکای germline است (charter + blueprint + `_code` + DBها). یک نسخه روی یک دیسک = یک نقطهٔ مرگ. طبقِ §۱۰ منشور، «معماریِ بقا» تا **یک restoreِ اثبات‌شده** نباشد **تئاتر** است.

**اصلِ کلیدی:** off-box باید **رمزنگاری‌شده** باشد. vault دادهٔ شخصی/PII دارد (`langar.db` = حافظهٔ langar) — کپیِ plaintext در فضای ابریِ دیگری نقضِ همان opsec است که M0 محافظتش می‌کند. پس: `rclone crypt` روی هر remote.

## ۰. پیش‌نیازها

| مورد | چه کسی | توضیح |
|---|---|---|
| نصبِ `rclone` | آری/من | `winget install Rclone.Rclone` یا از rclone.org — باینری، بی‌credential |
| حسابِ فضای ابری (مقصدِ off-box) | **آری (دستی)** | Backblaze B2 / Google Drive / OneDrive / S3 — هرکدام. ساختِ حساب + OAuth = دستِ انسان |
| password برای لایهٔ crypt | **آری (دستی)** | در password manager؛ **در vault یا کد نوشته نشود** — اگر گم شود، بکاپ غیرقابل‌بازیابی است |

> تخمین هزینه `[estimate]`: Backblaze B2 برای ~۱–۲GB vault ≈ زیرِ AU$0.05/ماه. مقدارِ دقیق بعد از اولین sync معلوم می‌شود.

## ۱. ساختِ remoteِ رمزنگاری‌شده (دستِ آری — تعاملی)

```powershell
rclone config
```
دو remote بساز (نام‌ها نمونه‌اند — `<...>` را پر کن):

1. **remoteِ خام** به مقصدِ ابری، مثلاً `n) New remote` → نام `<cloud-raw>` → نوعِ ابری (b2/drive/onedrive) → OAuth/کلید را **آری** وارد می‌کند.
2. **remoteِ crypt** روی‌ آن: نوع `crypt` → `remote = <cloud-raw>:mycoledger-germline` → `filename_encryption = standard` → password و salt را **آری** می‌گذارد (در password manager ذخیره کن). نامش `<germline-enc>`.

> هیچ‌کدام از این مقادیر در vault یا در این runbook نوشته نمی‌شود.

## ۲. اولین sync — **اول dry-run** (من می‌توانم آماده کنم، اجرا با آری)

فایلِ الگویِ exclude (منطبق با `.gitignore` ریشه + موارد سنگین/بازتولیدپذیر):

```
# .rclone-exclude  (regenerable/سنگین را رد کن؛ germline را نگه دار)
_Archive/**
_Duplicates/**
node_modules/**
__pycache__/**
*venv*/**
.git/**
.obsidian/workspace*.json
```

> نکته: `_code` و DBها (`langar.db`) **عمداً include** می‌مانند — این‌ها germline‌اند. رمزنگاریِ crypt امنشان می‌کند.

```powershell
# قدم ۱ — dry-run: فقط گزارش، صفر نوشتن
rclone sync "F:\backup" "<germline-enc>:" `
  --exclude-from "F:\backup\.rclone-exclude" `
  --dry-run --log-level INFO

# قدم ۲ — بعد از بازبینیِ dry-run، اجرای واقعی (دستِ آری):
rclone sync "F:\backup" "<germline-enc>:" `
  --exclude-from "F:\backup\.rclone-exclude" `
  --transfers 8 --log-file "%TEMP%\rclone-germline.log"
```

## ۳. زمان‌بندیِ ساعتی (charter: «rclone off-box ساعتی»)

Windows Task Scheduler (دستِ آری، یک‌بار):
```powershell
schtasks /create /tn "germline-offbox-hourly" /sc hourly /mo 1 `
  /tr "rclone sync \"F:\backup\" \"<germline-enc>:\" --exclude-from \"F:\backup\.rclone-exclude\" --log-file \"%TEMP%\rclone-germline.log\""
```
> `sync` (نه `copy`) آینه می‌کند؛ حذفِ محلی → حذفِ ریموت. اگر می‌خواهی حذف‌ها هم بازیابی‌پذیر بمانند، remoteِ ابری را روی **versioning/soft-delete** بگذار (B2 پیش‌فرض دارد) — این ناوردیِ append-only را در لایهٔ بکاپ هم نگه می‌دارد.

## ۴. ⭐ restoreِ اثبات‌شده — **این خودِ DoD است** (بدونِ این، M0.5 سبز نیست)

```powershell
$T = "$env:TEMP\germline-restore-test"
Remove-Item $T -Recurse -Force -ErrorAction SilentlyContinue
New-Item -ItemType Directory $T | Out-Null

# ۱) بازیابیِ کامل از off-box به پوشهٔ موقت
rclone copy "<germline-enc>:" $T --log-level INFO

# ۲) اثبات‌ها (هر سه باید سبز شوند):
#   الف) شمارِ فایل > صفر و هم‌مرتبه با منبع
(Get-ChildItem $T -Recurse -File | Measure-Object).Count
#   ب) نوتِ کلیدی سالم بازگشته:
Test-Path "$T\04 - Architect System\architect\01-Project\MYCOLEDGER-REBUILD-CHARTER-proposal-v2.md"
#   ج) DB باز می‌شود (integrity):
#      اگر sqlite3 هست:  sqlite3 "$T\...\langar\langar.db" "PRAGMA integrity_check;"  → باید 'ok'
```

**تعریفِ «اثبات‌شده»:** خروجیِ (الف) هم‌مرتبهٔ منبع + (ب) `True` + (ج) `ok`. تاریخ و نتیجه را در HANDOFF و `EXPERIENCE-LEDGER` (append) ثبت کن.
