# doctor_lite — نسخهٔ آزمایشیِ محلیِ دکتر تکاملی

یک اپِ **مستقل** روی لپ‌تاپ که از خودش (لاگِ تجربه) و از وب یاد می‌گیرد — مستقل از Cowork. با Python استاندارد کار می‌کند؛ در حالتِ **mock بدون هیچ کلید/نصب** اجرا می‌شود تا رفتار یادگیری را با چشم ببینی.

## چطور اجرا کنی (همین حالا، بدون هیچ چیز اضافه)

PowerShell را باز کن و بزن:

```powershell
cd "F:\backup\04 - Architect System\learning-engine\app"
python doctor_lite.py --once      # یک چرخه
python doctor_lite.py --once      # دوباره — می‌بینی موضوعِ متفاوتی انتخاب می‌کند
python doctor_lite.py --status    # وضعیت: چه یاد گرفته
```

**چه می‌بینی:** هر چرخه لاگِ خودش را می‌خواند و **کم‌پوشش‌ترین موضوع** را برای تحقیق بعدی انتخاب می‌کند. این «یادگیری از خود» است — بدون هیچ مدل/کلیدی. وقتی هر ۸ موضوع پوشش داده شد، خودش ریتمش را کند می‌کند (خود-جهش تجربه‌محور).

حلقهٔ پیوسته:

```powershell
python doctor_lite.py --loop      # هر ۵ دقیقه یک چرخه؛ Ctrl+C برای توقف
```

## چطور «هوش واقعی» را وصل کنی (۴ provider — DeepSeek + Fugu + Perplexity)

الان mock است. برای زنده‌شدن با کلیدهای واقعی:

1. فایلِ `.env.example` را کپی کن به `.env` (همین پوشه) و کلیدهایت را بگذار:
   ```
   PERPLEXITY_API_KEY=pplx-...
   DEEPSEEK_API_KEY=sk-...
   FUGU_API_KEY=...
   ```
   فقط همان‌هایی که داری — اپ هرکدام که کلید داشته باشد را استفاده می‌کند.
2. با `--live` اجرا کن:
   ```powershell
   python doctor_lite.py --once --live
   ```

**نقشِ هر provider (روترِ هوشمند، verdict آری):**

| کار | provider | چرا |
|---|---|---|
| جستجوی وب زنده (search) | **Perplexity** | منبع‌دار، به‌روز |
| فکر/سنتز (think) | **DeepSeek** | ارزان در حجم بالا |
| تصمیمِ سخت (hard) | **Fugu Ultra** | فقط escalation، گران‌تر |

هر کار اگر provider اصلی‌اش کلید نداشت، خودکار به بعدی fallback می‌کند. با `--status` می‌بینی کدام کلید فعال است.

> **امنیت (سخت):** کلیدها فقط در `.env` هستند که **`.agentignore` بلاکش می‌کند** — هرگز در چت/نوت/git/vault نمی‌روند. اپ آن‌ها را فقط از محیط می‌خواند. هیچ کلیدی در کد نیست.

## بودجه

پیش‌فرض: **نامحدود** (`budget_daily_calls: 0` در state، verdict آری «بدون سقف»). هر وقت خواستی سقف بگذاری، آن عدد را در `doctor_lite_state.json` به یک عددِ >0 تغییر بده (مثلاً ۵۰) → عبور از آن = توقفِ خودکارِ همان روز.

## ایمنی (هستهٔ غیرقابل‌مذاکره)

- **kill-switch:** یک فایلِ خالی به اسم `STOP` در ریشهٔ vault یا همین پوشه بساز → اپ فوراً می‌ایستد.
- **append-only:** هرگز چیزی حذف نمی‌شود؛ فقط به `doctor_lite_runs.jsonl` اضافه می‌شود.
- **سقفِ بودجه:** پیش‌فرض ۲۴ call خارجی در روز (در `doctor_lite_state.json` قابل‌تغییر)؛ عبور = توقف.
- **propose-only:** خروجی فقط در پوشهٔ `proposals/` است؛ هیچ تغییری روی سیستم بدون verdict تو.

## فایل‌هایی که اپ می‌سازد

- `doctor_lite_state.json` — حافظهٔ وضعیت (چرخه، پوشش، ریتم، بودجه).
- `doctor_lite_runs.jsonl` — حافظهٔ append-only (هر چرخه یک خط). این همان چیزی است که اپ از آن یاد می‌گیرد.
- `proposals/*.md` — پیشنهادهای هر چرخه.

## چرا این «اپ» است نه تسک Cowork

| | تسک‌های Cowork | doctor_lite |
|---|---|---|
| اجرا | فقط وقتی اپ Cowork باز است | یک پروسهٔ Python مستقل روی خودِ لپ‌تاپ |

| کنترل | زمان‌بندِ Cowork | خودت `python` می‌زنی؛ کاملاً در دستِ تو |

## قدم بعدی (فاز ۲ — با verdict تو)

- **canary:** قبل از هر خود-جهش، روی ۳–۵ سناریوی ثابت تست شود (طرح در `07 - Knowledge/_doctor-research/canary-adversarial-evaluator.md`).
- **مدلِ محلی:** اتصال به یک مدلِ local (Ollama) برای «فکرکردن» بدون سهمیه و بدون کلید خارجی.
- **حلقهٔ فکری:** به‌جای فقط جستجو، مرحلهٔ think→conclude→next روی خروجی وب (ستون ۳ دکتر).
