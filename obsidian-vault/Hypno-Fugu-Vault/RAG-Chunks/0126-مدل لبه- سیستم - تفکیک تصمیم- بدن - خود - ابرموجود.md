تفکیک تصمیم — از کجا آمده؟

سؤال «من تصمیم گرفتم یا ابرموجود؟» جواب صفر و یکی ندارد. تصمیم هر بار ترکیبی است از سه قطب:

  ۱. بدن: خواب، گرسنگی، خستگی، مصرف، استرس، هوس.
  ۲. خود بازتابی: ارزش‌ها، برنامهٔ ۹۰روزه، تصمیمِ قبل از محرک بیرونی، پذیرش هزینه‌های کسل‌کننده.
  ۳. ابرموجود: بازار، خانواده، پول، ترند، پلتفرم، فشار اجتماعی، مشتری، اقتصاد توجه.

مدل احتمالاتی: تغییرِ میلِ شما (Δn) در جهت کدام نیرو حرکت کرده؟

  Δn = γ_بدن·b + γ_خود·r + γ_ابرموجود·s + نویز

حساسیت به ابرموجود وقتی بالا می‌رود که بدن ضعیف یا آگاهی پایین باشد:
  γ_ابرموجود = σ(بدهی‌خواب + استرس + مصرف + فومو − آگاهی)
پس اگر خواب کم، استرس بالا، مصرف بالا و فومو بالا باشد، احتمال اینکه تصمیم از سمت ابرموجود آمده باشد بالا می‌رود. اگر آگاهی، تأخیر، نوشتن، برنامه و بدن پایدار باشد، γ_ابرموجود پایین می‌آید.

حساسیت به خودِ بازتابی:
  γ_خود = σ(هماهنگی‌باارزش + پیش‌تعهد + پایداری‌بعد‌از‌تأخیر + پذیرش‌هزینه − بدهی‌خواب − هوس)
یعنی تصمیمی بیشتر «خودتان» است که قبل از محرک بیرونی وجود داشته، بعد از ۲۴ ساعت هنوز می‌خواهیدش، با ارزش‌هایتان جور است، و فقط وقتی خسته/گرسنه هستید ظاهر نمی‌شود.

نسخهٔ سریع دستی — هر متغیر را ۰ تا ۱۰ نمره بده:

  شاخص خود (AI) = 0.25·ارزش + 0.20·پیش‌تعهد + 0.20·پذیرش‌هزینه + 0.20·پایداری۲۴ساعت + 0.15·ثبات‌بدن
  شاخص ابرموجود (SI) = 0.30·محرک‌بیرونی + 0.20·فومو + 0.20·فشار‌پول + 0.20·فوریت + 0.10·(۱−پایداری)
  شاخص بدن (BI) = 0.30·(۱−ثبات‌بدن) + 0.30·هوس + 0.20·بدهی‌خواب + 0.20·استرس

بعد سهم هر یک را نرمال کن (مجموع = ۱):
  سهم‌خود = AI ÷ (AI + SI + BI)
  سهم‌ابرموجود = SI ÷ (AI + SI + BI)
  سهم‌بدن = BI ÷ (AI + SI + BI)

تفسیر:
  اگر سهم‌خود بالاتر از ۰.۵۵ باشد → بیشتر تصمیم خودتان است.
  اگر سهم‌ابرموجود بالاتر از ۰.۵۵ باشد → بیشتر از موجِ بیرون آمده.
  اگر سهم‌بدن بالاتر از ۰.۵۵ باشد → بیشتر از خستگی/هوس/گرسنگی است.
  اگر هیچ‌کدام غالب نبود → تصمیم ترکیبی است.

نکتهٔ مهم: بهترین تصمیم‌های درآمدی معمولاً ترکیبی‌اند — سهم‌خود حدود ۰.۴، سهم‌ابرموجود حدود ۰.۴، سهم‌بدن حدود ۰.۲. یعنی یک سیگنال واقعی بازار را می‌گیرید، اما آگاهانه آن را به مسیر خودتان تبدیل می‌کنید.
