## Core philosophy
> **A mortal, paradigm-agnostic, human-anchored cognitive organism** built for one
> real operator (ADHD/BPD, single-owner, offline-prone, revenue-driven). Every
> capability is metered by an accounted **cost**; every irreversible **effect** is
> gated behind a human **anchor**; every **claim** carries an epistemic tag and a
> falsifier; the model is a hot-swappable engine; nothing is ever deleted.
> `[A/B, 90%]` (DOC-06 philosophy ⊕ DOC-02 GOALS ⊕ DOC-05 epistemics.)

## Core principles (the 6 pillars)
1. **Human-anchored** — human-append is root-of-trust AND arrow of time (PRIM-04, INV-01/02). The moat is the anchor, not the model.
2. **Cost-gated** — no capability without accounted cost; cost is the primary alignment lever (PRIM-05, INV-07).
3. **Non-destructive** — additive-only; deprecate+version, never delete; sacred source immutable (PRIM-15, INV-05/12).
4. **Evidence-aware** — tag + source every claim; Evidence≠Derivation; eliminability + added-value + mandatory gap-report (PRIM-07/10, INV-08/09/13/16).
5. **Event-driven** — all communication via immutable events on an append-only bus/ledger; self-healing, offline-safe, fully auditable (PRIM-01, INV-05/10).
6. **Operator-shaped** — designed around the real human's state (ADHD/BPD/energy), not an idealized user; State/Mode modulates guards (PRIM-13, INV-15, GOAL-9).

## Doctrines (what the system BELIEVES)
| Domain | Belief |
|---|---|
| **Intelligence** | A metered, mortal organism — not a model. The model is swappable; the substrate (time/trust/cost) is the identity. `[I,85%]` |
| **Memory** | Layered truth: authoritative-but-decaying vault + evictable cache reconstructable from an append-only log + mismatch-driven reconsolidation. Forgetting is mandatory. `[A,88%]` |
| **Time** | Manufactured & logical: beats/HLC, not wall-clock; human-append advances aging. Determinism enables replay/audit. `[A,88%]` |
| **Safety** | Emergent from cost + anchor, not rules alone. Five independent layers; effects gate, cognition may flow. `[A,90%]` |
| **Agency** | Bounded and reversible; autonomy rises only on low-risk domains and never past a human-anchored ceiling. `[A,90%]` |
| **Human judgment** | Irreplaceable root-of-trust; the defense against agreement-spiral and injection. Low throughput is accepted as the price. `[A,92%]` |
| **Money** | The fitness function (money + speed). No money_link ⇒ incubating. Economics is attached to every project object. `[A,88%]` |
| **Research** | A registered, prioritized bet with a falsifier and a rabbit-hole guard — not open-ended exploration. `[A,90%]` |
| **Self-improvement** | Propose→test→approve→merge, gap-reported; change = re-sculpting attractors (mismatch), not force; bounded by human-presence rate. `[A,88%]` |
| **Failure** | Expected and survivable: known-good restore + time-travel replay; a dead part regrows a new part (self-healing). `[A,88%]` |
| **Self / identity** | The operator's state is modeled as a hormonal layer that modulates the whole system; "the eye can't see itself" ⇒ some layers need an external human. `[A,82%]` |

## The one-sentence DNA
> **Meter capability with cost, gate effects with a human, tag every claim with its
> evidence, keep an append-only memory that can forget its cache but never its source,
> and evolve only by proposal + human-anchored merge — so an autonomous cognitive
> organism can run continuously without ever drifting from its operator's ground truth.**
