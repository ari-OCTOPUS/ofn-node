# buy.nsw Harvester (OFN H1) — نسخهٔ 0.2 (ادغام پکیج بازیابی‌شده + پل فایلی)

**مسئله:** `tenders.nsw.gov.au` (API قدیمی OCDS) مرده است و `buy.nsw.gov.au` نه API عمومی دارد نه به هیچ کلاینت غیر-مرورگری جواب می‌دهد (WAF از ایران، از curl و از fetch ایجنت — همه ۴۰۳).

**راه‌حل:** همان مرورگری که انسان در سیدنی دارد، صفحه را برای WAF «یک انسان» جلوه می‌دهد. این اکستنشن فقط همان صفحه‌ای را می‌خواند که انسان باز کرده است. صفحات buy.nsw سرور-رندرند؛ متن تمیزتر از عکس/OCR است و عکس لازم نیست.

## تبار این نسخه (صداقت کامل)

نسخهٔ 0.2 = ادغام دو پیاده‌سازی موازی:

- **پکیج «buysw-harvester-for-ari»** (بازیابی‌شده از Temp با نام‌های جابه‌جا؛ اصلی‌اش در پوشهٔ zip):
  mapping.js / content.js / background.js / manifest.json — برداشت صفحات جزئیات
  (CAN/جوایز: تأمین‌کننده، ایمیل/تلفن، ABN)، الگوهای لینک بیشتر
  (`/prcOpportunity/`، `RFTUUID=`، `CNUUID=`، `SONUUID=`)، زیردامنهٔ
  `suppliers.buy.nsw.gov.au`، ادغام رکورد نتیجه+جزئیات، صفحه‌بندی شماره‌ای،
  خروجی CSV. **popup نداشت** — بازنویسی شد.
- **پل فایلی این repo** (PR #84): گیت ingest پایتونی با همان دروازه‌های
  `h1_buysw`، بچ نسخه‌بندی‌شده، idempotent.

تصمیم‌های ادغام (بازبینی ایجنت):
1. `manifest`: permissionهای بلااستفادهٔ `scripting` و `activeTab` حذف شدند.
2. `background.js`: فقط هندلر `SAVE_DEBUG` اضافه شد (ذخیرهٔ دامپ دیباگ).
3. **پیش‌فرض بدون شبکه**: `autoPost`/`POST_ALL` (ارسال مستقیم به endpoint نود)
   در تنظیمات پیشرفته است و خاموش می‌ماند؛ مسیر اصلی همان فایل JSON +
   `tools/ingest_buynsw_batch.py` است.
4. سمت پایتون هر دو شکل پذیرفته می‌شود: بچ نسخه‌دار v1 و خروجی
   `{"source": "buysw_web", "count": N, "records": [...]}` اکستنشن.
   `access_mode=owner_upload` (سازگار با whitelist استور و صادقانه برای حمل انسانی).

## نصب (روی کامپیوتر سیدنی — فقط بار اول)

1. Chrome → `chrome://extensions`
2. **Developer mode** روشن
3. **Load unpacked** → پوشهٔ `tools/buynsw-harvester`
4. آیکون را پین کن

## گردش کار (۲ دقیقه)

1. صفحهٔ نتایج/جزئیات buy.nsw را باز کن (tender یا CAN/جوایز).
2. آیکون اکستنشن → **«برداشت از این صفحه»** — روی صفحهٔ جزئیات، رکورد
   غنی‌تر (تأمین‌کننده/تماس/ABN) با رکورد قبلی همان UUID ادغام می‌شود.
3. چند صفحه نتیجه؟ تعداد صفحه را تنظیم کن → **«شروع خودکار»** (مکث انسانی
   ۱.۵–۴ ثانیه بین صفحات، سقف ۴۰).
4. **«خروجی JSON»** → فایل `buysw-leads-<تاریخ>.json`.
5. فایل را به board138 ببر و اجرا کن:

```bash
cd /home/ari/wt-buynsw-ingest
python3 tools/ingest_buynsw_batch.py /home/ari/buysw-leads-2026-09-02-09-30-00.json
```

خروجی = حساب‌وکتاب صادق: `accepted` / `rejected_filter` / `rejected_dup` /
`rejected_invalid` / `leads_minted` (از رکوردهای award) / `pii_findings`
(ممیزی نشت PII در متن آزاد). کد خروج: `0` موفق، `2` بچ رد شد (هیچ نوشتنی
نکرده)، `1` خطای عملیاتی. اجرای دوباره بی‌ضرر است.

## مسیر بدون کلیک — sidecar (اختیاری، خاموش پیش‌فرض)

به‌جای scp+CLI، اکستنشن می‌تواند مستقیم به نود POST کند. روی board138
(⚠️ پورت‌های 8791–8796 را سرویس‌های خود نود اشغال کرده‌اند — پورت 8799+ بگذارید):

```bash
cd /home/ari/wt-buynsw-ingest
INGEST_TOKEN=یک-راز-مخفی OFN_PAINTING_DB=/home/ari/.local/share/ofn/painting.sqlite \
  python3 tools/buynsw-harvester/ingest_server.py --host 127.0.0.1 --port 8799
```

بعد در popup اکستنشن → «تنظیمات نود OFN»: endpoint =
`http://127.0.0.1:8799/api/leads/ingest` (یا آدرس تانل) + همان توکن.
بدون `INGEST_TOKEN` اصلاً بالا نمی‌آید (fail-closed). همان گیت واحد
`ingest_batch` را صدا می‌زند؛ مرحلهٔ تولیدی = انتقال به مسیر webhookِ
 Governed هنگام review. تست‌شده روی خود board138 (POST → accepted:1).

## نجات عنوان/مهلت (v0.3)

اگر متن لینک فقط «See details» بود یا فیلد مهلت خالی آمد، عنوان واقعی و
`Closes:` از متن کارت بازیابی می‌شوند (idempotent). تولیدکنندهٔ JS هم
`window.__BUYSW__` را export می‌کند تا صفحهٔ self-test بومی (بدون نصب
اکستنشن، از هر جایی حتی ایران) بتواند استخراج‌کننده را صدا بزند.

## حلقهٔ قفل‌کردن سلکتورها

اگر «برداشت» رکوردی پیدا نکرد یا فیلدها خالی بود: **«دامپ دیباگ DOM»** →
فایل `buysw-debug-*.json` (شامل `linkCount`، `sampleCards` به‌صورت HTML
خام، `nextPage`) → برای ایجنت بفرست تا سلکتورها با DOM واقعی قفل شود.
اعتبارسنجی اولیه روی صفحهٔ واقعی ذخیره‌شدهٔ Supplier Hub انجام شده است
(لینک‌های ناوبری به‌درستی نمی‌گیرند؛ خروجی صفرِ تمیز).
