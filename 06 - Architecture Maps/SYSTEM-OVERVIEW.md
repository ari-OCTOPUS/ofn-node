# System Overview — vault-عامل + سازوارهٔ خودگاورنور (Organism)

> برای مهندس معمارِ سیستم‌های پیچیده که می‌خواهد سریع بفهمد این چیست، چرا این‌طور ساخته شده، و کجا واقعاً جالب است.
> این سند خلاصهٔ معماری است، نه اسپک اجرا — برای جزئیات خط‌به‌خط لایهٔ ارگانیسم: [[_ops/ORGANISM-SPEC|ORGANISM-SPEC]].

## ۱) یک‌خط

یک vault ابسیدینِ **agent-first** (Claude Code به‌عنوان لایهٔ استدلال/اجرا؛ markdown + wikilink به‌عنوان بستر دانشِ پایدار و human-readable) که کنترل‌پلینِ چند بیزنس موازی است، به‌علاوهٔ یک زیرسیستمِ **خودگاورنور** («ارگانیسم») که تخصیص منابع/مناظرهٔ ایده/تکثیر را خودش مدیریت می‌کند — تماماً پشتِ گیت‌های ایمنیِ سخت که در کد قفل‌اند، نه فقط در سند.

## ۲) فلسفهٔ طراحی

- **هوشِ گران فقط در نقاطِ تصمیمِ نادر؛ هرچه روزمره است ارزان و رویدادمحور.** اکثر عملیات fail-soft و deterministic‌اند؛ فراخوانی LLM فقط در گلوگاه‌های تصمیم واقعی.
- **سیستم هرگز نباید بتواند معیارِ قضاوتِ خودش را دور بزند** — درسِ کلاسیکِ reward-hacking در سیستم‌های خودبهبود (DGM). evaluator/ژنوم فریز است؛ «پذیرفته‌شدن» فقط از عملِ واقعیِ انسان می‌آید، هرگز از گزارشِ خودِ ایجنت.
- **Local-first، بدون vendor lock-in:** markdown + JSONL + SQLite + git. بدون دیتابیسِ اختصاصی، بدون قفلِ پلتفرم.
- **ایمنی از طریقِ ساختار، نه انضباط.** مثال: تاریخِ فعال‌سازیِ مسیرِ زنده (۲۰۲۶-۰۷-۲۱) در خودِ کد چک می‌شود (`opslib.live_gate_open`)، نه فقط در یک سند که می‌شود فراموشش کرد.

## ۴) سازوارهٔ ارگانیسم — بخش فنیِ جالب

سه لایه، یک حلقهٔ همیشه‌روشن (`organism.py`)، صفر call پولی مگر گیتِ دوقفلهٔ زنده باز شود:

| زیرسیستم | مسئولیت | ماژول‌های کلیدی |
|---|---|---|
| **Metabolism** | تلمتریِ واحد از دو منبعِ حقیقت → گیتِ per-organ → تخصیصِ سایه (epoch آلوستاتیک) → fitness/تکثیرِ پیشنهادی | `opslib`, `telemetry`, `organ_gate`, `governor_epoch`, `fitness`, `replication` |
| **Debate** | دو ایجنتِ جعبه‌سیاه (معمار × خلاق) که روی موضوعِ whitelist-شده مناظره می‌کنند؛ بازمانده = بلیتِ صفِ انسانی، نه امتیاز | `debate/client.py`, `topics.py`, `debate_loop.py` |
| **Organism loop** | تیکِ ۵دقیقه‌ای: kill-check → تلمتری → epoch در سررسید → روزی‌یک‌بار fitness/σ → heartbeat ساعتی → state برای UI | `organism.py` + HTTP وضعیتِ فقط‌خواندنی |

نکتهٔ معماری: **`organ_gate` هرگز جایگزینِ enforcer اصلی (`budget_gate`) نمی‌شود — فقط دورش می‌پیچد.** الگوی تک-enforcer به‌جای چند لایهٔ موازیِ enforcement، دقیقاً برای جلوگیری از حالتی است که دو لایه دربارهٔ «مجاز است یا نه» با هم ناسازگار شوند.

## ۵) ناوردی‌های ایمنی (نمونهٔ منتخب از ۱۰ تا)

- **تک-enforcer:** فقط یک نقطه اجازهٔ خرج می‌دهد؛ بقیهٔ لایه‌ها فقط measure/propose.
- **Fail-closed:** ناسازگاریِ تلمتری↔حسابداری = فریزِ همهٔ grantها، نه ادامهٔ خوش‌بینانه.
- **Append-only + hash-chain:** لجرِ رویدادها هرگز rewrite نمی‌شود؛ هر تغییرِ پنهان زنجیره را می‌شکند و `verify()` آن را می‌گیرد.
- **گیتِ زمانیِ سخت‌کدشده:** هیچ مسیرِ خرج‌دار پیش از تاریخِ تعیین‌شده باز نمی‌شود — چک در کد است، نه فقط توافق.
- **ضدِ reward-hacking:** پذیرش = فقط از رکوردِ عملِ انسانی (کلیک واقعی) + تطبیق با حسابِ مستقل؛ ادعای خودِ ایجنت هرگز شمرده نمی‌شود.
- **ضدِ سرطان (تکثیر):** σ_effective ≤ ۱، سقفِ تعدادِ سلول، عمقِ spawn = ۱، spawn همیشه فقط پیشنهاد — never اجرای واقعی.
- **مرزِ ضدتزریق:** داده‌ی ورودی به مناظره در نشانه‌گذاریِ fence می‌پیچد و جمله‌ی گاردِ ثابت در system prompt هر دو نقش هست؛ داده هرگز دستور نیست.

## ۶) تصمیم‌های مهندسیِ قابل‌بحث (برای گفتگو با مهندس)

- **Epoch آلوستاتیک، نه clock ثابت:** طولِ epoch تابعِ فشار است (`max(spend_velocity, deadline_proximity, anomaly)`) — سیستم زیرِ فشار تندتر می‌تپد، در آرامش کندتر. تشبیهِ زیستی عمدی است (whole metaphor: سازواره = organism، سلول = cell، برازندگی = fitness).
- **قفلِ دولایه برای concurrency واقعی:** یک باگِ واقعی همین هفته پیدا شد — قفلِ صرفاً فایلی زیرِ چند تردِ هم‌پروسه گاهی timeout می‌کرد و زنجیرهٔ hash فورک می‌شد. فیکس: `threading.Lock` سراسری per-path (قطعی، هرگز timeout) + همان قفلِ فایلی برای بین-پروسه (دفاعِ دوم). یک نمونهٔ خوب از «تستِ happy-path سبز بود، race واقعی زیرِ بار پنهان مانده بود.»
- **گاردِ نشتِ کلید باید دوطرفه باشد:** گاردِ اول فقط جهتِ «کلیدِ اشتباه → هاستِ درست» را می‌بست؛ جهتِ معکوس (کلیدِ واقعی → هاستِ اشتباه بر اثرِ typo در env) باز مانده بود. چکِ روی hostname واقعی، نه substring، هر دو جهت را می‌بندد.
- **بازبینیِ چندایجنتیِ موازی به‌جای یک پاسِ سکانسیال:** وقتی خواسته شد «کامل بازبینی کن»، سه ایجنتِ متخصص و فقط‌خواندنی موازی (درستیِ کد / سلامتِ ارتباطات / آمادگیِ دیپلوی) بیشتر از یک پاسِ سکانسیال باگِ واقعی پیدا کردند.

## ۷) وضعیتِ فعلی (۲۰۲۶-۰۷-۰۷)

- لایهٔ ارگانیسم: کاملاً ساخته‌شده، **شادو-مود، $۰**؛ سوئیتِ تست ۳۳ چک سبز.
- زیرسیستمِ دانشِ قدیمی‌تر (`genome-system`، ledger + سه ایجنتِ Guardian/Creativity/Doctor): نسخهٔ v0.4.3، ۵ سوئیتِ تست سبز.
- پنلِ محلیِ مالک (پروفایل/وضعیتِ پروژه‌ها/وضعیتِ ارگانیسم): زنده و تست‌شده.
- هیچ مسیرِ زنده/پولی فعال نیست؛ فعال‌سازی پشتِ verdict صریحِ مالک و تاریخِ قفل‌شده در کد است.
- تاریخچهٔ git به‌تازگی ترمیم شد (یک خط کانفیگِ خرابِ باقی‌مانده از یک sandbox قدیمی) — الان تاریخچهٔ کامل و verify‌شده دارد.
