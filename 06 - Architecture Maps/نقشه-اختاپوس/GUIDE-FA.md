# راهنمای فارسی — اسکنرِ گاوصندوقِ (Vault) تو

> این راهنما برای `vault_scanner.py` است که روی دسکتاپِ تو ساخته شده.
> همه‌چیز را به ساده‌ترین شکل توضیح می‌دهد.

---

## ۱. این اسکریپت چه کار می‌کند؟

این برنامه مثل یک ناظر فقط-می‌بیند رفتار می‌کند:

۱. **تمامِ `F:\backup` را اسکن می‌کند** — هر پوشه، هر فایل، هر زیرپوشه.
۲. **به هر بخش یک برچسب می‌زند** — مثلاً «پروژه»، «کد»، «حافظه»، «پر از شلوغی».
۳. **ریسک را تشخیص می‌دهد** — پول، رمزارز، اسرار، OnlyFans و غیره را با رنگ قرمز علامت می‌زند.
۴. **یک گزارش می‌سازد** — روی دسکتاپ دو فایل تولید می‌کند:
   - `vault-inventory.json` — دادهٔ کامل و ساختاریافته
   - `vault-report.md` — گزارشی که آدم می‌خواند
۵. **یک خلاصه به تلگرامت می‌فرستد** — با مدل سبز/زرد/قرمز.

---

## ۲. چطور اجرایش کنی؟ (قدم‌به‌قدم)

### قدم ۱ — ترمینال را باز کن

کلیدهای `Win + R` را بزن، تایپ کن `cmd` یا `powershell`، اینتر بزن.

### قدم ۲ — برو به دسکتاپ

```bash
cd C:\Users\Armin\Desktop
```

### قدم ۳ — اولین بار: فقط پیش‌نمایش (هیچ‌چیز ننویس، هیچ‌چیز نفرست)

```bash
python -X utf8 vault_scanner.py --dry-run
```

این حالت **هیچ فایلی نمی‌سازد و هیچ پیامی نمی‌فرستد**. فقط روی صفحه نشان
می‌دهد چه چیزی پیدا کرده. اولین بار همیشه این‌طور اجرا کن تا مطمئن شوی.

### قدم ۴ — وقتی راضی بودی: اسکن کامل

```bash
python -X utf8 vault_scanner.py
```

این کار:
- `vault-inventory.json` و `vault-report.md` را روی دسکتاپ می‌نویسد.
- خلاصه را به تلگرامت می‌فرستد.

### قدم ۵ — اگر تلگرام را نمی‌خواهی

```bash
python -X utf8 vault_scanner.py --no-telegram
```

فقط فایل‌های گزارش را می‌سازد، پیام تلگرام نمی‌فرستد.

### (اختیاری) اسکنِ فقط یک بخش

```bash
python -X utf8 vault_scanner.py --scope "03 - Projects"
```

فقط `03 - Projects` را اسکن می‌کند، نه کلِ گاوصندوق را.

---

## ۳. تلگرام چطور کار می‌کند؟

این اسکریپت **باتِ تلگرامِ موجودِ تو** را استفاده می‌کند. تو از قبل یک
بات ساخته بودی و توکنش را در `F:\backup\.env` گذاشته بودی:

```
TELEGRAM_BOT_TOKEN=...
TELEGRAM_OWNER_CHAT_ID=...
```

اسکریپت این دو مقدار را از همان فایل می‌خواند، پیام را به
`https://api.telegram.org/bot.../sendMessage` می‌فرستد، و تمام.

**نیازی به ساخت بات جدید نیست.** نیازی به نصب کتابخانهٔ جدید نیست — فقط
از `requests` استفاده می‌کند که از قبل نصب شده.

**اگر پیام تلگرام نفرستید:**
- چک کن `F:\backup\.env` واقعاً آن دو خط را دارد.
- چک کن به اینترنت وصلی.
- برنامه را با `--no-telegram` اجرا کن تا حداقل گزارش‌ها ساخته شوند، بعد
  خطای تلگرام را بررسی کن.

---

## ۴. 🔒 امنیت: چرا فایل‌هایت جابه‌جا نمی‌شوند؟

این مهم‌ترین بخش است. سه لایهٔ محافظت وجود دارد:

### لایهٔ ۱ — کد فقط خواندنی است

اسکریپت از **فقط** این توابع استفاده می‌کند:

| تابع | کارش |
|------|------|
| `os.listdir()` | لیست کردنِ محتوای پوشه |
| `os.scandir()` | اسکن کردنِ سریع |
| `os.path.getsize()` | گرفتنِ اندازهٔ فایل |
| `os.path.getmtime()` | گرفتنِ زمانِ تغییر |
| `os.path.isdir()` / `isfile()` | چک کردنِ نوع |
| `open(..., 'r')` | خواندنِ محتوا (فقط خواندن) |

### لایهٔ ۲ — این توابع ممنوعه اصلاً در کد نیستند

| تابعِ ممنوعه | اگر بود چه می‌کرد |
|--------------|-------------------|
| `os.remove()` | فایل را پاک می‌کرد |
| `os.rename()` | نام فایل را عوض می‌کرد |
| `os.rmdir()` | پوشه را پاک می‌کرد |
| `shutil.move()` | فایل را جابه‌جا می‌کرد |
| `shutil.copy()` | فایل را کپی می‌کرد |
| `shutil.rmtree()` | کلِ یک درخت را پاک می‌کرد |
| `open(..., 'w')` یا `'a'` | روی فایلِ گاوصندوق می‌نوشت |

**کتابخانهٔ `shutil` اصلاً import نشده است.**

### لایهٔ ۳ — خودت می‌توانی راستی‌آزمایی کنی

این دستور را در ترمینال بزن:

```bash
grep -nE "shutil|os\.remove|os\.rename|os\.rmdir" vault_scanner.py
```

نتیجه باید خالی باشد یا فقط به خطِ کامنت اشاره کند. اگر چیزی پیدا کردی که
به فایلِ گاوصندوق اشاره دارد، قبل از اجرا گزارش بده.

**تنها جایی که `'w'` (نوشتن) استفاده می‌شود** برای دو فایلِ خروجی روی
دسکتاپ است (`vault-inventory.json` و `vault-report.md`) — هرگز روی مسیرِ
داخلِ `F:\backup`.

### بلوکهٔ dry-run

حتی اگر چیزی هم اشتباه شده باشد، `--dry-run` **هیچ‌چیز نمی‌نویسد و هیچ‌چیز
نمی‌فرستد**. اولین اجرا همیشه با این پرچم باشد.

## ۵. گزارش را چطور بخوانم؟

وقتی `vault-report.md` ساخته شد، آن را در ویرایشگرِ مارک‌داون (یا حتی
Notepad) باز کن. سه بخشِ اصلی دارد:

### 🔴 قرمز — ریسکِ بالا
مثلاً `.env`، پوشهٔ `Accounting`، `Crypto - etoro`، `Mining`، `اونلی فنز`.
**این‌ها را هرگز خودکار دست نزن.** قبل از هر تغییری، با خودت/با یک ایجنت
مشورت کن.

### 🟡 زرد — نیاز به توجه
مثلاً:
- **پوشهٔ شلوغ:** `00 - Inbox` با ۷۶ فایلِ پراکنده — شاید وقتِ دسته‌بندی‌اش است.
- **پوشهٔ خالی:** `09 - People` و `02 - Life OS` — یا پرشان کن یا پاکشان کن.
- **فایل‌های پراکنده در ریشه:** ۱۲ فایلِ `.md` و `.docx` که در ریشه‌ی
  `F:\backup` خوابیده‌اند و باید به جای درست‌شان بروند.
- **تکرارِ احتمالی:** `_code/` آینه‌ای از `03 - Projects/` است — شاید
  نسخهٔ کهنه است.

### 🟢 سبز — سالم
پروژه‌هایی که مرتب‌اند یا اخیراً فعال بوده‌اند.

---

## ۶. موجِ بعدی چیست؟

این اسکنر **فقط می‌بیند**. موج‌های بعدی به ترتیب:

1. **مشاهده** ✅ (الان این را ساختی)
2. **پیشنهاد دادن** — اسکریپتی که بگوید «این فایل‌ها احتمالاً باید بروند
   آنجا» ولی خودش جابه‌جا نکند.
3. **اجرای کم‌ریسک** — مثلاً rename استاندارد یا ساختِ پوشهٔ پیشنهادی.
4. **تأیید برای ریسک بالا** — حذف یا جابه‌جاییِ مهم، فقط با گفتِ تو.

هر موج را جدا بساز. هر موج را جدا تست کن. صبر کن.

---

## ۷. خلاصهٔ یک‌خطی

> این اسکریپت فقط **می‌بیند و گزارش می‌دهد**. هیچ فایلی را در
> `F:\backup` جابه‌جا، پاک، یا تغییر نام نمی‌دهد. اول با `--dry-run` اجرا
> کن، بعد با خیال راحت `python vault_scanner.py` بزن.
