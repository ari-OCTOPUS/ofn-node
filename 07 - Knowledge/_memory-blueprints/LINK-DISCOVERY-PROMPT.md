# LINK-DISCOVERY-PROMPT — چرخهٔ کشف → پیشنهاد → verdict → اعمال

این پرامپت را هر بار که می‌خواهی «ارتباطات جدید» پیدا/اعمال شوند به ایجنت بده. یافته‌های [[REVIEW]] (متر orphan خوشه‌ای، توهم رابطه، RTL) داخلش لحاظ شده.

## فاز ۱ — اسکن (read-only)

1. همهٔ `.md` خارج از محدودهٔ منفی (`.agentignore` + `_memory` + `_Templates` + `.claude` + کلاس قرنطینهٔ checklist) را فهرست کن.
2. گراف wikilink بساز؛ همهٔ مقایسه‌ها با **NFC + casefold + حذف کاراکترهای جهت‌دار RTL**.
3. orphan را **per-subtree** حساب کن؛ «orphan واقعی» را از «عضو خوشهٔ جزیره‌ای» (لینک داخلی دارد، لینک بیرونی ندارد) جدا گزارش کن — خوشهٔ جزیره‌ای نیاز به ۱ لینک hub دارد، نه n لینک.

## فاز ۲ — کشف کاندیدا

- **unlinked-mention:** عنوان نوت B در بدنهٔ A هست، لینک نیست. فقط عنوان‌های «متمایز» (چندکلمه‌ای یا فارسی یا ≥۸ کاراکترِ غیر-generic)؛ تطبیق فقط با word-boundary. عنوان‌های قالبی (Research/Roadmap/Timeline/DecisionLog/…) هرگز.
- **frontmatter:** `project:`/`parent:`/`aligns_to:` بدون لینک متناظر.
- هر کاندیدا برچسب بخورد: هم‌subtree یا بین‌دایرکتوری؛ فقط بین‌دایرکتوری‌ها اولویت دارند.

## فاز ۳ — سه‌لایه‌سازی (ضد توهم)

- **Tier A:** ارجاع صریح و بی‌ابهام → آمادهٔ اعمال.
- **Tier B:** ابهام (ایندکس عمداً ساده، خوشهٔ قالبی، نوت گزارشی) → فقط با بازبینی.
- **Tier C:** هرگز (منابع `_superseded`، نوت‌های overwrite-شونده، پرامپت‌های گذرا، کلاس قرنطینه).
- **قانون:** هیچ رابطهٔ «استنباطی» LLM بدون شاهد متنی مستقیم وارد Tier A نمی‌شود. نمونه‌گیری ۱۰٪ از Tier A و چک دستی شاهد؛ اگر دقت <۹۵٪ بود، کل دسته به Tier B سقوط می‌کند.

## فاز ۴ — verdict

خروجی فقط یک نوت `CONNECTIONS-MAP` تازه در `_memory/`. هیچ اعمالی بدون verdict صریح آری.

## فاز ۵ — اعمال (فقط بعد از verdict)

1. فقط Tier A تاییدشده. روش: افزودن بخش `## مرتبط` در **انتهای نوت منبع** (نه دست‌کاری متن اصلی) — برگشت‌پذیر و diff-خوانا.
2. نوت‌های overwrite-شونده و read-only (قانون اساسی) هرگز ویرایش نمی‌شوند.
3. بعد از هر دسته: هر دو validator؛ اگر >۵ فایل تغییر کرد و vault روزی git شد: commit `agent-checkpoint: link-batch <n>`.
4. متر موفقیت: Δorphan واقعی + Δدرجهٔ میانگین + «هر خوشهٔ جزیره‌ای ≥۱ لینک hub» — نه تعداد خام لینک.

## حلقهٔ بهبود

هر اجرا، false-positiveهای دیده‌شده را به فهرست STOP همین پرامپت اضافه کن (append، با تاریخ). این نوت سند زنده است.
