| فیکی که تابعِ واقعی را دور می‌زند | کلاسِ **واقعی** را بساز، نه فیک |
| سبزِ دروغین | شمارِ صریحِ pass/fail + exit code |
| جهشِ سبز | جهش را اعمال کن؛ هیچ تستی قرمز نشد ⇒ آن خط دیده‌نشده است |
| ادعای بی‌نامِ نماد | `git grep` بزن؛ صفر خواننده = گپ |
| «انجام شد» = فلگ | اثر را در ظرفِ مقصد بسنج |
| ری‌استارتِ بی‌اثر | `RESTART-PROCESS.ps1` + **مقایسهٔ PID** |
| نبودِ داده = حکم | سه‌حالتی گزارش: ok / نه / **نمی‌دانم** |

## اگر فقط یک چیز را به یاد بسپاری

> این سیستم بارها «سبز» بوده و کار نکرده. هر بار ریشه یکی بود: **ادعایی که هیچ
> مشاهده‌ای نمی‌توانست ابطالش کند.** پس هر چیزی که می‌سازی را طوری بساز که بتواند
> دروغ‌گفتنش را نشان دهد — و بعد بررسی کن که واقعاً نشان می‌دهد.
