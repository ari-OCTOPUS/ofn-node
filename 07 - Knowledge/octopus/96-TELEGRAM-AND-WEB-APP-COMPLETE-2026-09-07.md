### چت آزاد با مغز

وقتی متن بدون `/` می‌فرستی، center.py آن را به **مغز محلی** (qwen via `ask_brain`) می‌دهد و جواب برمی‌گرداند. فلگ‌های فعال:

- `OCTOPUS_TG_LLM_ASK=1` — چت با LLM فعال
- `OCTOPUS_TG_CHAT_LOCAL=1` — مدل محلی
- `OCTOPUS_TG_ASK_VAULT=1` — پرسش از vault
- `OCTOPUS_TG_ASK_BRAIN=1` — پرسش مستقیم از مغز
- `OCTOPUS_TG_ASK_ESCALATE=1` — ارتقا به مدل قوی‌تر

**چگونگی چت:** در DM ربات @Robo2725_bot هر متنی بفرست (بدون /) — اختاپوس با مغز محلی جواب می‌دهد ($0).

## نکته‌های معماری

- سنتر تلگرام **یک poller** است (نه HTTP server) — پیام‌ها را از API تلگرام می‌کشد
- مینی‌اپ یک **دیوار HMAC** است — فقط با initData معتبر تلگرام دادهٔ کامل می‌دهد
- کنترل‌پنل **local-only** است — بدون احراز، فقط روی 127.0.0.1
- همهٔ سه سطح از **همان مغز** استفاده می‌کنند (model_router → cortex → local/paid)
