# واژه‌نامه

| واژه | معنا |
|---|---|
| **OCTOPUS** | سیستم چندایجنتی مالک. معماری اندام‌وار با یادگیری تحت حکمرانی و تصمیم قابل حسابرسی |
| **NBB-CP** | Control Plane. لایهٔ حکمرانی fail-closed با حاکمیت انسانی. طبق NBB-V1 حاکم بالای شش پا |
| **شش پا** | حسابداری (فقط طراحی) · رنگ سرب (زنده، ۳۳ تست) · استخراج (فقط پژوهش) · کریپتو-eToro (`NO_ACTION`) · زیمان (زنده، ۲۱ تست) · پروژه-F (زنده، ۲۹ تست) |
| **دو مغز** | `4d_system` و `NBB-CP` |
| **رصدخانه** | زیرسیستم فقط‌خواندنی سنجش پیش‌بینی در برابر دنیای واقعی |
| **تک‌درگاه خروج** | اصل «فقط یک فایل اجازهٔ شبکه دارد» — `gateway.py` |
| **fail-closed** | در شک، مسدود کن |
| **propose-only** | ایجنت پیشنهاد می‌دهد، اجرا نمی‌کند |
| **invariant** | شرطی که نقضش باعث halt می‌شود، نه retry |
| **Brier score** | معیار خطای پیش‌بینی احتمالی. کمتر بهتر |
| **persistence** | baseline «فردا مثل امروز است» |
| **prior** | baseline نرخ پایهٔ تاریخی |
| **random** | baseline تصادفی |
| **block bootstrap** | روش تصحیح خودهمبستگی در سری‌زمانی |
| **evidence_level A/B/C** | سطح اطمینان یک ادعا — [[11-EVIDENCE-LEVELS]] |
| **RFC 9309** | استاندارد رسمی `robots.txt` |
| **kill switch** | فایل `kill.switch` با محتوای `KILL` — همه چیز را می‌بندد |
| **WIRE flags** | `OCTOPUS_WIRE_*` و `OFN_WIRE_*` — هیچ‌وقت روشن نشوند |
| **مالک** | آرمین. تنها کسی که اجرا می‌کند |
