Part 1 — Architecture Overview / بخش ۱ — نمای کلی معماری
EN: OCTOPUS is a multi-agent organism architecture combining business-facing "legs," independent reasoning systems, a governance layer (NBB-CP), persistent memory, and auditable self-learning loops under a shared control model (Architecture Briefing). Its layer stack runs L1 Governance (PROJECT_INSTRUCTIONS.md, human-only edit, 200-line ceiling) → L2 Control (dual-brain, 6-step Perception→Diagnosis→Proposal→Human Verdict→Apply→Measure loop) → L2b External Intelligence (Sakana Fugu API, Tokyo, multi-agent orchestration with 5 use points F1–F5) → L3 Ingest/Security (4 gates: Path Scope, Checklist Quarantine, Secret Scan, Encoding Sanity) → L4 Memory/Knowledge (Durable, Active, Decision, Agent-synthesis layers) → L5 Project/Ops (G0–G4 gates) → L6–L9 People/Log/Handoff/Agent templates.
FA: OCTOPUS یک معماری ارگانیسمی چندعاملی است که «پاهای» کسب‌وکارمحور، سیستم‌های استدلال مستقل، یک لایهٔ حاکمیتی (NBB-CP)، حافظهٔ پایدار، و حلقه‌های خودیادگیریِ قابل‌حسابرسی را تحت یک مدل کنترل مشترک ترکیب می‌کند (بریفینگ معماری). پشتهٔ لایه‌ای آن عبارت است از: L1 حاکمیت (PROJECT_INSTRUCTIONS.md، ویرایش فقط توسط انسان، سقف ۲۰۰ خط) ← L2 کنترل (دومغزی، حلقهٔ شش‌مرحله‌ای ادراک←تشخیص←پیشنهاد←رأی انسانی←اعمال←سنجش) ← L2b هوش بیرونی (Sakana Fugu API، توکیو، هماهنگی چندعاملی با پنج نقطهٔ مصرف F1 تا F5) ← L3 ورودی/امنیت (چهار دروازه: محدودهٔ مسیر، قرنطینهٔ چک‌لیست، اسکن راز، سلامت رمزگذاری) ← L4 حافظه/دانش (لایه‌های پایدار، فعال، تصمیم، سنتز عامل) ← L5 پروژه/عملیات (دروازه‌های G0 تا G4) ← الگوهای L6 تا L9 برای افراد/لاگ/انتقال/عامل.

EN: Ant colonies use quorum thresholds to switch from slow assessment/recruitment to commitment; the mechanism trades decision speed against reliability rather than making consensus intrinsically true (Pratt et al., Behavioral Ecology and Sociobiology). This is the crucial engineering point that both councils insist on: OCTOPUS must count independent evidence families, not agent messages — detecting correlated models, shared sources, copied reasoning, and common prompts; preserving dissent and its evidence; escalating disagreement rather than averaging it away; setting thresholds by impact, reversibility, uncertainty, and time pressure; capping deliberation cost; and allowing abstention. A quorum of homogeneous agents is one correlated vote, not independent confirmation. Diversity is a required input to quorum, not an optional aesthetic (GPT-5.6 Sol C2, §5; biological AI council on "monitor and proposer sharing one model/memory = repeated role, not independent cognition," paste.txt).

11.3 The State Ladder / نردبان وضعیت
EN: The first council confused declared (appears in policy/docs) with deployed (that artifact digest is running). Every fact in an audit must be classified along GPT-5.6 Sol's state ladder (GPT-5.6 Sol C2 §7.A):

Implemented — code exists.
Tested — a bound artifact passed.
Deployed — that artifact digest is running.
Drilled — behavior was observed under a realistic failure.
Independently reproduced — an auditor reran or directly verified it.
