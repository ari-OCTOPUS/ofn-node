# قالبِ پاسخِ ایجنتِ خود-ممیز

> هر بخش الزامی؛ خالی = «چیزی یافت نشد» صریح. هر عدد با file:line.

1. **خلاصهٔ اجرایی** (≤۱۰ خط — حکمِ کلی + ۳ یافتهٔ برتر)
2. **فرضیات و ابهام‌ها** (هرچه قطعی نیست، جدا از واقعیت)
3. **جدولِ زنده/مرده** — جزء | شاهدِ تازگی | حکم (زنده/کهنه/تزئین/مرده)
4. **دیاگرامِ معماریِ مشاهده‌شده** (اگر با نقشهٔ مرجع فرق دارد، فرق را بگو)
5. **سیم‌های بریده** — producer↔consumer + کوچک‌ترین فیکس
6. **نقاطِ قوت** (حداکثر ۵، شواهددار)
7. **ریسک‌های جدی/پنهان** — جدولِ تهدید|سناریو|احتمال|شدت|راهکار
8. **Failure Modes** — مرگِ پروسه/قفل/فایلِ سرگردان + مسیرِ بازیابی
9. **تحلیلِ حافظه** (append-only/atomic/persist — تست‌شده، نه فرضی)
10. **تحلیلِ ابزار/گیت‌ها** — هر مسیرِ اثرگذار → گیتِ انسانی‌اش
11. **تحلیلِ تست‌پذیری** — green-lie/فانتوم/ثبت‌نشده + پوشش‌های خالی
12. **اصلاحاتِ فوری** (امن، بدونِ رأی) / **اصلاحاتِ رأی-خواه** (پول/ارسال/schema)
13. **پیشنهادِ V2** — فقط از شکاف‌های اثبات‌شده، هر آیتم با تلاش/اثر/گیت
14. **تست‌های ضروریِ بعدی** (نام + چه چیزی را قفل می‌کند)
15. **جدولِ امتیاز** — معماری/پایداری/امنیت/تست/صداقتِ UI (۱..۵ + دلیلِ یک‌خطی)
16. **سوال‌های تکمیلی از مالک** (کاربردی، append به AGENT_QUESTIONS)
17. **نتیجهٔ نهایی** (۳ خط، بدونِ تعارف)
