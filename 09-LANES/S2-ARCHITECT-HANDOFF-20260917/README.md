# S2 — بستهٔ معمار اجرایی اختاپوس

این بسته برای شروع سریع ایجنت بعدی تهیه شده است؛ اجرای سیزن جدید یا deploy انجام‌شده نیست.

1. `python verify_bundle.py` — بررسی تمامیت بسته.
2. `PROMPT-AND-DATA.md` — پرامپت کامل همراه دادهٔ آغازین؛ همان را به ایجنت بعدی بده.
3. `EXPERIMENT-PROTOCOL.md` — معیار واقعی یادگیری، خودترمیمی، کنترل آزمایش و شواهد.
4. `MATURITY-GATES.json` — شروط قابل‌ماشین‌خواندن؛ همه هنوز از روی receipt فعلی نیاز به ارزیابی دارند.
5. `CONCEPT-AND-RESEARCH.md` — تفسیر مفهومی، پیشینه و مرز ادعاها.

`source/` گزیدهٔ کد موجود و وصله‌هاست؛ checkout کامل یا بستهٔ deploy نیست. `evidence/`
رسیدها و گزارش‌های دقیق S1 است؛ هیچ‌کدام خودبه‌خود وضعیت فعلی runtime را اثبات نمی‌کند.
`SOURCE-INDEX.json` هر فایل همراه را به مسیر اصلی و SHA بایت‌هایش وصل می‌کند.

دادهٔ خام تجاری، کلید، credential، .env، ژورنال کامل و fixture واقعی ۳۰۰۰رویدادی در ZIP
نیستند. benchmark fixture باید از مسیر موجودِ معتبر و hash ثبت‌شده خوانده شود؛ با
دادهٔ مصنوعی جایگزین نشود. fixtureهای fault اگر ساخته شوند صریحاً synthetic برچسب دارند.

ریشهٔ اجرایی کاندید: `F:/wt-s1-fleet-self-model-20260917`، commit `31a39ee6`.
ریشهٔ T1: `F:/s1-t1-rehearsal-20260917/09-LANES/S1-T1-REHEARSAL-20260917`.
ریشهٔ vault: `F:/backup`. برای اجرا روی دستگاه دیگر، این مسیرها را به منابع واقعاً موجود
map کن؛ ZIP به‌تنهایی دسترسی یا محیط runtime ایجاد نمی‌کند.

پرامپت اجازهٔ موجود مالک را منتقل می‌کند؛ امضای رمزنگاری یا release جدید تولید نمی‌کند.
بازکردن این فایل، ساخت task یا شروع worker نیست. فایل‌ها داخلی‌اند؛ برای انتشار عمومی
نیاز به نسخهٔ بازبینی و پاک‌سازی‌شده دارند.
