## برای هر اندام، پنج رگ را بپرسید (جدول خروجیِ فاز ۰)

| رگ | سوال | منبع جواب |
|---|---|---|
| **رگِ محاسبه** | این اندام می‌تواند از استخر پایه کار/CPU بکشد؟ کانالش کجاست؟ | کد + capability رجیستری |
| **رگِ مغز** | این اندام اصلاً «مغز» صدا می‌زند؟ از کدام مسیر (remote_brain/BRAIN_PROVIDER/T3/llama)؟ | importها + لجر api-budget |
| **رگِ داده** | state/حافظه‌اش کجاست؟ تغذیه‌اش از کجا می‌آید؟ | مسیرهای state |
| **رگِ رسید** | اثرهایش رسید دارند؟ قابل rollback اند؟ | receipts/events |
| **رگِ تلمتری** | سلامتش دیده می‌شود؟ (heartbeat/journal/unit) | تایمرها + heartbeat |

وضعیت هر خانه یکی از: `PERFUSED` (خون می‌رسد، شاهد دارد) / `BLOCKED` (رگ بسته
است، عامل مشخص) / `ATROPHIED` (اندام هست ولی هیچ‌وقت تغذیه نشده — کد بدون
فراخوانی) / `DORMANT` (عمداً خاموش؛ دلیل حکمی) / `UNKNOWN` (نمی‌دانیم — صادق).
