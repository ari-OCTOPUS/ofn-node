# آزمایشگاه تکاملی اختاپوس | کد و راهنمای اجرا

OCTOPUS QD Lab یک «جزیرهٔ تکاملی» محلی است: شبکه‌های عصبی کوچک در ماز دوبعدی آزمایش می‌شوند، از آرشیو نخبگان والد می‌گیرند و مهارت‌های متنوع تولید می‌کنند. ثبت شواهد، شاخص‌های وضعیت و بستهٔ پیشنهاد از مفاهیم اختاپوس الهام گرفته‌اند؛ این کد به Core، گیت‌هاب، والت، مدل‌های پولی یا بردهای واقعی وصل نیست.

## اجرای سریع

Python 3.10 یا جدیدتر لازم است. فقط NumPy و Matplotlib نصب می‌شوند؛ GPU، کلید API و دادهٔ خصوصی لازم نیست.

```bash
python -m pip install -r requirements.txt
python -m unittest discover -v
python replay.py
```

دستور آخر، بهترین نخبهٔ داده‌های همراه بسته را بازپخش و تطابق کیفیت و رفتار آن را بررسی می‌کند. برای اجرای آزمایش کوچک مستقل، از پوشهٔ خروجی جدید استفاده کنید.

```bash
python experiment.py --out smoke --generations 4 --initial 32 --batch 16 --grid 16 --seeds 7 --modes full mutation random
python analyze.py --results smoke
```

آزمایش کوچک صرفاً بررسی نصب و مسیر اجراست و فرضیه‌های عملکردیِ مطالعهٔ اصلی را تأیید نمی‌کند. پوشهٔ موجود و اجرای ناقص بازنویسی نمی‌شوند؛ برای تکرار از نام تازه استفاده کنید.

## بازتولید مطالعهٔ اصلی

هر روش در سه بذر 7، 11 و 23، با 500 نسل، 256 فرد آغازین و 96 فرزند در هر نسل اجرا می‌شود. همهٔ روش‌ها دقیقاً 48,256 ارزیابی دارند و نقاط آغاز و محیط یکسان‌اند.

```bash
python experiment.py --out reproduced
python validate.py --archive reproduced/full_seed7/archive.npz --out reproduced/full_archive_replay.json
python analyze.py --results reproduced
python write_report.py --results reproduced
```

در ویندوز اگر `python` شناخته نشد، از `py` استفاده کنید. می‌توانید وابستگی‌ها را در محیط مجازی نصب کنید:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m unittest discover -v
```

برای کم‌کردن سربار BLAS در لینوکس، اجرای `OPENBLAS_NUM_THREADS=1 python experiment.py --out reproduced` مناسب است. بین نسخه‌ها یا سخت‌افزارهای عددی متفاوت، اختلاف بسیار کوچک اعشاری ممکن است به انتخاب نخبگان متفاوت منجر شود؛ نسخه‌های اجرای تحویلی در `results/study.json` ثبت شده‌اند.

## فایل‌های مهم

| فایل | کارکرد |
|---|---|
| `environment.py` | ماز، حسگرها، کنترلر 6→8→2، برخورد پویش‌شده و کیفیت |
| `map_elites.py` | آرشیو دوبعدی، ترکیب یکنواخت، Iso+LineDD، جهش و نسب والدین |
| `octopus_bridge.py` | زنجیرهٔ شواهد، بررسی تمامیت، پیشنهاد fail-closed و وضعیت observe-only |
| `experiment.py` | پروتکل ثابت، بذرها، اجرای برابر و ثبت هش کد و خروجی‌ها |
| `analyze.py` | شش نمودار، دادهٔ ژنوم، تحلیل، فرضیه‌ها و پیشنهاد نهایی |
| `replay.py` | بازپخش دقیق نخبه و خروجی اختیاری مسیر CSV |
| `validate.py` | بازپخش عددی همهٔ نخبگان آرشیو نمونه |
| `test_simulator.py`, `test_bridge.py`, `test_analysis.py` | آزمون‌های علمی، مرزهای شواهد و تطبیق گزارش |
| `results/study.json` | تنظیمات، نسخه‌ها، هش کد و آستانه‌های ثبت‌شده پیش از مطالعهٔ v2 |
| `results/*_seed*/archive.npz` | وزن‌های کامل، رفتار، کیفیت، والدین و زمان‌های آرشیو |
| `results/*_seed*/receipts.jsonl` | رویدادهای زنجیره‌شده و شناسهٔ والدین واقعاً مصرف‌شده |
| `results/analysis/elites_archive.csv` | یک ردیف برای هر نخبه با 74 وزن در دقت کامل |
| `results/analysis/elite_cards.json` | شش نمونه با ماتریس‌های W1، b1، W2، b2 |
| `results/analysis/hypothesis_records.json` | آستانه‌ها، measured_delta و verdict |
| `results/analysis/promotion_proposal.json` | پیشنهاد بدون مجوز اجرا |
| `results/analysis/self_model.json` | شرح ساختاری توانایی‌ها و مجهولات، نه مدل جهان |

شناسهٔ نخبه درون هر اجرا معنی دارد، نه بین همهٔ بذرها. برای بازپخش یک نخبهٔ خاص، شناسه را از CSV همان اجرا بردارید.

```bash
python replay.py --elite-id 1234 --trajectory my_trajectory.csv
```

عدد `1234` فقط نمونه است و ممکن است در آرشیو باقی نمانده باشد. دستور بدون `--elite-id` همیشه بهترین نخبهٔ آرشیو را انتخاب می‌کند.

## قرارداد علمی

کیفیت این نسخه برابر است با:

\[
q=\min(L/0.5,1)\,[1-0.6\,\overline{|turn|}-0.4\,collision\_rate].
\]

بنابراین بی‌حرکتی امتیاز بالای کاذب نمی‌گیرد؛ اما حرکت حلقوی همچنان می‌تواند خوب ارزیابی شود. این سنجه «حرکت کافی، نرمی و کاهش برخورد» را می‌سنجد، نه کوتاه‌ترین مسیر، هوش عمومی یا سود کسب‌وکار.

پوشش اصلی برابر تعداد سلول‌های پُر تقسیم بر تمام سلول‌های شبکه است. پوشش کمکیِ مراکز آزاد فقط تقریب هندسی است؛ سلول مرزی می‌تواند نخبه‌ای بیرون مانع داشته باشد ولی مرکز همان سلول داخل مانع باشد، بنابراین این دو شمارش نباید مخلوط شوند.

`first_generation` اولین کشف سلول و `last_generation` آخرین جایگزینی نخبه است. پذیرش متوالی فرزند و باقی‌ماندن آن در پایان batch نیز جداگانه گزارش می‌شوند.

## مرز اختاپوس

اینجا «حافظه» آرشیو مهارت‌هاست و مصرف آن با شناسهٔ والدهای انتخاب‌شده ثبت می‌شود. این مکانیزم با حافظهٔ معنایی یا یادگیری مدل زبانی یکی نیست و شاهد اتصال به حافظهٔ زندهٔ اختاپوس محسوب نمی‌شود.

زنجیرهٔ هش محلی بدون امضاست؛ هویت مالک یا استقلال شاهد را اثبات نمی‌کند. حذف انتهای زنجیره فقط در مقایسه با head و count مورد انتظار آشکار می‌شود؛ بازنویسی هم‌زمان داده و لنگر محلی با این طرح به‌تنهایی قابل جلوگیری نیست.

وضعیت GREEN/YELLOW/RED/BLACK از یک فرمول اسباب‌بازی منابع استخراج می‌شود و صرفاً دیده‌بانی است. هیچ فرمان اجرا، اعطای خودمختاری A1/A2، ارتقای Core یا اتصال Orange Pi/ESP32 در بسته وجود ندارد.

## مفاهیم مگاپرامپت

سه ایده به مکانیزم اجرایی محدود شده‌اند: آرشیو مهارت و استفادهٔ دوباره، مقایسهٔ کنترل‌شدهٔ عملگرها، و شواهد fail-closed. نام پروژه‌های بیرونی و ادعاهای فایل ارسالی در این مطالعه راستی‌آزمایی نشده‌اند و شاهد تجربی این شبیه‌ساز نیستند.

مگاپرامپت ادامهٔ کار در `OCTOPUS_QD_HANDOFF.md` دقیقاً مرز آزمایش، آستانه‌ها، شواهد و شروط توقف را حفظ می‌کند. هیچ نتیجهٔ شبیه‌سازی مجوز انتشار یا اجرای بیرونی نیست.
