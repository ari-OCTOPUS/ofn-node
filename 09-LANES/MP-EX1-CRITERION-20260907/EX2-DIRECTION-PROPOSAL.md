# EX2 — انحراف جهت مولد (پیشنهاد محدود، اعمال‌نشده)

طبق قاعدهٔ مالک: ایراد پیاده‌سازی ⇒ اصلاح محدود + آزمون مرتبط، بدون دست‌زدن به تاریخ.

متن v3.0 §EX-2: `خروجی: ops/verifiable_claims.yaml → contracts/claim_v1.py (مولد + قفل SHA-256 + سربرگ DO NOT EDIT)`  
پیاده‌سازی بررسی‌شده (baseline `ba5d239…` و candidate دیباگ): منبع Python است و YAML خروجی مولد است.

طبقه‌بندی: **انحراف پیاده‌سازی از متن فعلی قرارداد**، نه مجوز تغییر قرارداد برای سبز شدن.

اصلاح پیشنهادی (اعمال نشود تا دستور جدا):

1. مولد را روی لپ‌تاپ به مسیر YAML→Python برگردان؛ runtime برد به PyYAML وابسته نشود.
2. تست‌های round-trip / parity / قفل F1 را نگه دار.
3. نتیجهٔ ۱۶۵ تست قبلی را تحت همان candidate و همان هش‌ها حفظ کن؛ آن اجرا را این نشست تکرار نکرد (`TEST-RECEIPT.json` منبع نقل است).

این پیشنهاد EX1 را PASS نمی‌کند و EX3 را شروع نمی‌کند.
