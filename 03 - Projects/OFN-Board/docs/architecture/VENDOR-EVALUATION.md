# ارزیابی vendor مارکتینگ — کاندیدها و معیارها

**فاز M · تاریخ: ۲۰۲۶-۰۸-۱۰ · این یک تصمیم نیست، یک ارزیابی است.**

> هیچ vendor ای بدون حکم آری وصل نمی‌شود. این سند کاندیدها را با معیار
> مشخص می‌سنجد تا تصمیم آگاهانه باشد.

## معیارها (از مگاپرامت M.1)

| معیار | چرا مهم است |
|---|---|
| API رسمی | بدون API رسمی، adapter نمی‌تواند چیزی بخواند |
| Webhook امضا | بدون امضا، پذیرش payload ناامن است (یافته ۱) |
| Rate limit شفاف | بدون آن، flood ممکن است |
| OAuth یا API key | OAuth پیچیده‌تر ولی امن‌تر؛ API key ساده‌تر |
| هزینه/مدل | مالک باید بداند قبل از commit |
| پشتیبانی فارسی | برای شریک‌ها (سبا/ملیحه) |

## کاندیدها

### ۱. Telegram Bot API (پیش‌فرض — از قبل وصل)

| معیار | وضعیت |
|---|---|
| API رسمی | ✅ مستند کامل |
| Webhook امضا | ✅ HMAC-SHA256 + secret_token |
| Rate limit | ✅ شفاف (۳۰ msg/s) |
| OAuth/Key | ✅ Bot Token (API key) |
| هزینه | ✅ رایگان |
| فارسی | ✅ عالی |

**ریسک:** فقط Telegram — سایر پلتفرم‌ها (Instagram/ایمیل) پوشش نمی‌گیرد.

### ۲. Bluesky AT Protocol

| معیار | وضعیت |
|---|---|
| API رسمی | ✅ open protocol |
| Webhook امضا | ⚠️ محدود — firehose است نه webhook امضاشده |
| Rate limit | ✅ ساده |
| OAuth/Key | ✅ App Password |
| هزینه | ✅ رایگان |
| فارسی | ⚠️ متوسط |

**ریسک:** جامعه کوچک؛ adapter خشک از قبل در `platforms/bluesky.py` هست.

### ۳. Meta Graph API (Instagram)

| معیار | وضعیت |
|---|---|
| API رسمی | ✅ مستند |
| Webhook امضا | ✅ HMAC + app secret |
| Rate limit | ⚠️ پیچیده (slots/calls) |
| OAuth/Key | ⚠️ OAuth سنگین + review اپ |
| هزینه | ⚠️ تغییرات قیمت‌گذاری ۲۰۲۶ |
| فارسی | ✅ |

**ریسک:** OAuth پیچیده، Graph API مدام تغییر می‌کند، نیاز به App Review.
یافته ۹۹: adapter از قبل غایب است.

### ۴. Mailchimp

| معیار | وضعیت |
|---|---|
| API رسمی | ✅ |
| Webhook امضا | ✅ |
| Rate limit | ✅ |
| OAuth/Key | ✅ API key |
| هزینه | ⚠️ پولی + pricing tiers |
| فارسی | ⚠️ |

**ریسک:** برای ایمیل مارکتینگ است نه «محتوای استودیو»؛ سنگین برای این برد.

## خلاصه

| vendor | مناسب برای | ریسک |
|---|---|---|
| **Telegram (پیشنهاد اول)** | همه — از قبل وصل | فقط یک پلتفرم |
| **Bluesky** | آزمایش محتوا | کوچک |
| **Meta/Instagram** | استودیو (سبا) | OAuth سنگین |
| **Mailchimp** | ایمیل | پولی |

## پیشنهاد به آری
1. **کوتاه‌مدت:** Telegram Bot API را به‌عنوان vendor رسمی اول بپذیر (همه‌چیز
   از قبل آماده است؛ فقط HMAC واقعی + sender با حکم).
2. **آزمایش:** Bluesky به‌عنوان pilot read-only (adapter خشک موجود است).
3. **Meta/Instagram:** فقط بعد از اینکه studio واقعاً نیازش را نشان داد.
4. **Mailchimp:** رد — هزینه و وزن برای این برد.

**منتظر حکم آری.** هیچ کد vendor ای تا حکم نوشته/وصل نمی‌شود.
