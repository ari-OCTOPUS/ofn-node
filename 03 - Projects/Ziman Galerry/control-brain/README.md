# 🧠 مغز کنترل (Control Brain) — نسخهٔ اول

رابطِ فرماندهیِ تو. از **تلگرام** (و یک **داشبوردِ وبِ کوچک** روی لپ‌تاپ) وضعیتِ همهٔ پروژه‌هایت را می‌بینی و یک پروژه را **روشن / خاموش / تست** می‌کنی. ساده، تمیز، و مطمئن.

> این «برشِ نازکِ اول» است: کوچک ولی واقعی و تست‌شده. بعداً می‌شود پله‌پله بزرگش کرد.

---

## این نسخه چه‌کار می‌کند
- دیدنِ وضعیتِ همهٔ پروژه‌ها (روشن / خاموش / سالم).
- روشن، خاموش و تستِ یک پروژه — از تلگرام یا از خط فرمان.
- **دکمهٔ توقف اضطراری**: تا وقتی روشن است، هیچ پروژه‌ای بالا نمی‌آید.
- **فقط مالک**: ربات فقط به آی‌دی چتِ خودت جواب می‌دهد.
- یک پروژهٔ **نمونه** همراهش هست تا بدون هیچ رمز یا پروژهٔ واقعی، همین حالا تستش کنی.

## داخلش چیست
```
control-brain/
├─ core/            # مغزِ منطقی (مستقل از تلگرام و وب) → کاملاً تست‌شده
│  ├─ manager.py    #   روشن/خاموش/تست/وضعیت
│  ├─ registry.py   #   خواندن لیست پروژه‌ها از projects.yaml
│  ├─ safety.py     #   قفل ایمنی (دکمهٔ توقف)
│  ├─ store.py      #   حافظه (یک پایگاه‌دادهٔ سبک)
│  └─ runner.py     #   اجرای واقعی فرایندها
├─ adapters/
│  ├─ telegram_bot.py  # رابط تلگرام
│  └─ dashboard.py     # داشبورد وبِ فقط-خواندنی
├─ config/projects.yaml # لیست پروژه‌هایت را اینجا تعریف می‌کنی
├─ sample_project/       # پروژهٔ نمونه برای تست
├─ tests/                # آزمون‌ها
├─ app.py                # نقطهٔ شروع
└─ requirements.txt
```

## راه‌اندازی روی لپ‌تاپ (ویندوز)

۱) پایتون ۳.۱۰ یا بالاتر نصب باشد. بعد در همین پوشه:
```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

۲) **اول بدون تلگرام تستش کن** (تا مطمئن شوی کار می‌کند):
```
python app.py status         # وضعیت همه
python app.py start demo      # روشن‌کردن پروژهٔ نمونه
python app.py status          # حالا باید «running» باشد
python app.py stop demo       # خاموش‌کردن
python app.py test demo       # باید «سبز» بدهد
```

۳) داشبورد وب:
```
python app.py
```
بعد در مرورگر برو به:  `http://127.0.0.1:8770`

## وصل‌کردن تلگرام (اختیاری، وقتی آماده بودی)

۱) در تلگرام به **@BotFather** برو، دستور `/newbot` → یک **رمزِ ربات (token)** می‌گیری.
۲) به **@userinfobot** برو تا **آی‌دی عددیِ چتِ** خودت را ببینی.
۳) فایل `.env.example` را کپی کن به نامِ `.env` و پرش کن:
```
TELEGRAM_TOKEN=رمزی که از BotFather گرفتی
OWNER_CHAT_ID=آی‌دی عددی خودت
```
۴) اجرا:
```
python app.py
```
حالا در تلگرام به رباتت `/status` بزن. دکمه‌های ▶️ روشن، ⏹ خاموش، 🧪 تست، و `/halt` و `/resume` را داری.

> رمزها فقط داخل `.env` می‌مانند و هیچ‌وقت داخل کد یا vault نمی‌روند (فایل `.gitignore` مراقبش است).

## اضافه‌کردن پروژهٔ واقعی
فایل `config/projects.yaml` را باز کن. برای هر پروژه:
```
  - id: painting
    name: "ربات نقاشی"
    workdir: "C:/Users/Armin/Desktop/backup/03 - Projects/نقاشی/کاریابی/bot"
    start: ["python", "main.py"]     # دستور روشن‌کردن
    test:  ["pytest", "-q"]          # دستور تست (اختیاری)
    enabled: true                    # تا رمزها عوض نشده، false بگذار
```
> نکته: تا **تعویض رمزها** انجام نشده، پروژه‌های واقعی را `enabled: false` نگه‌دار. مغزِ کنترل خودش جلوی روشن‌شدنشان را می‌گیرد.

## دکمهٔ توقف اضطراری
- در تلگرام: `/halt` (متوقف)، `/resume` (ادامه).
- در خط فرمان: `python app.py halt` و `python app.py resume`.
- تا وقتی متوقف است، یک فایل به‌نام `STOP` وجود دارد و هیچ پروژه‌ای روشن نمی‌شود.

## آزمون‌ها
اگر `pytest` داری:  `pytest -q`
اگر نداری:  `python run_tests.py`  (بدونِ هیچ نصبِ اضافه)

## کجا نگهش دارم؟
- می‌توانی همین پوشه را طبق قواعد vault داخلِ `04 - Architect System/architect/_code/` بگذاری (کدِ اجرایی آنجا زندگی می‌کند).
- محیطِ مجازی (`.venv`) و پوشهٔ `data/` را **بیرون از vault** بساز؛ یا متغیرِ `CONTROL_STATE_DIR` را به یک مسیرِ بیرونی بده تا حافظه آنجا ذخیره شود.

## محدودیت‌های این نسخه (صادقانه)
- «روشن‌کردن» یعنی اجرای یک فرایندِ محلی روی همین لپ‌تاپ؛ برای همیشه‌روشن‌بودن، بعداً باید روی یک سرور برود.
- صفِ «تأیید/رد» و اتصال به مغزِ هوش مصنوعی هنوز اینجا نیست — عمداً، تا اول همین هستهٔ ساده مطمئن جا بیفتد.
- قدم بعدی پیشنهادی: اول رمزها را عوض کن، بعد یک پروژهٔ واقعی (ربات نقاشی) را `enabled` کن و یک هفته آزمایشی بگیر.

## 🔐 رمزها (خلاصه — جزئیات کامل در `SECRETS.md`)
همهٔ رمزها فقط در **KeePassXC** می‌مانند. مغزِ کنترل موقعِ شروع یک‌بار قفلش را باز می‌کند و رمزِ هر پروژه را موقعِ روشن‌کردن خودش تزریق می‌کند — هیچ `.env`ِ خامی پخشِ پروژه‌ها نمی‌شود.
- بررسیِ درستیِ تنظیمات (بدونِ نمایشِ مقدار): `python app.py secrets-check`
- تعویضِ رمز = فقط در KeePassXC عوضش کن؛ به کد دست نمی‌زنی.

## ▶️ شروعِ یک‌کلیکی
روی ویندوز فقط **`start.bat`** را دابل‌کلیک کن (بارِ اول خودش محیط و کتابخانه‌ها را می‌سازد). یک‌بار رمزِ KeePassXC را می‌پرسد و بالا می‌آید. روی لینوکس/VPS: `./start.sh`.
