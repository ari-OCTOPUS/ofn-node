# OPS-02 — Site Inspection Checklist

> چک‌لیستِ بازدیدِ سایت پیش از quote نهایی. ورودیِ OPS-01 (quoting). agentِ Operations این را به‌عنوان فرمِ ساختاریافته draft می‌کند؛ Operator در محل پر می‌کند یا عکس می‌فرستد.
> بدونِ کد؛ فقط checklist تئوری.

---

## ۰. چرا بازدید
quote دقیق بدونِ دیدنِ سطح ممکن نیست. بازدید سه چیز را قفل می‌کند: **m² واقعی، وضعیتِ prep، و ریسک‌های ایمنی/قانونی** (lead/asbestos/ارتفاع → OPS-09).

## ۱. پیش از رفتن
- آدرس + suburb + سگمنت ثبت شده؟
- نوعِ کار (داخلی/بیرونی/هر دو) از enquiry مشخص است؟
- سنِ تقریبیِ ساختمان (برای ریسکِ lead paint پیش‌از ۱۹۹۷)؟
- دسترسی/پارکینگ/کلید/حضورِ ساکن هماهنگ؟

## ۲. اندازه‌گیری
- [ ] m² هر دیوار/سقف (طول × ارتفاع)
- [ ] تعدادِ درب، پنجره، skirting/trim (متر طول)
- [ ] تعدادِ طبقه و ارتفاعِ سقف
- [ ] feature wallها مشخص

## ۳. وضعیتِ سطح (محرکِ prep)
- [ ] جنس: gyprock / آجر / render / چوب / فلز
- [ ] ترک: مویی / سازه‌ای (سازه‌ای = خارج از scope نقاشی، ارجاع)
- [ ] رطوبت/کپک/شوره (نیاز به treatment پیش از رنگ)
- [ ] پوسته‌شدن/chalking رنگِ قبلی
- [ ] لکه/آب‌زدگی (نیاز به stain block)
- [ ] رنگِ فعلی روشن یا تیره (coat اضافه؟)

## ۴. دسترسی و ایمنی
- [ ] نیاز به scaffold / EWP / نردبانِ بلند؟
- [ ] کارِ ارتفاع (WHS — OPS-09)؟
- [ ] فضای محدود/تهویه؟
- [ ] خطوطِ برق نزدیک نما؟
- [ ] حیوانِ خانگی/کودک/سالمند در محل؟

## ۵. ریسکِ قانونی/سلامت (پرچمِ قرمز → OPS-09)
- [ ] ساختمان پیش‌از ۱۹۹۷ → **تستِ lead paint** پیش از scrape/sand
- [ ] ماده مشکوک به asbestos (eaves، fibro قدیمی) → **توقف، ارجاع به متخصص**
- [ ] اگر هر کدام مثبت: کار متوقف، بازبینیِ scope و quote

## ۶. عکس‌برداری (ورودیِ asset + capital works)
- [ ] عکسِ هر سطحِ مشکل‌دار (برای فرض‌های quote)
- [ ] عکسِ کلیِ before (برای before/after بعداً — KB-03)
- [ ] برای strata: عکسِ وضعیتِ نما برای `capital_works_assessment` (KB-14)

## ۷. خروجی
خلاصهٔ بازدید → ورودیِ OPS-01 §۱/§۲ → agent یک quote draft می‌سازد → Gate → صفِ تلگرام برای تأیید.

> هشدارِ هزینهٔ پنهان (KB-02 §۸): هزینهٔ واقعیِ این بازدیدها = **زمانِ حضوریِ Operator**، نه توکنِ AI. این را در مدلِ مالیِ خودت لحاظ کن.
