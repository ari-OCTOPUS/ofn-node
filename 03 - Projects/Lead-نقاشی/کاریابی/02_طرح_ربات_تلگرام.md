## فیلترهای کاربر (`/setup`)

- **سابرب‌ها**: لیست postcode هایی که می‌پوشونی
- **حداقل/حداکثر مبلغ**: مثلاً $20K تا $2M
- **دسته‌ها**: ☑ Gov ☑ Commercial ☑ Strata ☐ Residential
- **کلمات کلیدی منفی** (skip): مثلاً «remote»، «regional»
- **ساعت digest**: ۸ صبح
- **آلرت لحظه‌ای**: فقط امتیاز >۸۰

## MVP — مرحله اول (هفته ۱-۲)

فقط با ۳ منبع شروع کن:
1. **PlanningAlerts API** (آسون، رایگان، حجم بالا)
2. **AusTender RSS** (RSS مستقیم، بدون scrape)
3. **EstimateOne** (scrape ساده)

با همین سه‌تا، روزانه ۲۰-۵۰ لید با کیفیت می‌رسه.

### استک پیشنهادی

```
Python 3.11
├── python-telegram-bot==21.x  (بات)
├── feedparser                  (RSS)
├── playwright                  (scrape با JS)
├── beautifulsoup4              (HTML)
├── sqlmodel + SQLite           (دیتابیس)
├── apscheduler                 (cron داخلی)
└── openai (اختیاری)            (scoring)
```

### Hosting

- **Render.com** یا **Railway.app** — رایگان تا یه حدی
- **GitHub Actions** — اگه فقط روزانه run می‌کنی
- **Fly.io** — برای always-on

## مرحله ۲ — اضافه کردن منابع (هفته ۳-۴)

- پارس کردن ایمیل alert های `tenders.nsw.gov.au` از یه inbox اختصاصی (Gmail IMAP)
- Scrape سایت Hutchies/Lendlease
- اضافه کردن GPT-4o-mini برای scoring (~ $5/ماه)

## مرحله ۳ — قابلیت‌های پیشرفته (ماه ۲+)

- **CRM mini داخلی**: هر لید یه status (new / quoted / won / lost)
- **Email/SMS هم‌زمان** (Twilio)
- **Dashboard وب** برای historical analytics
- **اشتراک تیمی** (چند کاربر، با role)

## سوال‌های قبل از کد زدن

1. می‌خوای ربات رو من کامل کد بزنم، یا فقط architecture document باشه؟
2. کجا host می‌کنی (Render / Railway / VPS شخصی)؟
3. آیا الان مشترک BCI Central / Cordell هستی، یا فقط با منابع رایگان شروع کنیم؟
4. زبان پیام‌های ربات: فارسی یا انگلیسی؟
5. فقط برای خودت، یا برنامه داری ربات رو به نقاش‌های دیگه هم بفروشی؟
