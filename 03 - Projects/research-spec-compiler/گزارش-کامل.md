# بخش ۱ — اصول و قواعدِ قفل‌شده (این‌ها را بررسی کن)

## ۱.۱ پنج گیتِ سختِ هر spec (تخطی = رد)
هر ایده باید به یک spec ابطال‌پذیر کامپایل شود که این ۵ گیت را PASS کند
(`python rsc.py validate`):

| گیت | معنی | اگر نباشد |
|---|---|---|
| **metric** | نام + جهت + baseline و expected عددی | بی‌فایده |
| **falsifiability** | predicateِ `{metric, op, threshold}` عددی داخلِ [baseline, expected] | شبه‌پژوهش |
| **api_contract** | endpoint + method + request/response ناتهی | قابلِ اتصال نیست |
| **mvp** | stack + effort | قابلِ اجرا نیست |
| **decision_rule** | ≥۲ باندِ پیوسته با verdict؛ باندِ DISCARD با failure هم‌تراز | بدونِ closure |

## ۱.۲ تگ‌های معرفتی (هر عدد باید تگ + منبع داشته باشد)
- **[FACT]** = از اجرای واقعیِ کد، تکرارپذیر، با منبع.
- **[EST]** = حدس/تقریب؛ صادقانه گفته شود «مطمئن نیستم».
- **[RUN] / [SPEC] / [MAP]** = وضعیتِ اشیای هندسی (اجراشده / قابل‌کامپایل / فقط نقشه).

## ۱.۳ دیسیپلینِ عدم‌اغراق
- اعدادِ `demo/mock_experiments.py` **سنتتیک**‌اند؛ هرگز به‌عنوان نتیجه گزارش نمی‌شوند.
  هدرِ اجرا `[SYNTHETIC/mock scores]` در برابر `[REAL run — …]`. registryِ واقعیِ
  خرابْ **خطای سخت** می‌دهد، نه fallbackِ بی‌صدا به mock.
- **LLM هستهٔ مغز نیست، ماژولِ قابل‌تعویض است.** هیچ نتیجهٔ C0–C3 به C4 تعمیم داده نمی‌شود.
- **آتش‌بندِ C0⇏C4**: هیچ ادعای آگاهیِ پدیداری/qualia/sentience. (خطِ سرخِ کدشدهٔ بدن هم همین است.)

## ۱.۴ دیسیپلینِ اجرا (روش‌شناسی)
- **pilot → freeze → confirmatory**: پارامترها روی خانوادهٔ seedِ pilot فریز، بعد اجرای
  تأییدی روی خانوادهٔ seedِ **مجزا** (991000 / 993000 / 994000 / 996000 / 997000 / 998000).
- **بازبینیِ خصمانه هر دور**: ۳ لنز (صحتِ کد / متدولوژی / وفاداری‌به‌منبع) × verify؛ هر
  یافتهٔ تأییدشده **قبل از بستنِ verdict** اعمال می‌شود.
- هر تعهدِ معماری = یک **ADR**؛ `decision_rule` همان GO/NO-GO است.

## ۱.۵ دکترینِ مالک (قانون مرکزی — ADR-007)
> «مغز اختاپوسِ ماها با هم به آگاهی برسند؛ خلق و نجات AGI اولویت اول؛ نشکن.»

سه گیت روی هر قدم: **AGI / اقتصاد / اخلاق**. **firewall (نشکن):** اقتصاد صفِ
آزمایش‌ها را جابه‌جا می‌کند، **هرگز verdict را خم نمی‌کند**. «آگاهی» عملیاتی خوانده
می‌شود (C1–C3: خود-پیش‌بینی، انتزاعِ قابل‌انتقال، تصمیمِ OOD)، نه پدیداری. پارامترهای
مالی [EST]-planاند؛ هیچ خرید/فروش/حسابی خودکار انجام نمی‌شود.

## ۱.۶ دکترینِ اتصال به بدن (ADR-008 — یادگرفته از F:\backup)
- کرنل = **اندامِ شناختیِ Ring-2** (نه Ring 0/1)؛ sibling/brain، نه tenant.
- **afferent broadband (خواندن) / efferent فقط propose-only.** Risk Ladder = **سبز**
  (خواندن/گزارش/فایل‌نو). اتصالِ زنده = اقدامِ **نارنجی** = verdictِ تلگرامیِ مالک.
- **هرگز**: نوشتن به بدن، لمسِ TCB/genome/pulse (لنگرِ هویت 0.135073)، ساختِ حساب/راز.
- **improve-not-rewrite**: فقط افزایشی؛ بدن دست‌نخورده.
- خواندنِ بدن فقط با `sqlite file:...?mode=ro&immutable=1`.

# بخش ۲ — تئوری

## ۲.۱ ایدهٔ مرکزیِ کرنل
مغزِ مصنوعی را از **بلوک‌های پایه** می‌سازیم (حافظهٔ کاری، انتزاع، خودمدل، هومیواستاز،
تثبیت)، نه با شعار بلکه با **میکروآزمایش‌های ابطال‌پذیر**. هر بلوک باید نسبت به baseline
آزمون‌پذیر باشد و هزینه/محدودیتش روشن باشد. LLM ماژولِ قابل‌تعویض است، نه هسته.

## ۲.۲ اصلِ ۷ (لنگرِ نظری) و هندسی‌سازی‌اش
اصلِ ۷ پیکرهٔ خام: **«انتزاع وقتی پایدار است که در پیش‌بینی، فشرده‌سازی و انتقال مفید
باشد.»** این سه، سه محورِ یک **فضای کیفیت انتزاع** می‌شوند (تحققِ `axis_coordinates`).
`GEOMETRY.md` هر ریاضیِ خام را به یک شیء هندسی نگاشت می‌کند:

| ایدهٔ خام | شیء هندسی | وضعیت |
|---|---|---|
| اصل ۷ | فضای کیفیت انتزاعِ ۳-محوره | **[RUN]** |
| RSA/CKA, D_causal | `RTA(φ)` = نرخِ اصابتِ انتقال (⚠️ **RSA نیست**، فقط هم‌خانواده) | **[RUN]** |
| D_t هومیواستاز | منظرِ پتانسیلِ انرژی روی حالتِ درونی | **[SPEC→RUN]** |
| اصل ۸ (index چندگانه) | فضای چند‌متریکِ حافظه | [SPEC] |
| Kan extension `U_𝒟∘F≅U_𝒞` | بلندکردنِ هدف = مثلثِ جابه‌جاشونده | [MAP] |
| نردبان C0–C4 × A0–A4 | مشبکهٔ ترتیبیِ دوبعدی | [MAP] |
| زنجیرهٔ نابرابری | برجِ تصویرِ غیراینجکتیو (رفتار⊋بازنمایی⊋علیت⊋پدیدار) | [MAP] |

## ۲.۳ چهار مکانیزمِ اثبات‌شده (که در hybrid ترکیب شدند)
1. **تنگنای WM + gating (H-OWN-03):** ظرفیتِ محدود + انتخابِ یادگرفته‌شده، عامل را
   وادار به کشفِ زیرمجموعهٔ رابطه‌ایِ قابل‌انتقال می‌کند.
2. **هندسهٔ RTA (H-GEO-01):** هم‌ترازیِ انتقال‌محورِ بازنمایی با کنشِ بهینه، transfer
   را پیش‌بینی می‌کند (نه فشرده‌سازیِ خام).
3. **خودمدلِ پیش‌بین/MPC (EXP-003):** کنترلِ مدل‌محور تحتِ اختلالِ OOD از کنترلِ
   واکنشیِ myopic بهتر تنظیم می‌کند.
4. **تثبیت = library learning (H-OWN-04):** تبدیلِ تجربه به کتابخانهٔ schema، Q را
   denoise و بهتر منتقل می‌کند تا replayِ خام.

## ۲.۴ درسِ روش‌شناختی (چرا این پروژه قابل‌اعتماد است)
بارها بازبینیِ خصمانه یک اثرِ به‌ظاهر‌قوی را به یک artifact تقلیل داد و **قبل از گزارش**
اصلاح شد: confoundِ ری‌استارتِ اکتشاف (ADR-006، +0.077→+0.010)، عدمِ‌تطابقِ sim/executor
در MPC (ADR-005)، برچسبِ غلطِ «RSA» (ADR-003)، و گیتِ تریویال + baselineِ پوشالی
(ADR-008، از INTEGRATEِ متورم به OPTIMIZEِ صادقانه). این «شکست‌های صادقانه» ارزشِ
اصلیِ پروژه‌اند.

## ۳.۳ نکاتِ کلیدیِ هر verdict
- **H-OWN-03 REJECTED ولی مکانیزم واقعی**: 0.520<0.67، اما +0.250 بر نامحدود، +0.239 بر
  کنترلِ oracle → فشارِ ظرفیت+gating واقعی است؛ آستانهٔ مطلق (mock) خیلی بالا بود. v2
  نسبی همین را به OPTIMIZE برد.
- **Drake**: نسخهٔ فیزیکیِ مولتی‌ورس عمداً از گیتِ falsifiability رد شد؛ نسخهٔ سیم‌شده
  (تنها مولتی‌ورسِ دارای کانالِ مشاهده) قابل‌اجرا و OPTIMIZE.
- **RTA**: فشرده‌سازیِ خام transfer را پیش‌بینی نمی‌کند (ρ 0.009)، هم‌ترازیِ کنش‌محور می‌کند
  (ρ 0.662).
- **hybrid روی بدن**: کرنل رفتارِ ارگانیسم را با 0.946 پیش‌بینی می‌کند، ولی این عمدتاً
  تریویال‌بودنِ استریمِ ۹-فازی است؛ کمیتِ واقعیِ ابطال‌پذیر مزیتِ تنگنا (+0.036) است → OPTIMIZE.
