⚠️ مرحله ۰: حل مشکل CORS (الزامی)

  1. مطمئن شو Python 3 نصبه: در ترمینال python --version یا python3 --version
  2. فایل cors_proxy.py در همین فولدر هست. در ترمینال (cmd / PowerShell) برو به این فولدر و اجرا کن:
    python cors_proxy.py
  3. پیغام «Listening on http://localhost:8787» باید ظاهر بشه — این پنجره را باز نگهدار
  4. در صفحه، فیلد «API Base URL» باید http://localhost:8787/v1 باشد (پیش‌فرض)

مرحله ۱-۴: استفاده

  1. Access Token را از cryptoquant.com/pro/settings/api بگیر
  2. بازه زمانی را انتخاب کن (۹۰ روز پیش‌فرض)
  3. «شروع دریافت» را بزن — همه ~۶۰ نوع endpoint × ۲۱ کوین خودکار اجرا می‌شوند
  4. endpoint های خارج از پلن خودکار رد می‌شوند (403 → unavailable در chip بالا)
درباره تعداد endpoint:
• فعلاً ~۶۰ template تعریف شده که با ۲۱ کوین می‌شه ~۳۰۰-۴۰۰ درخواست
• CryptoQuant بیشتر از این هم endpoint داره (per-exchange، entity-specific، windows غیر روزانه)
• چیزایی مثل Bank/Fund/ETF/Inter-entity در پلن Personal معمولاً ۴۰۳ می‌دن — Pro نیاز هست
• اگه ۴۰۳ گرفتی، یعنی پلنت اون رو نداره (مستقل از کد ماست)
