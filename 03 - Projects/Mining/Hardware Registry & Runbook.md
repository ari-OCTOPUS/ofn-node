> رقمِ «۶» مربوط به دورهٔ Hcash بود و بازنشسته است ([[03 - Projects/Mining/DecisionLog|D-008]]).

## ۳. Runbook عملیات از راه دور

1. **اتصال:** Tailscale mesh → SSH با کلید (نه پسورد) `[Unverified — بعد از rotation ست شود]`.
2. **سلامت:** `uptime`، دمای SoC، هش‌ریتِ فعلی → گزارشِ روزانه به تاپیکِ ⛏ تلگرام.
3. **توقف اضطراری:** فایل STOP / فلگ DB (kill-switch واحد D-06) → همه ماینرها down.
4. **قاعده AI (D-20):** ایجنت **هرگز** SSH مستقیم نمی‌زند — تغییرات فقط از مسیرِ repo + deploy gate با verdict.
5. **برق:** اگر هزینه > $0.05/kWh و خورشیدی نیست → HALT ساختاری. **وضعیتِ فعلی: خورشیدی → پاس.**
6. **کیف پول (D-11):** ایجنت هیچ‌وقت seed/private key نمی‌بیند. هر خرید/فروش/برداشت = HARD_STOP انسانی (D-10).
