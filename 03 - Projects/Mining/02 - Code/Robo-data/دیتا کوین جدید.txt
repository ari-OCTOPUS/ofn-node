## ⚙️ تنظیمات پیشنهادی Orange Pi 5

### برای YescryptR32 (LuckyPepe):
```bash
# cpuminer-opt with NEON
./cpuminer -a yescryptR32 \
  -o stratum+tcp://pool.luckypepe.net:3333 \
  -u <wallet> \
  -t 4  # فقط 4 هسته A76
```

### برای RandomX (LMonetae, CoinCync):
```bash
# XMRig
./xmrig -o pool.lmonetae.net:3333 \
  -u <wallet> \
  -a rx/0 \
  --threads=4 \
  --huge-pages
```

### برای HooHash (PEPEPOW, Hoosat):
```bash
# نصب Hoodroid APK روی Android device
# یا hoo_cpu miner روی Linux ARM
```

### 🛠️ بهینه‌سازی سخت‌افزاری: چرا فقط هسته‌های A76؟

در پردازنده RK3588، ما با یک معماری **big.LITTLE** روبرو هستیم. دلیل تأکید شما بر استفاده از هسته‌های Cortex-A76 (هسته‌های بزرگ) در تنظیمات XMRig و cpuminer کاملاً درست است.

* **هسته‌های A76:** دارای خط لوله (Pipeline) عریض‌تر و قدرت محاسبه ممیز شناور بسیار بالاتری هستند که برای الگوریتم‌های سنگین مثل RandomX حیاتی است.
* **هسته‌های A55:** این هسته‌ها حافظه L2 بسیار محدودی دارند. اگر الگوریتم RandomX را روی آن‌ها اجرا کنید، به دلیل کمبود Cache، کل سیستم دچار گلوگاه (Bottleneck) شده و کارایی هسته‌های بزرگ را هم پایین می‌آورند.

> **نکته حرفه‌ای:** برای الگوریتم‌های سبک‌تر مثل **YescryptR32 (LuckyPepe)**، می‌توانید هسته‌های A55 را هم با ۵۰٪ توان درگیر کنید، چون این الگوریتم بیشتر به پهنای باند حافظه حساس است تا Cache سنگین.

### ⚠️ فیلتر واقعیت (Candor Check)

باید با هم روراست باشیم؛ استراتژی انباشت حداکثری یک **بازی آماری** است.

1. **ریسک تورم:** کوینی مثل LPEPE که عرضه بی‌نهایت دارد، ذاتاً برای افت قیمت طراحی شده است. هدف شما باید استخراج و تبدیل سریع بخشی از آن به BTC یا USDC (طبق قانون ۲۰/۸۰ در فایل استراتژی) باشد.
2. **دمای عملیاتی:** Orange Pi 5 زیر بار ۱۰۰٪ روی هسته‌های A76 به شدت گرم می‌شود. برای حفظ **تداوم ۵ ساله**، حتماً اطمینان حاصل کنید که دما بالای **۶۵°C** نرود، در غیر این صورت پردازنده دچار Throttling شده و تعداد کوین‌های دریافتی افت می‌کند.
