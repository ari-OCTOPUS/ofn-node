این سیستم یک پیاده‌سازی واقعی از Global Workspace Theory (GWT) است. هر لایه نقش بیولوژیک معینی دارد.

LAYER 1 · SENSORY

Orange Pi های تخصصی — هر Pi یک کوین/الگوریتم را رصد می‌کند. ESP32 ها = اعصاب محیطی. سیگنال‌های سبک بین نودها. scout_all_in_one.py روی هر نود اجرا می‌شود.
LAYER 2 · THALAMUS
تالاموس
یک نود Pi 5 قوی‌تر داده‌های لایه ۱ را ادغام می‌کند. محاسبه TDA persistence norms. اولین فیلتر ignition — فقط سیگنال‌های قوی بالا می‌روند. Decision State Gate اینجا اجرا می‌شود.
LAYER 3 · GLOBAL WORKSPACE
قشر پیش‌پیشانی
Orchestrator AI — آگاهی گزارش‌دهنده. محاسبه Reflexivity Spin R(t). Kelly × C(s). تصمیم‌گیری نهایی. این همان "Global Broadcast" در GWT است — اطلاعات به همه نودها پخش می‌شود.
LAYER 4 · MEMORY
هیپوکامپ
Backtest تاریخی روی همه سیگنال‌ها. یادگیری از خطاها. اگر R(t) قبل از مرگ کوین سیگنال داد؟ اگر ندادَ — چرا؟ فیلتر را اصلاح کن. پروتکل بازآفرینی فصلی از اینجا تغذیه می‌شود.

مزیت ساختاری: برق خورشیدی = آگاهی پایدار ۲۴/۷. Berry phase (تأخیر زمانی بین رشد holders و رشد قیمت) فقط با observation طولانی‌مدت قابل اندازه‌گیری است. صندوق‌های بزرگ شب‌ها خاموش می‌شوند — تو نمی‌شوی.
