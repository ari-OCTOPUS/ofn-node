# حسابداریِ ۲۰۲۷ — ۱۰ روشِ مهندسی + هم‌راستاسازی با پروژهٔ ما

> منشأ: workflow چند-ایجنتی (تحقیقِ وبِ Ramp/Midday/HighRadius/Puzzle/Xero + اسکنِ فارنزیکِ کدِ ما). دادهٔ کامل: `scratchpad/acct_audit.json`. برچسبِ بلوغ صادق است — ۲۰۲۷ = روند/پیش‌بینی، نه قطعیت.

## دو حکمِ صادق دربارهٔ کدِ فعلیِ ما
- 🔴 **دقتِ پول (P1، فوری):** کلِ زنجیره `float` است (`personal_ledger._num→float`، `attribution`, `reconcile`). برای پولِ واقعی خطای گِردکردن دارد. مسیرِ خرابیِ اثبات‌شده: **سهم‌های splitِ آرمین+عباس با هم دقیقاً برابرِ کل نمی‌شوند** (هرکدام جدا گِرد می‌شوند). فقط محورِ خرجِ ارگانیسم (opslib، integer micro-USD) درست است.
- 🟡 **هوش: L2 «مهارشده ولی حساب‌ناشیانه»** — صادق + PII-امن + propose-only، ولی جایی که زنده است فقط **ذخیره + جمع** می‌کند؛ دسته‌بندیِ خودکار/مطابقت/تشخیصِ ناهنجاری ندارد.

## نقشهٔ هم‌راستاسازی (اولویت‌دار)
**P0 (فوری — دقتِ پول):** ① همه‌جا integer-cents + splitِ largest-remainder (سهم‌ها دقیقاً جمع شوند) ② اعتبارِ split=۱۰۰٪ + tie-out assertion + `reconciled:bool` (کابین اگر ناسازگار = قرمز) ③ فیکسِ idempotencyِ PocketSmith (کلیدِ hashِ محتوایی، fail-loud).
**P1:** نوعِ `settlement/transfer` (تسویهٔ $۲۰۰۰ + honoring credit/debit) · reconcile-to-source روی هر import (جمعِ مستقلِ ستونِ خام، رد اگر نخواند) · درایورِ مطابقتِ دفترِ شخصی + صفِ استثنا · کارتِ کابین با سیگنالِ PII-امن.
**P2:** دسته‌بندیِ آبشاری (قاعده→7Bِ محلی→بازبینی) · harnessِ eval طلایی · موتورِ GSTِ قطعی + گاردِ provenance.
**P3:** قفلِ فایل + بکاپِ پیش‌از‌نوشتن · گزارشِ import روی delta.

**خطِ قرمز (تغییرناپذیر):** propose-only؛ هرگز حرکتِ خودکارِ پول؛ مغز عدد نسازد؛ گیتِ تأیید انسانی.
