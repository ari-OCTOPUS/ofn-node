# 🎨 راه‌اندازیِ گرافِ والت — نسخهٔ آماده (کپی، بدونِ تغییر در والت)

این یک **کپیِ جدا** است. تا وقتی خودت نخواهی، **هیچ چیزی در والتت عوض نمی‌شود**.

از روی فایل‌های ساختاریِ Crypto-eToro که فرستادی، ساختارِ اکوسیستمت را فهمیدم — مغزِ مادر «langar» زیرِ **Architect**، لِگ‌های تنant‌ (**Crypto / Mining / Accounting**)، پوشهٔ **Projects** و **Knowledge** — و رنگ‌بندی را بر همان اساس ساختم. فقط برای فهمِ ساختار؛ به منطقِ معاملاتی/verdictها کاری ندارم.

---

## 📦 فایل‌ها
- `graph.json` — تنظیماتِ آمادهٔ Global Graph (سبک‌شده برای والتِ سنگین + رنگ‌بندیِ نواحی).
- همین راهنما.

---

## ⚙️ چطور اعمالش کنم (۲ دقیقه، کاملاً برگشت‌پذیر)

1. Obsidian را **ببند** (مهم — وگرنه موقعِ بسته‌شدن تنظیماتِ فعلی را روی فایل بازمی‌نویسد).
2. در والتت به پوشهٔ `.obsidian` برو. از `graph.json`ِ فعلی یک **پشتیبان** بگیر: اسمش را بگذار `graph.json.bak`.
3. فایلِ `graph.json`ِ این پوشه را همان‌جا کپی کن (جایگزینِ قبلی).
4. Obsidian را باز کن → Graph View. نواحی باید رنگی شوند و گراف بازتر و سبک‌تر باشد.

> **برگشت:** اگر نپسندیدی، `graph.json.bak` را دوباره اسمش را `graph.json` کن. تمام — انگار هیچ اتفاقی نیفتاده.

## 🔍 قبل از اعمال، این را بدان
چون فقط فایل‌های Crypto را دیدم، اسمِ دقیقِ همهٔ نواحیِ سطح‌بالای والتت (۰۰ تا ۰۹) را نمی‌دانم. بعد از باز کردن، اگر ناحیه‌ای بی‌رنگ ماند، فقط یک خط در `colorGroups` کپی کن و token را عوض کن. مثال برای یک ناحیهٔ جدید:

```json
{ "query": "path:Health", "color": { "a": 1, "rgb": 3900150 } }
```

(هر عددِ `rgb` یک رنگ است؛ می‌توانی از رنگ‌های همین فایل قرض بگیری.)

## 🧭 بعد از رنگ‌بندی — برای والتِ سنگین

- **ناوبری با Local Graph:** به‌جای Global، از Local Graph استفاده کن و depth را روی **۲** بگذار. روی والتِ بزرگ خیلی روان‌تر است.
- **مدیا را کنار بگذار:** `Settings → Files and links → Excluded files` → پوشهٔ عکس/ضمیمهٔ حجیم (مثل `data/` یا `archive/`) را اضافه کن تا اپ سبک‌تر شود.
- **نمای سه‌بعدی:** `Settings → Community plugins → Browse` → «3D Graph» (نویسنده: Apoo711) → Install → Enable. بعد در تنظیماتش یک فیلترِ محدود به یک ناحیه بگذار (مثلاً فقط `path:Crypto`) تا روی والتِ بزرگ فریز نکند (سه‌بعدی مصرفِ GPU بالایی دارد).

## 🛠️ آنچه داخلِ graph.json برایت تنظیم شده
- **Attachments خاموش** → ۱۰GB عکس/PDF دیگر نود نمی‌شود.
- **Orphans خاموش** → شلوغیِ یادداشت‌های بی‌لینک کم می‌شود.
- **نیروها ملایم** (linkDistance بلندتر، repel بیشتر) → گراف بازتر و خواناتر.
- **محوِ متن موقع zoom-out** → وقتی عقب می‌کشی تمیز می‌ماند، وقتی نزدیک می‌شوی اسم‌ها پیدا می‌شوند.
