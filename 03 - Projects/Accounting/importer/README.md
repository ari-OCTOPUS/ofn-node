# ANZ CSV Importer (draft-only)

Importer که export بانک ANZ را می‌خواند و **پیش‌نویسِ** دفتر می‌سازد — با GST درست، dedup، دسته‌بندی، پرچم انطباق و مغایرت‌گیری. طبق [[ARCHITECT_CHARTER]] هیچ‌چیز بدون **verdict انسانی** نهایی نمی‌شود؛ خروجی فقط draft است. هیچ secret/شبکه‌ای درکار نیست.

## فایل‌ها
- `anz-import.js` — منطق + اجرا (`node anz-import.js <export.csv>`)
- `config.js` — قواعد قابل‌ویرایش (حساب‌های بیزنس، Associates، نگاشت فروشنده، آستانه‌ها)
- `anz-import.test.js` — تست منطق خالص (`node anz-import.test.js`) — **۱۳/۱۳ سبز**

## چه می‌کند
1. **dedup** روی ستون `ID` بانک → import مکرر رکورد تکراری نمی‌سازد.
2. **GST درست**: مبلغِ GST-inclusive ⟵ `gst = total/11` (نه `*0.10`)؛ خارجی/بهره/حقوق ⟵ `0`.
3. **دسته‌بندی draft** + جداسازی business/personal + امتیاز اطمینان (کم‌اطمینان‌ها → صف بازبینی).
4. **پرچم انطباق**: Div 7A (پرداخت به associate)، پرداخت بیزنس بدون ABN (>$75)، تراکنش ≥ $10k.
5. **مغایرت‌گیری** با `Closing Balance` → خطای دسته‌بندی/OCR را قبل از BAS می‌گیرد.

خروجی: `importer/out/draft-<date>.json` (+ جدول `bank_import` برای dedup). جدول `business_transactions` **دست‌نخورده** می‌ماند تا verdict.
