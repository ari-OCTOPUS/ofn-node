# ۳۰ کلیپ FACELESS — آماده‌ی فیلم‌برداری
### بانک شات‌ریدی برای TikTok / Reels / Shorts · feet-only · SFW · مکمل Trends 2027

> هر کلیپ = یک کارت آماده. با موبایل + نور پنجره قابل ساخت است. همه **بدون چهره، بدون بدن، فقط پا**.
> هدف: reach رایگان → link-hub (age gate) → OF/FeetFinder.

---

## ⚙️ قوانین قبل از ضبط (۶۰ ثانیه بخوان)

1. **SFW بمان:** روی TikTok/IG محتوا باید مثل پیج **nail-art / ASMR / beauty** به‌نظر برسد — aesthetic و care-focused، نه sexualized. نسخه‌ی «spicy» فقط داخل OF. (این مرز = هم ضدِ ban، هم حفظ آبرو.)
2. **هرگز لینک مستقیم OF در bio تیک‌تاک/اینستا نگذار** → فقط **link-hub با تأیید ۱۸+**.
3. **قانون ۳ ثانیه:** بدون چهره، ۳ ثانیه‌ی اول باید با **حرکت / تکسچر / متن** فوراً قلاب بزند وگرنه اسکرول می‌شوند.
4. **طول:** ۱۵–۳۰ ثانیه برای satisfying/aesthetic · تا ۴۵ ثانیه برای routine/GRWM.
5. **صدا:** یک **trending sound** روی کلیپ بگذار (share تا +۵۲٪). برای ASMR، صدای طبیعی خودت + موزیک ملایم زیرش.
6. **Cross-post:** همان فایل را **بدون watermark تیک‌تاک** روی Reels + Shorts هم بگذار (۳× reach، یک تولید).
7. **Privacy:** قبل آپلود، **EXIF strip + watermark ملایم** + چک reflection/لندمارک/بسته‌ی پستی.

**راهنمای ستون‌ها:** Hook = ۳ ثانیه‌ی اول · Shot = چه فیلم بگیری · Overlay = متن روی ویدئو (EN) · Sound = نوع صدا · Len = طول.

## 🎬 پلن Batch (۳۰ کلیپ در ۲ جلسه)

**جلسه ۱ (۹۰ دق):** کلیپ‌های A + B + C + G که به pedicure/ASMR/routine نیاز دارند → یک بار لاک بزن، همه‌ی close-upها و routineها را پشت‌سرهم بگیر.
**جلسه ۲ (۶۰ دق):** D + E + F (counter-seasonal/POV/trend) → صحنه‌های cozy و آفتابی.
**بعد از ضبط:** cull → edit سبک → watermark → strip EXIF → tag در **Fable5 DB2 (Content Assets)** → schedule در **DB3**.

## 📅 ریتم انتشار
- **۱–۲ کلیپ/روز** روی TikTok، همان را روی Reels + Shorts. (consistency > volume؛ ۳۰ کلیپ = ~۳ هفته مهمات.)
- هفته‌ای ۱ بار: صدای ترندِ روز را روی ۲–۳ شات آماده بگذار (کلیپ‌های E).
- هر کلیپ را در **Experiment Log (DB7)** رهگیری کن: view / watch-time / کلیک به bio. برنده‌ها را دوباره با واریاسیون بساز.
