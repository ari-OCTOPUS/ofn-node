# TELEGRAM · CONTENT STUDIO — سطحِ مسئولِ تولیدِ محتوا (Project-F)

> یک سطحِ تلگرامِ **جدا و ایزوله** برای تولیدکنندهٔ محتوا (صبا). **workflow-محور:** فقط متادیتای جریانِ کار را حمل می‌کند — هرگز رسانه/هویت. جدا از سطحِ آری. داخلِ پوشهٔ Project-F می‌ماند (صفر echo بیرون).

## ۱. اصل و جدایی
- **دو نقش، دو سطح:** آری = ops/تأیید/پول (P3-UX-v2). صبا = تولید/ثبتِ درفت (این سند). صبا هرگز پول/ops نمی‌بیند؛ آری فقط تأییدها را می‌بیند، نه جریانِ خصوصیِ تولید.
- **بات/توکنِ جدا** (allowlist = chat_idِ صبا) — پیشنهاد: بات جداگانه برای جداییِ کامل.
- **قواعدِ قفل‌شدهٔ منشور حاکم‌اند:** فقط‌پا · faceless · بدون explicit · ۱۸+ و رضایتِ ثبت‌شده · پرداخت فقط درون‌پلتفرم · privacy دوطرفه · geo-block ایران · صفر echo هویت/محتوا بیرونِ این پوشه.

## ۲. سطحِ کاربری (سبکِ غنی، HTML)
**منوی اصلی:**
```
🎬 استودیوی محتوا — Project-F
[📋 بریف‌ها]  [📤 ثبتِ درفت]
[✅ وضعیت]   [🗓 تقویم]
[🔒 قواعد]   [✋ محدودهٔ من]
```
**📋 بریف (تسکِ محتوا):** تم/پراپ/تعداد/مهلت — همه در چارچوبِ faceless-feet و محدودهٔ صبا.
`[✅ قبول]  [💬 نیازِ گفت‌وگو]`
**📤 ثبتِ درفت:** صبا یک درفت را **ثبت** می‌کند = شناسه + self-cert چک‌لیست (`faceless ✅ · فقط‌پا ✅ · بدون explicit ✅ · ۱۸+/رضایت ✅`). **رسانهٔ خام از باتِ رد نمی‌شود** — در پلتفرم/محلی می‌ماند؛ بات فقط pointer/وضعیت.
```
📤 درفت ثبت شد · PF-DRAFT-20260709-001
self-cert: ✅✅✅✅ → صفِ تأییدِ آری
```
**✅ وضعیت:** هر درفت: `⏳ در انتظار · ✅ تأیید · ✏️ نیازِ تغییر` (از human-appendِ آری).
**🗓 تقویم:** اسلات‌های برنامه‌ریزی‌شده. **هیچ‌چیز خودکار publish نمی‌شود** — انتشار فقط بعد از تأیید، درون‌پلتفرم.
**🔒 قواعد:** چک‌لیستِ همیشگیِ قواعدِ قفل‌شده (بالا) — یادآورِ دائم.
**✋ محدودهٔ من:** صبا محدوده‌اش را تنظیم/به‌روز می‌کند. **محدوده حاکمِ مطلق است** و بر هر پلن مقدم. یک‌ضربه `⛔ این از خطِ من رد می‌شود` → همان آیتم فوراً halt.

## ۳. خطوطِ قرمز (در خودِ بات baked)
1. **بات فقط متادیتای workflow را حمل می‌کند** — هرگز رسانه/هویت بیرونِ Project-F. رسانه درون‌پلتفرم/محلی.
2. **هیچ انتشار بدونِ human-appendِ آری** (دوکلیده: صبا ثبت → آری تأیید → انتشارِ درون‌پلتفرم).
3. **بات هرگز دربارهٔ پرداخت مذاکره/صحبت نمی‌کند** — فقط درون‌پلتفرم.
4. **حاکمیتِ محدوده** + ۱۸+/رضایتِ ثبت‌شده + faceless-feet با self-cert در لحظهٔ ثبت.
5. **allowlistِ جدا** (chat_idِ صبا ≠ آری) · کدِ «Project-F» بیرونِ پوشه · صفر echo هویت/محتوا.
6. **geo-block ایران** · هیچ factِ جغرافیایی در حدِ شهر.
