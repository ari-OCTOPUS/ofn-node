# CH-17 · Watchdog Alerts

> **Channel type:** Stay-alive / alert aggregator
> **Status:** ✅ Implemented
> **Wave:** 2 (P1 channel)

---

## Purpose

Three responsibilities:
1. **Stay-alive monitor** — detect organism death (port 8771 stale)
2. **Alert aggregator** — parse governor-alerts.md + events.jsonl
3. **Health score (independent)** — cross-check against CH-07

---

## Alert Parsing

Parses `governor-alerts.md` blocks:

```markdown
## 2026-07-12T10:30:48 (metabolism)
- ⚠️ suspect_zero detected in cell X
- ⚠️ budget cap at 95%
```

Each block = one timestamp + source + list of warnings.

### Severity Inference

| Keywords | Severity |
|---|---|
| failed, error, crash, critical, blocked, throttled | critical |
| warn, downgraded, missing, stale | warning |
| (default) | info |

---

## Health Score (Watchdog)

Independent computation for cross-check with CH-07:

| Condition | Penalty | Status |
|---|---|---|
| State stale > 60 min | −25 | AMBER |
| Critical alerts ≥ 3 | −40 | RED |
| Critical alerts > 0 | −15 each | AMBER |
| STOP flags present | −30 | RED |

## Base Watchdog (`_ops/watchdog.py`)

- **Propose-only** — actual restart requires external PS1 script
