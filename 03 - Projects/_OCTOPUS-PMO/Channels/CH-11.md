# CH-11 · Tracer + Audit Dashboard

> **Channel type:** Agent telemetry / distributed tracing
> **Status:** ✅ Implemented
> **Wave:** 2 (P1 channel)

---

## Purpose

Content-free tracing of every significant function call across the organism:
- **Duration** — how long did it take?
- **Args fingerprint** — SHA-256 of arg *types* (not values)
- **Result hint** — return type name only
- **Status** — ok / error / timeout / blocked
- **Correlation** — trace_id + span_id + parent_span_id

No secrets. No PII. No business values. Pure telemetry.

## Public API

### Decorator
```python
from observability.tracer import trace

@trace(agent_id="analyst")
def analyze_batch(data):
    return result
```

### Context Manager
```python
from observability.tracer import trace_span

with trace_span("compute_frontier", agent_id="analyst") as span:
    result = heavy_work()
    span["result_hint"] = "dict"
```

---

## Content-Free Guarantee

| Field | What is logged | What is NOT logged |
|---|---|---|
| `args_hash` | SHA-256 of arg *type names* | arg values |
| `result_hint` | `type(result).__name__` | result value |
| `exc_hint` | exception class name | exception message / stack |
| `agent_id` | symbolic name | user identity |
| `operation` | function name | call arguments |

---

## Transport

1. **Primary:** `unified_bus.publish("TRACE", record)` — if bus available
2. **Fallback:** append to `_ops/state/traces.jsonl` — always written
3. **Rotation:** auto-backup when file > ~400 KB

## Audit Dashboard (extract_audit_data.py)

Aggregates four sources into `audit-data.js`:

| Source | Path | What |
|---|---|---|
| Events | `_ops/state/events.jsonl` | Structured events (last 300) |
| Traces | `_ops/state/traces.jsonl` | Trace spans (last 300) |
| Fallback ledger | `_ops/state/ledger-fallback.jsonl` | Audit fallback |
| Genome ledger | `07 - Knowledge/genome-system/ledger/ledger.jsonl` | Authoritative ledger |

### Transforms
- Freshness check (> 45 min = stale)
- Delta detection (SHA-256 digest comparison)
- Aggregation by agent, status, event name
- Span statistics (avg/max/p95 duration)
- Incident count, pending approvals

### Output
Consumed by `OCTOPUS/worlds/04-twin/index.html` (twin/audit world).
