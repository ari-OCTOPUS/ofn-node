# CH-16 · Neural Vitals

> **Channel type:** Neural stack telemetry
> **Status:** ✅ Implemented
> **Wave:** 2 (P1 channel)

---

## Purpose

Surface the internal state of the organism's "nervous system":
- **Circadian** — time-of-day readiness
- **Rhythm** — GREEN/AMBER/RED mode, stress, novelty
- **Hebbian** — signal association weights
- **Consolidation** — canonical memory cycles
- **Protective mode** — halt state override

### 1. Vitals Bar

| Field | Source | Note |
|---|---|---|

## Protective Mode Override

If `ORGANISM-STATE.json` has `protective_mode: true`:
- `mode_color` forced to `"RED"`
- Advisory: "توقفِ حفاظتی — فقط observation؛ ضربانِ قرمز"

This ensures the UI reflects halt state even if rhythm module is GREEN.
