### B.3 افق `[FACT]`
۷ روز تا شواهد اولیه / آزمایش.

### B.4 تعریف کشف `[FACT]`
`C+D+E`: رابطهٔ تازه بین واقعیت‌های شناخته‌شده + فرصت/تهدیدی که رقبا هنوز آشکارا استفاده نکرده‌اند + فرضیهٔ قابل آزمون.
خلاصه‌کردن یک مقاله = کشف نیست. ترکیب چند شاهد برای ساخت فرضیهٔ ابطال‌پذیر = می‌تواند کشف باشد.

### B.5 حداقل شاهد `[FACT]`
- پایه: **۲ منبع مستقل**.
- `INFERENCE`: برای ادعای رقابتی/مالی، شاهد بیرونی قابل مشاهده (deploy واقعی، pricing رسمی، changelog) لازم است تا confidence بالا برود.
- چند صفحه از یک شرکت چند منبع مستقل **نیست**. چند مقالهٔ ارجاع‌دهنده به یک press release **یک منبع** محسوب می‌شوند.
- snippet موتور جست‌وجو شاهد نهایی **نیست**.

### B.6 رقبای مرجع `[FACT]`
1. Anthropic — Claude / agent architecture / safety
2. xAI — Grok
3. Sakana AI — (ژاپن) رویکردهای تکاملی / multi-agent
4. Moonshot / Kimi K3 — context طویل
5. Perplexity — search-grounded agents

### B.7 تعریف رقابت `[FACT]`
همهٔ ابعاد با وزن متفاوت. فرمول مزیت نامتقارن:
```
مزیت رقیب × نقطه‌ضعف ساختاری او × مزیت محلی/شخصی اختاپوس = فرصت رقابتی اختاپوس
```

## G. stop conditions `[FACT]`

مأموریت فقط در یکی از این حالت‌ها تمام می‌شود:
1. `DISCOVERY_VALIDATED` — کشف مشخص، تازه یا رابطهٔ تازه، چندمنبعی، contradiction search، falsifier، تحلیل رقابتی، آزمایش کم‌خطر، direction link، بدون تخلف.
2. `NO_VALID_DISCOVERY` — جست‌وجوی کافی (و گسترده‌یافته) انجام شد؛ کاندیداها رد یا تکراری بودند؛ گزارش صادقانه وجود دارد.
3. `CONTESTED` — شواهد معتبر مخالف وجود دارد؛ آزمایش حل تناقض طراحی شده.
4. `BLOCKED_BY_OWNER` — قدم بعدی نیازمند ارسال/پول/حساب/تماس/تصمیم مالک است.
5. `IMPLEMENTED_NOT_INTEGRATED` — اندام و تست‌ها آماده‌اند؛ اتصال به runtime به‌علت ایجنت موازی یا owner gate انجام نشده.

هرگز فقط به‌خاطر ساخت فایل یا سبزشدن تست‌ها `DISCOVERY_VALIDATED` گفته نمی‌شود.
