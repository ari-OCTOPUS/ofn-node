# world_discovery_action — مرزِ «کشفِ دنیا» ↔ «پلِ اقدام»

> **وضعیت: `INTEGRATED_IN_SANDBOX`.** صفر صداکنندهٔ runtime، صفر فلگ، صفر
> ارسال، صفر خرج، صفر تغییرِ state زنده.

## چرا این پکیج سوم وجود دارد

دو اندام نباید هم را بشناسند. اگر `action_bridge` بداند `world_discovery` چه
شکلی است، یا برعکس، جدا مردنشان ناممکن می‌شود. پس تنها پکیجی که **هر دو** را
می‌شناسد این است، و جهتِ وابستگی یک‌طرفه و اثبات‌شده است:

```text
artifact ِ world_discovery  →  این مترجم  →  قراردادِ عمومیِ action_bridge
```

## قاعده‌ای که همه‌چیز حولِ آن است

**`NO_VALID_DISCOVERY` یک نتیجهٔ معتبر است** — نه شکستی که باید دورش زد. مرز
حق ندارد آن را به عمل، به `PASS`، یا به «تقریباً کشف» ترجمه کند. تنها استثنا
یک آزمایشِ **کاملاً اطلاعاتیِ A0** برای رفعِ کمبودِ شاهد است — و حتی آن هم کشف
را validated اعلام نمی‌کند.

## سطحِ اعلام‌شده باور نمی‌شود

`policy.infer_level()` سطحِ منبع را **کف** می‌گیرد نه سقف، و از رفتارِ واقعی
استنتاج می‌کند: فلگِ `external_effect`، هزینه، مقصد، قابلیت‌ها، و افعالِ
عملیاتی در **گام‌های** آزمایش.

```text
declared E0 + فلگِ بیرونی      → A4
declared E0 + فعلِ send در گام → A4
declared E1 + cost > 0         → A5
declared E2 + مقصدِ PRE-0      → A6
سطحِ ناشناخته                  → BLOCK
```

`source_component: "world_discovery"` صفر privilege می‌گیرد.

## تلگرام

فقط `draft` ِ pure-data. ماژول `telegram_draft` **هیچ مسیرِ ارسالی ندارد** —
نه فلگِ خاموش، بلکه راهی که ساخته نشده؛ و گاردش با **AST** سنجیده می‌شود نه
grep. راز و PII **قبل** از ساختِ متن حذف می‌شوند.

## نقشه

| فایل | نقش |
|---|---|
| `contracts.py` | اسکیمای رسیدِ ترجمه + وضعیت‌ها + `unwrap` دو-لایه |
| `validator.py` | اعتبارِ artifact + شمارشِ **مستقلِ** شاهد + redaction |
| `policy.py` | استنتاجِ سطحِ واقعی + تصمیمِ مرز (تنها مولدِ `NO_ACTION`) |
| `translator.py` | چهار تابعِ عمومیِ ترجمه |
| `telegram_draft.py` | متنِ کارت، بدونِ هیچ transport |
| `integration_receipt.py` | نوشتنِ اتمیک داخلِ namespace خودمان |
| `dry_run.py` | زنجیرهٔ کامل، بدونِ اثر |

## نکتهٔ مرزیِ ثبت‌شده

مانیفستِ GLM کلیدهای `experiment` و `opportunity` را مستند کرده ولی artifact
واقعی هیچ‌کدام را ندارد، و `asymmetry_hypotheses` در آن صفر است (چهار فرضیه در
گزارشِ انسانی‌اند). تناقض نیست — تفکیکِ گزارشِ انسانی از قراردادِ ماشین. ولی
مترجم شکلِ مستند را **فرض نمی‌کند**؛ هر کلید قبل از خواندن وجودش تأیید می‌شود.
