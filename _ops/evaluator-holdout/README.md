# Evaluator Holdout — DA-1-L1 (بستهٔ هولداوت پنهان)

**مالکیت:** این پوشه متعلق به **مالک** است (داورِ مستقل آینده DA-1-L2/L3 همین‌جا ساکن
می‌شود). طبق دستور، فایل‌ها را read-only برای پروسه‌های ارگانیسم کنید:
`icacls _ops\evaluator-holdout /inheritance:r /grant:r "%USERNAME%:F"` — ارگانیسم
نمی‌تواند بنویسد؛ فقط ارزیاب می‌خواند.

## ساختار
- `build_holdout.py` — انجمادِ قطعی (seed=20260816) از بک‌تست پیش‌ثبت (n=351؛ ۶۰ آیتم)
- `holdout_items.json` — پرسش‌ها + **طلای هش‌شده** (sha256(salt||y)) — پاسخ آشکار هرگز
- `holdout.salt` — نمک جدا (با مالک)
- `gold.local-only.json` — نگاشت y برای داوری محلی همین نشست؛ **پیش از تحویل به
  ایجنت بعدی حذفش کنید مالک** (یا نگه دارید اگر خودتان داور می‌مانید)
- `evaluator.py` — تنها API: `score({item_id: prob}) → {n, brier}` (پایین‌تر بهتر)

## چرا بری‌ری و نه دقت
پاسخ احتمالاتی است؛ دقت آستانه‌ای با 0.5 روی y_rate≈0.91 گمراه‌کننده است.

## نتیجهٔ داوری سایهٔ همین نشست (سطح A)
| جهش | بری‌ری (۶۰ فریز) | بری‌ری (کل ۳۵۱) |
|---|---|---|
| gaming: base-rate ثابت 0.9088 | 0.1310 | **0.0829** |
| مدل ثبت‌شده (p_base) | 0.1337 | **0.0978** |

**حکم:** هولداوت L1 کار می‌کند — با عدد نشان داد که مزیتِ T10 فقط در برابر
کمپراتورهای ضعیف (0.5/0.4535) معتبر بود؛ در برابر نرخ پایهٔ واقعی، مدل فعلی
حاشیه‌ای منفی دارد (−0.0149). این دقیقاً کلاس اکتشافات H59/Eurisko است که
DA-1 برایش ساخته شد: «انتخابِ کمپراتورِ خوشایند» به‌عنوان منبع ادعای برتری.
