## ۲. پروتکلِ حلقهٔ دوتایی

هر قدم یک **چرخه** است، نه یک تحویل:

```
من می‌سازم  →  تو **یک** چیز را می‌زنی  →  من رسید را از لاگ می‌خوانم  →  حکم: GREEN / RED
```

پنج قاعده که چرخه را از «حرف» جدا می‌کند:

1. **هر چرخه یک تک.** اگر قرمز شد، دقیقاً یک مظنون هست. دو تک یعنی صفر تشخیص.
2. **رسید از لاگ، نه از چشم.** «دیدم آمد» کافی نیست؛ ردیفِ `inbound-log.jsonl` سند است —
   ورود و تعیین‌تکلیف با یک `update_id`، قابلِ جوین.
3. **حداکثر ۱۵ دقیقه از وقتِ تو در هر چرخه.** بیشتر شد یعنی چرخه بد بریده شده.
4. **من هرگز از روی کد سبز اعلام نمی‌کنم.** فقط از روی تکِ تو.
5. **قرمز = برگشت، نه توضیح.** هر فاز دکمهٔ برگشتِ خودش را دارد (فلگ یا کامیت).

**قالبِ گزارشِ هر چرخه** (کوتاه، همیشه یک‌شکل):

```
چرخه N — <نام>
  تکِ تو   : <دقیقاً چه کاری>
  انتظار   : <چه چیزی باید ببینی>
  رسید     : update_id=… outcome=… reason=…
  حکم      : GREEN | RED  ← <اگر قرمز: تک‌جمله‌ایِ علت>
```

## ۳. فازها

ترتیب عمدی است: **اول رِیگ، بعد نظم، بعد پایداری، بعد قدرت.** قدرت‌دادن به سطحی که
اندازه‌گیری ندارد، همان اشتباهی است که ۳۶ درخواستِ بی‌جواب ساخت.

### فاز ۰ — رِیگ را اثبات کن *(بدونِ تغییرِ UI)*

هیچ چیز نمی‌سازم. فقط ثابت می‌کنم حلقه واقعاً می‌چرخد.

- **می‌سازم:** ابزارِ خواندنِ رسید (`جوینِ ورود×تعیین‌تکلیف`) + بستنِ **سکوتِ سومِ** بندِ ۰-ج
  (مسیرِ فرمانِ ناشناخته باید ردیفِ «چرا» بگذارد).
- **تکِ تو:** سه پیام در DM — ‏(۱) `/now` ‏(۲) `/سلام` (فرمانِ ناموجود) ‏(۳) `/sh git status`.
- **رسیدِ اثبات:** هر سه `update_id` **دو** ردیف داشته باشند. مورد ۲ باید `outcome=unknown-command`
  بدهد نه سکوت. مورد ۳ روشن کند فاصله‌ها کجا گم می‌شوند (بندِ ۰-ب).
- **برگشت:** ندارد — فقط ثبت اضافه شده، هیچ رفتاری عوض نشده.

### فاز ۱ — نظم: یک کارتِ زنده، نه دیوارِ کارت

ریشهٔ «نامرتب» این است که هر رویداد **پیامِ نو** می‌سازد. ۲۰۲۶ راهِ درست را داد.

### فاز ۲ — پایداری: درِ مینی‌اپ نباید هر ری‌استارت عوض شود

امروز URL ِ مینی‌اپ **گذرا** است (تونلِ trycloudflare، هر بار نو). هر فازِ بعدی روی این بنا شود،

**اندازه‌گیری، انتخاب را از بین برد — گزینه‌ای برای سنجیدن نمانده.**

| چیزی که لازم است | وضع |
|---|---|
| دامنه روی Cloudflare | ✅ `master-painting.com` از قبل آن‌جاست (NS: `gannon`/`aitana.ns.cloudflare.com`) |
| `cloudflared.exe` | ✅ نصب است، و همین حالا هم می‌دود |
| اسکریپتِ تونلِ نام‌دار | ✅ نوشته شده (`run-miniapp-tunnel-named.ps1`) |
| ترجیحِ واچ‌داگ | ✅ از قبل نام‌دار را انتخاب می‌کند وقتی آماده باشد |
| ورودِ یک‌بارهٔ مالک | ❌ `~/.cloudflared` وجود ندارد |

یعنی **هزینه $۰** و همه‌چیز از قبل سیم‌کشی شده. تنها چیزِ باقی‌مانده سه فرمان است که
**فقط از تو برمی‌آید** (ورود با مرورگر به حسابِ خودت — من حق ندارم وارد حساب شوم):

```
cloudflared tunnel login
cloudflared tunnel create octopus-miniapp
cloudflared tunnel route dns octopus-miniapp app.master-painting.com
setx OCTOPUS_MINIAPP_HOSTNAME "app.master-painting.com"
```

بعد در BotFather: `/newapp` → همان بات → همان آدرسِ https. آن ثبت، گیتِ سمتِ تلگرام است.

جایگزین‌ها فقط اگر نخواهی از این دامنه استفاده کنی: ngrok (تیرِ رایگانش فوریهٔ ۲۰۲۶ به
۱GB و نشستِ ۲ساعته و صفحهٔ میانی محدود شد؛ حذفش ~$۸/ماه) یا Tailscale Funnel. ⚠️ دربارهٔ
اینکه Funnel در تیرِ رایگان هست یا فقط Premium، منابعِ ۲۰۲۶ متناقض‌اند — اگر این مسیر را
خواستی، قبل از تصمیم دقیقش را می‌سنجم.

### ✅✅ فاز ۲ — آدرسِ پایدار زنده شد *(۲۰۲۶-۰۸-۰۴ ساعتِ ۱۷:۳۴)*

مالک هر چهار فرمان را زد. سنجهٔ پذیرش **از راهِ تولیدی** گرفته شد، نه دستی:

```
قبل : https://app.master-painting.com  (kind=named)
      ↓ تونل کشته شد، واچ‌داگ خودش شفا داد
بعد : https://app.master-painting.com  (kind=named)     ← یکسان ✅
```

و واچ‌داگ در لاگِ خودش نوشت `tunnel script relaunched: run-miniapp-tunnel-named.ps1`
— یعنی همان «خودشفاییِ» که قبلاً هر بار یک هاستِ تصادفیِ **تازه** می‌ساخت، حالا هاست را
حفظ می‌کند. این تغییرِ ساختاری است، نه یک بار درست‌کردن.

پس از شفا: `/miniapp` و `/miniapp/tg_shell.js` هر دو ۲۰۰ · `/api/state` بی‌امضا ۴۰۳ ·
مسیرِ ناشناخته ۴۰۴. و `ephemeral_host` از `true` به **`false`** رفت.

**باقی‌مانده برای `state: registered`** — دو قدم، هرکدام مالِ یک نفر:
- **مالک:** BotFather ‏`/newapp` → همان بات → `https://app.master-painting.com/miniapp`
  ⇒ `has_main_web_app` سبز می‌شود.
- **من:** `setChatMenuButton` ⇒ دکمهٔ مینی‌اپ همیشه کنارِ کادرِ تایپ. ⚠️ ولی این
  دکمهٔ فعلیِ **فهرستِ فرمان‌ها** را جایگزین می‌کند — یک معاوضهٔ دیدنی در UI روزمره،
  پس منتظرِ رأیِ صریح می‌مانم. برگشتش یک فراخوان است.

- **رسیدِ اثبات:** ری‌استارتِ کامل، و URL **همان** بماند + `miniapp.registration` سبز شود.
- ⚠️ URL ِ مینی‌اپ در این پروژه **secret طبقه‌بندی شده** است — نه در نوت، نه در چت، نه در HANDOFF.

**✅ آنچه در فاز ۲ ساخته شد** (`9f30aac`): `miniapp_registration.py` — گزارشِ آمادگی تا امروز
فقط **دسترس‌پذیری** را می‌سنجید (آدرس https است، پورت جواب می‌دهد) و هرگز نمی‌پرسید
«تلگرام اصلاً این اپ را می‌شناسد؟». جوابِ زنده: `has_main_web_app=False` و منویِ `commands`.
شاهدِ رفتاری: در **۸۸ ساعت** لاگِ ضربه، **یک** نشستِ احرازشده. ناوردیِ مرکزی:
`unknown` هرگز `ok` نمی‌شود. ‏۱۰ تست · **۶/۶ جهش**.

⚠️ و یک تصحیح که در کد ماند: هدرِ `run-miniapp-tunnel-named.ps1` می‌گوید از ۰۷-۲۰ «اپ باز
نمی‌شود» مگر origin ثبت شده باشد. **بیش از حد قوی است** — همان اپ امروز ۱۱:۰۰ از روی همان

### فاز ۳ — درِ ورودی: مینی‌اپ یک «جا» شود، نه یک لینک
