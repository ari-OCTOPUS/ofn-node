## ۶ · واقعیت‌های محیطی که غافلگیرت می‌کنند

- **جلسه‌های موازی روی همین درخت فعال‌اند.** جلسهٔ ۰۸-۰۳ دو بار غافلگیر شد: یک

  کامیت‌نشدهٔ خودش را داخلِ کامیتِ دیگری جا داد. **قبل از هر ویرایش `git status`
  و `git log` بزن.**
- **`_ops/OCTOPUS-flags.cmd` در gitignore است** ⇒ هر رأیِ مالک که به فلگ تبدیل
  شود **در هیچ کامیتی نیست**. رأی‌های غیرمحرمانه به `_ops/owner-verdicts.yaml`
  ِ tracked می‌روند. فایلِ `.cmd` **CRLF-حساس** است — با ابزارِ Edit ویرایشش نکن،
  در سطحِ بایت append کن (یک ویرایشِ متنی یک‌بار CRLF را کشت و مرکز با ۵۹ از ۱۵۶
  فلگ بالا آمد).
- **`.gitattributes` = `*.md merge=union`** ⇒ تصادمِ markdown conflict نمی‌دهد،
  **بلوکِ تکراری** می‌دهد. بعد از merge روی `HANDOFF.md` چشمی چک کن.
- **دو آنتی‌ویروسِ لحظه‌ای فعال‌اند.** اسکنِ بازگشتی این لپ‌تاپ را می‌خواباند
  (۹ دقیقه برای `du` روی ۵۲۰MB). هرگز `find`/`du` از ریشهٔ vault نزن.
- **`schtasks` از Bash بی‌صدا خالی برمی‌گردد** — از PowerShell و
  `Get-ScheduledTask` استفاده کن.
- **backtick در هر رشتهٔ bash جانشینی می‌شود** — متنِ بلندِ فارسی/کددار را با
  ابزارِ فایل بنویس، نه `echo`.
- **خروجیِ فارسی روی این کنسول cp1252 است** — `PYTHONIOENCODING=utf-8` بگذار
  وگرنه `UnicodeEncodeError` می‌گیری و ممکن است آن را با شکستِ تست اشتباه بگیری.

## ۷ · دام‌های سنجش — گران‌ترین بخشِ این سند

هر کدام یک‌بار واقعاً اتفاق افتاده:

| دام | چه شکلی است | پادزهر |
|---|---|---|
| **فیکی که تابعِ واقعی را دور می‌زند** | تست سبز، تولید fail-closed (باگِ `gate` ِ برشِ ۱، باگِ هدرِ برشِ ۳) | کلاسِ **واقعی** را بساز، نه فیک |
| **سبزِ دروغین** | تستِ pytest-style که مستقیم اجرا شود صفر assert می‌دود و سبز شمرده می‌شود | شمارِ صریحِ pass/fail + exit code |
| **جهشِ سبز** | جهش را اعمال کردی و هیچ تستی قرمز نشد ⇒ آن خط دیده‌نشده است | فیکسچرِ پایه باید **زیرِ** سطحِ هدف باشد |
| **لنگرِ جهشِ غیریکتا** | `replace(...,1)` به اولین وقوع می‌خورد که معمولاً تابعِ خواهر است | قبل از اعمال، وقوع‌ها را بشمار |
| **جهش با فایلِ dirty** | `git checkout --` کلِ فایل را برمی‌گرداند و رفعِ کامیت‌نشده‌ات را می‌کشد | **قبل از جهش کامیت کن** |
| **گاردِ بی‌دندان** | assert روی نوعِ خروجی به‌جای مقدار؛ یا سنجهٔ «۴۰۳ نیست» که یک ۵۰۰ ِ بلعیده هم از آن رد می‌شود | سنجه را به «واقعاً موفق شد» ببند |
| **نبودِ داده = حکم** | کلیدِ غایب خودش را «همه خاموش» جا می‌زند؛ گرپِ سقف‌خورده منفیِ کاذب می‌سازد | سه‌حالتی گزارش کن: ok / نه / **نمی‌دانم** |
| **ادعای بی‌نامِ نماد** | سند قابلیتی را اعلام می‌کند که صفر خوانندهٔ کد دارد | `git grep` بزن؛ صفر خواننده = گپ |
| **«انجام شد» = فلگ** | فلگ ست شد ≠ جهان عوض شد؛ `ok=true` یعنی «استثنا نداد» | اثر را در ظرفِ مقصد بسنج |
| **ری‌استارتِ بی‌اثر** | پایتون هات‌ریلود نمی‌کند؛ و launcherها نمونهٔ قبلی را نمی‌کشند | `RESTART-PROCESS.ps1` + **مقایسهٔ PID** |
| **ساعتِ دیوار در تست** | سوییتی که فقط روزها سبز است؛ UTC در نویسنده / محلی در خواننده | ساعت را پین/تزریق کن |
| **خواننده و نویسنده جدا سنجیده** | چهار مکانیزمِ «سبز در تست، گرسنه در تولید» از عدم‌تطابقِ شکلِ داده | round-trip از مسیرِ **تولیدی** |
