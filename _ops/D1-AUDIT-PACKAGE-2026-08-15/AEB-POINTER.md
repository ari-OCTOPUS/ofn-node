# AEB POINTER — بستهٔ شواهدِ زنده برای ممیزِ D1 (R19/R21، 2026-08-16)

حسابرسی روی سندِ نثری **ممنوع** (درسِ شورای اول: بریفینگِ کهنه = رأیِ نادرست).
ممیزِ بیرونی باید از این‌جا شروع کند:

- **تولیدکننده:** `_ops/audit/generate_aeb.py` (فقط-خواندن؛ هر فکت با
  `observed_at` + TTL + نردبانِ وضعیت)
- **باندل‌ها:** `_ops/audit/bundles/AEB-<timestamp>.json` + `.txt` (نسخهٔ
  امضاشدنی با Ed25519 مالک — همان کلیدِ این بسته)
- **نردبان وضعیت:** declared → implemented → tested → deployed → drilled →
  independently reproduced — هر ادعای سرخطِ باندل برچسبِ نردبان دارد.

## وضعیت ممیزی
- این بستهٔ D1 همچنان **NOT_STARTED** است — انتخاب/دعوتِ ممیزِ بیرونی فقط
  با مالک (R21).
- قاعدهٔ تازگی: باندلِ جدیدِ AEB باید در **۲۴ ساعتِ قبل از شروعِ ممیزی**
  بازتولید شود (حقایقِ فرّار TTL دارند)؛ ممیز خروجیِ خام را خودش دوباره
  اجرا کند (RUN-AUDIT.ps1 همین است).
- تغییرِ TCB/ارزیاب/زمان‌بند/PEP/حافظه ⇒ باندلِ نو + ممیزیِ مجدد الزامی.
