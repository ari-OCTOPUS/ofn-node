## سه سیم‌کشیِ باقی‌مانده — هر کدام یک خط

### ۱) ثبتِ تست‌های نو در سوئیت


### ۲) snapshotِ فلگ‌ها سرِ boot — بدونِ این، پروب معنا ندارد
در همان جایی که پروسه بالا می‌آید (اولِ `organism.py` / `center.py`)، یک‌بار:
```python
try:
    import flag_drift as _fd
    _fd.snapshot(_OPS / "OCTOPUS-flags.cmd", _OPS / "state" / "flags-loaded.json")
except Exception:  # noqa: BLE001 — هرگز boot را نمی‌کشد
    pass
```
پروب عمداً بدونِ snapshot `status="no_snapshot"` برمی‌گرداند و **هرگز سبز
اعلام نمی‌کند** — یعنی نبودِ سیم‌کشی خودش قابلِ مشاهده است.

### ۳) دو فرمانِ فقط‌خواندنی در `center.py`
در دیکشنریِ `handlers` داخلِ `_handle_message`:
```python
    "/flags": lambda: _flags_text(),
    "/trace": lambda: _trace_text(text),
```
و دو هلپرِ کوتاه:
```python
def _flags_text(self):
    try:
        import flag_drift as fd
        return fd.render(fd.probe(_OPS / "OCTOPUS-flags.cmd",
                                  _OPS / "state" / "flags-loaded.json"))
    except Exception as e:      # noqa: BLE001
        return f"🚩 پروبِ فلگ در دسترس نیست: {type(e).__name__}"

def _trace_text(self, text):
    try:
        import tg_trace as tg
        n = next((int(p) for p in text.split()[1:] if p.isdigit()), 15)
        rows, stats, topics, chat = tg.trace(limit=n)
        return tg.render(rows, stats, topics, chat, limit=n)
    except Exception as e:      # noqa: BLE001
        return f"🚩 ردِ ارسال در دسترس نیست: {type(e).__name__}"
```
⚠️ طبق BS-۱۲، این دو `send` هم باید `topic_id=self._reply_thread(msg)` بگیرند،
وگرنه جوابِ `/trace` خودش در General می‌افتد — که کمدی است.
