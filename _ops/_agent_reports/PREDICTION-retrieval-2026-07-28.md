## پیش‌بینیِ آزمون‌پذیر

وقتی `consolidation.json` ردیفِ سیکلِ ۵۳۶ یا بالاتر را بنویسد، **یکی از این دو**
رخ می‌دهد:

**الف) بازیابی کار می‌کند** → آن ردیف `latent_vector` غیرِ null دارد **و**
`similar_keys` غیرِ null. یعنی سیستم برای اولین بار می‌تواند چیزی را با شباهت
به یاد بیاورد، نه فقط به ترتیب بازپخش کند.

**ب) بازیابی هنوز نمی‌رسد** → `similar_keys` باز هم `null` می‌ماند در حالی که
بردار وجود دارد. یعنی بردار ساخته می‌شود ولی به رکورد نمی‌رسد — یک قوسِ بریده
بینِ تولید و ثبت.

**من (ب) را محتمل‌تر می‌دانم**، چون در همین جلسه چند بار همین الگو دیده شد:
تولیدکننده کار می‌کند، مصرف‌کننده وصل نیست. ولی شواهدی ندارم که (الف) را رد کند
— پس این یک حدسِ ثبت‌شده است، نه یک یافته.

## نحوهٔ سنجش (برای هر کسی که بعد می‌آید)

```bash
python -X utf8 -c "
import json
d=json.loads(open(r'F:/backup/_ops/neural/consolidation.json',encoding='utf-8').read())
new=[r for r in d if r['cycle']>535]
print('ردیف‌های تازه:', len(new))
for r in new:
    print(r['cycle'], 'vector=', r.get('latent_vector') is not None,
          'similar=', r.get('similar_keys'))
"
```

اگر `similar_keys` هنوز `null` بود → شاخهٔ (ب) → قوسِ بریده باید پیدا و بسته شود.
اگر پر شد → شاخهٔ (الف) → لایهٔ تداعی برای اولین بار زنده است و باید ثبت شود.
