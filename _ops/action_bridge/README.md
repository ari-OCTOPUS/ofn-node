# action_bridge — پلِ اقدامِ عمومیِ اختاپوس

> **وضعیت: `IMPLEMENTED_NOT_INTEGRATED`.** هیچ صداکنندهٔ runtime، هیچ فلگ، هیچ
> اتصال به `organism`/`wiring`/`test_cycle`. عمداً.

## مسئله‌ای که این پل حل می‌کند

تا امروز حلقهٔ خودهدف‌گذاری این بود:

```
جهت → هدف → پیش‌ثبت → مشاهده → حکم → روشِ بعدی
```

و شکافش این: `test_cycle.run()` متنِ روش را **ثبت** می‌کند ولی به اقدام تبدیلش
نمی‌کند. پس وقتی هدف می‌گوید «لیدهای آمادهٔ claim را بررسی کن»، هیچ‌کس آن بررسی
را انجام نمی‌دهد؛ ارزیاب درست `FAIL` می‌دهد و مولد روشِ دوم را انتخاب می‌کند —
و روشِ دوم هم یک **رشته** می‌ماند.

این پل همان حلقهٔ گم‌شده است:

```
… → روش → درخواستِ عمل → طبقه‌بندی → مجوز → نقشه
      → اجرا یا کارتِ مالک → رسید → مشاهده → حکمِ مستقل → حافظه/چرخش
```

## سه اصلی که همه‌چیز از آن‌ها می‌آید

**۱. ناشناخته = خطرناک.** نوعِ عملی که در جدول نیست `A6` است، نه `A0`. کلاسِ
ناشناخته `REJECT` می‌گیرد. مجوزِ بی‌حافظهٔ replay رد می‌شود. دفترِ غایب
`CONFLICT` است نه `NEW`. هیچ مسیرِ پیش‌فرضِ سخاوتمندانه‌ای وجود ندارد.

**۲. فقط بالا، هرگز پایین.** هر سیگنال می‌تواند کلاس را بالا ببرد؛ هیچ‌کدام
پایین نه. `contracts.escalate()` این را ساختاراً تضمین می‌کند.

**۳. متن مجوز نیست.** `intent`، `expected_effect` و `source_component` فقط
بالابرنده‌اند. این بندِ ضدِ prompt-injection است: مولدی مثل `world_discovery` از
**وبِ عمومی** تغذیه می‌شود، پس متنِ دشمن‌محتمل واردِ `intent` می‌شود. طبقه‌بندی
از میدان‌های **ساختاری** می‌آید (نوع، مقصد، فلگ، هزینه، قابلیت) نه از روایت.

## نردبانِ کلاس

| کلاس | معنی | تصمیمِ این دور |
|---|---|---|
| `A0` | مشاهده — صفر تغییر/ارسال/خرج | `ALLOW` |
| `A1` | artifact در sandbox، برگشت‌پذیر | `ALLOW` |
| `A2` | تغییرِ برگشت‌پذیرِ allowlisted | `BLOCK` — تا رأیِ حاکمیتی |
| `A3` | کاری که مالک باید تأیید کند | `OWNER_GATE` |
| `A4` | اثرِ بیرونی (پیام/فرم/انتشار/deploy) | `BLOCK` |
| `A5` | پول یا تعهد | `BLOCK` |
| `A6` | ممنوعِ مطلق | `REJECT` |

`A2` عمداً `BLOCK` است، نه چون خطرناک‌تر از `A3` باشد — چون `VQ-SELFGOAL-002`
چهار پیش‌شرطِ مکانیکیِ باز دارد. وقتی بسته شدند، فقط یک خط
(`classifier.DECISION_BY_CLASS`) عوض می‌شود.

## چه چیزی این پکیج **نمی‌تواند** بکند

نه «فلگش خاموش است» — **تابعش نوشته نشده**. برای `A2..A6` هیچ مسیرِ اجرایی در
`executor` وجود ندارد. تفاوت مهم است: فلگِ خاموش یعنی کدِ آمادهٔ خفته؛ مسیرِ
غایب یعنی برای بازکردنش باید کسی کد بنویسد و آن کد از بازبینی رد شود.

سه ناوردی در **هر** مسیر، و تست‌شده:

```
external_effects == []      همیشه
cost == 0                   همیشه
artifact ⊂ sandbox          هر فایلِ نوشته‌شده
```

## مجوز — پنج بندی که بدونشان approval یک کلیدِ عمومی است

```
bind     به action_id + payload_hash + scope گره می‌خورد
expiry   منقضی = نامعتبر، بی‌استثنا
replay   nonce یک‌بارمصرف؛ حافظهٔ غایب = رد، نه عبور
shape    امضای غیر-هگز رد می‌شود قبل از مقایسه (وگرنه رشتهٔ فارسی گیت را می‌ترکاند)
key      بدونِ کلیدِ امضا هیچ مجوزی صادر و هیچ‌کدام تأیید نمی‌شود
```

و صریح: **کارتِ رأی مجوز نیست.** `is_authorization: False` در خودِ کارت نوشته
شده. «آره بزن» در چت هم یک رشته است.

| `executor.py` | فقط A0/A1، فقط sandbox |
| `rollback.py` | برگرداندنِ artifactهای A1 |
| `integration.py` | نقشهٔ اتصالِ پیشنهادی — اعمال‌نشده |
