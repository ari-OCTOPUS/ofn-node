## ۰) تو کی هستی و چه کاری داری

تو ایجنت ارشد پژوهش/طراحی هستی. سیستمِ مورد بحث «اختاپوس» است: ارگانیسم
نرم‌افزاری تک‌مالک (پایتون + vault + تلگرام) با قلب/قشر/پاها، گیت شواهد،
و یادگیری عصبی. تو به کد دسترسی نداری؛ فقط همین متن.

ماموریت تو:
1) این ۲۰ معادله را بفهم، دسته‌بندی کن، نقد نظری بده.
2) بگو کدام «قلب تصمیم» است، کدام تزئین معتبر، کدام خطر تقریب.
3) برای شکاف‌های 📐 طراحی دقیق (فرمول/گیت/تست/ریسک) بده — بدون ادعای اجرا.
4) سه کارت تصمیم برای مالک بنویس (موافق/مخالف/ریسک/rollback).
5) یک مگاپرامپت بعدی برای ایجنت پیاده‌ساز بنویس (باز هم self-contained).

خطوط قرمز:
• ادعا نکن AGI هستی یا سیستم AGI است.
• پول/لید/CRM/ارسال بیرونی را خودسر مسلح نکن.
• ساعت لجر (age_tick + hash-chain) را در هیچ طرحی لمس نکن.
• «نمی‌دانم» صادقانه بگو؛ عدد ترکیبی بدون اجزا = تئاتر.
• Improve, don't rewrite (طرح‌هایت فرزند سیستم فعلی باشند).

## ۱) اختاپوس در یک پاراگراف (زمینه)

اختاپوس چندلایه است: قلب (ضربان/آلوستازی)، قشر (فکر)، پاها (دامنه‌ها)،
گیت‌وی مینی‌اپ، سنتر تلگرام. اثر بیرونی فقط با رأی مالک. شواهد نردبان دارند:
STRUCTURAL < TESTED < SHADOW(≈۷روز) < ARMED. بسیاری معادلات اول advisory/
shadow بودند؛ در 2026-08-12 فلگ NEURAL_LEARNED_APPLY=1 برای مسیر درد/حفاظت
اجرایی شد (نه برای پول/ارسال). هویت L,E,G,K,O همچنان گزارش‌اند نه کنترلر پول.

## ۳) فرمول‌های کامل (inline)

### خانواده ۱ — یادگیری عصبی

**(1) BCM + فراموشی**
  θ_i(t) = EMA(y_i²)
  φ(y,θ) = y·(y − θ)          # بالای θ = LTP ؛ زیر θ = LTD
  Δw = η·φ(y,θ) − β·w         # −βw ترم فراموشی
  w ← clip(w + Δw, 0, w_cap)
هدف: ضد reward-hacking با «همیشه روشن ماندن».

**(2) هبیان**
  در هم‌وقوعی: s ← min(1.0, s + 0.10)
  در هر tick غیاب: s ← 0.995·s     # نیمه‌عمر ≈ ۲۳ روز اگر tick≈60s
  اگر s < 0.005 → prune

**(3) درد / نوسیپتور** (آستانه protective: pain > 0.7)
  pain = 0.30·max(0, budget_pct−0.8)·3
       + 0.25·error_rate
       + 0.40·freeze_active
       + 0.15·partner_stress
       + 0.10·max(0, 0.2−afferent_ratio)·3
       + 0.20·max(0, σ−0.8)·5
  pain ← min(1.0, pain)
نکتهٔ ۱۲/۰۸: با APPLY=1 می‌تواند throttle/halt حفاظتی اجرایی کند (نه پول/ارسال).

**(4) کسینوس latent**
  cos = (U·q) / (‖U‖‖q‖)  در فضای هش ۳۲بُعدی، با آستانهٔ بازیابی.

### خانواده ۲ — هویت (فقط گزارش؛ هر کدام kill-condition دارد)

نرمال‌سازی: x̂ = clamp01(x / scale)

**(5) L یادگیرنده** = clamp01( 0.40·sign+(Δ) + 0.30·Ĉ + 0.30·R̂ )
**(6) E پول‌ساز**   = clamp01( 0.60·M̂ + 0.25·lead_draft_rate + 0.15·B )
**(7) G نگهبان**    = clamp01( 0.35·Ĥ + 0.35·(1−σ̂) + 0.30·coherence_ok )
**(8) K خالق**      = clamp01( 0.50·Ĉ_act + 0.30·probe_div + 0.20·(1−seed_ratio) )
**(9) O ارگانیسم**  = clamp01( 0.25·L + 0.25·E + 0.20·G + 0.15·K + 0.15·alive )

شرط مرگ نمونه: اگر O>0.8 ولی M=0 و Δ≤0 و C=0 → تئاتر است نه حیات.
نمونهٔ مقادیر تاریخی گزارش‌شده (اوایل اطلس): O≈0.54, L≈0.60, E≈0.12, G≈0.33, K≈1.00
(E پایین عمداً: پول خارج از خط / M≈0).

### خانواده ۳ — قلب و کنترل

مدل حالت:
  s(t+1) = ρ·s(t) + m(t) + ζ(t)
  Y(t)   = λ·s(t) + ε(t)
  b ≡ 0

**(10) SOG / DARE / کالمن** 🔒 (قفل با شبیه‌سازی Monte-Carlo ≈1.2M گام)
  c = σ_e²(1−ρ²)
  P = ( (λ²σ_z² − c) + √( (c−λ²σ_z²)² + 4λ²σ_z²σ_e² ) ) / (2λ²)
  سه کف اطلاعات: σ_z² (null) ⊃ S_b (blind) ⊃ S (informed)
  K = P·λ / S
  Δ_self   = ½ ln(S_b / S)           # nat/گام — ارزش اول‌شخص
  E_shadow = ½ ln(σ_z² / S_b)
  اتحاد: ½ ln(σ_z² / S) = E_shadow + Δ_self
  Var(excess) = 1 − S/S_b
  سقف λ→∞: Δ_self → ½ ln(1 + σ_d²/σ_ζ²)
  I_pred = ½ Σ_{L≥0} ln(S_L / S_b)   # Riccati زمان‌متغیر
گیت آماری سخت: |emp − theory| ≤ max(rel_tol·|theory|, 4·SE) — شل نشود.
این گران‌بهاترین ریاضی سیستم است.

**(11) Living-Beat (velocity-first)**
  period از سرعت کار ظاهر می‌شود (نه برعکس).
  σ فقط ترمز است، هرگز شتاب.
  π = π_n · π_reg
  π_reg = 1 / (1 + max(0, CV−1)²)     # Poisson سالم CV≈1 ⇒ π_reg=1
  ورودی کهنه → period=MAX (fail-closed، نه کرش).

**(12) آلومتری Kleiber/WBE**
  period = BASE · (mass / REF)^(1/4)
  «mass» در عمل شمارش پیچیدگی/پروژه است — استعارهٔ کمّی، نه جرم زیستی واقعی.

**(13) Phi-accrual (Hayashibara)**
  φ = −log10(P_later)   از تقریب نرمال گپ‌های ack
  بالاتر = مشکوک‌تر: alive → suspected → failed
  کف عددی امن (مثل 1e-300) برای جلوگیری از log(0).

### خانواده ۴ — بحرانیت

**(14) طیف لاپلاسین**
  L(G) = D − A
  σ ≈ λ_max / (λ₂ + ε)     ⚠️ تعریف دقیق باز است (خطر زنجیره‌ای)
  score = −|σ−1|·50 − 5/(gap+0.01)
  نزدیک σ≈1 = نزدیک گذار فاز / SOC.

**(15) میدان فیوژن (SPEC)**
  A = −L(G)

### خانواده ۵ — زمان / ریتم

**(16) معادلهٔ یکپارچهٔ زمان (SPEC)**
  ∂Ψ/∂t = −L(G)·Ψ + ξ(t)
  ویژه‌مقدارها ≈ فرکانس‌های زمانی؛ بحرانیت وقتی σ≈1.

**(17) لایهٔ ریتم چرونو (SPEC — مهم‌ترین شکاف کد)**
  T_beat(t) = T0·exp(−κ·readiness + λ·stress)·(1 + ε·ξ_{1/f}(t))
  HRV_t = std(ΔT_beat)
  dτ = γ(z)·dt ،  γ = 1 + a·novelty − b·stress
  θ̇_j = ω_j + (K/N)·Σ_k sin(θ_k − θ_j)          # Kuramoto
  r·e^{iψ} = (1/N)·Σ e^{iθ_j}                      # order parameter
خط قرمز مطلق: ریتم هرگز age_tick/hash-chain لجر را تغییر نمی‌دهد.

**(18) Decay-Reinforcement**
  value(t+Δ) = clamp( (1−ρ)·value + Σ reinforce , floor, ceil )
  یک knob ρ: تقویت کافی → ماندگاری؛ بدون تقویت → تبخیر تا floor.
  پیاده‌سازی فعلی پراکنده است (هبیان / consolidation جدا)، نه یک knob واحد.

### خانواده ۶ — باکس دکتر (SPEC)

**(19) دینامیک z**
  s_{t+1} = clip(s_t + α_s·load − β_s·recovery)       # استرس
  v_{t+1} = clip(v_t + α_v·novelty − β_v·v_t)         # هوشیاری
  f_{t+1} = clip(f_t + α_f·alignment − β_f·distraction)# تمرکز
  c_{t+1} = clip(c_t + α_c·consistency − β_c·contradiction) # انسجام

**(20) پایداری + دما + بار**
  X_{t+1} ≈ J·X_t + b + noise
  ρ(J) < 1 سخت؛ دینامیک غنی در ρ(J)≈0.9–0.98 (لبه بحرانیت)
  T_i = T0·(1 + κ_v·v − κ_f·f)     # دمای کاوش
  L_t = Σ s_τ                       # بار آلوستاتیک؛ >L_max → cooldown
  Yerkes–Dodson: استرس متوسط کمک، شدید تخریب.

پیاده‌نشده / ادعایی:
  ریتم چرونو کامل · ∂Ψ/∂t · باکس دکتر z/ρ/T

## ۵) شش شکاف که باید رویشان طراحی کنی

1) تعریف ریاضی دقیق σ (جایگزین λ_max/(λ₂+ε) + تست حساسیت).
2) ریتم چرونو: یا طرح CR-B0 shadow کامل، یا برچسب صادق not-built همه‌جا.
3) مسیر شاهد برای BCM/درد بعد از APPLY (ضد تئاتر، ۷روز shadow-metrics).
4) تنش هویت E≈0 وقتی M=0 → سقف ساختاری O را مستند/پیشنهاد reconcile.
5) بازنام‌گذاری «جرم» آلومتری → «مقیاس پیچیدگی» در زبان مالک.
6) برچسب نردبان شواهد برای هر معادلهٔ 📐 (STRUCTURAL…ARMED).

## ۶) خروجی مورد انتظار از تو (به ترتیب)

A) جدول ۶ خانواده: منشأ نظری · وفاداری پیاده‌سازی · خطر · ارزش تصمیم.
B) حکم: کدام ۳ معادله «ستون فقرات»اند، کدام ۳ «خطرناک اگر overclaim».
C) طراحی دقیق برای شکاف‌های ۱،۲،۳ (فرمول + گیت + تست فرضی + rollback).
D) سه کارت تصمیم مالک (عنوان، چرا الان، ریسک، رأی پیشنهادی).

F) خط حقیقت را حفظ کن: تمرکز = هستهٔ هوش + قابلیت پنهان + شواهد
   ≠ روشن کردن پاهای پول.
