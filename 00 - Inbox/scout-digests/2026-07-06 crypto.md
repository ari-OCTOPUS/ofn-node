# Crypto — Research Digest 2026-07-06

## Today's question
Following on from 2026-07-04's spore: is there a free/near-free substitute for LunarCrush's now-paid (~US$72/mo) Galaxy Score / AltRank sentiment feed that still gives decision-grade edge inside the AU$30/month budget?

## Findings
- **Alternative.me's Fear & Greed Index has a genuinely free, no-auth, no-key JSON API (`api.alternative.me/fng/`, CORS-enabled, `?limit=0` for full history) that is directly automatable.** It is not per-coin (one blended 0–100 score from volatility, momentum, social media, dominance, and Google Trends), so it can't replace AltRank's per-asset ranking — but it's a zero-cost, script-ready macro sentiment overlay we don't currently have wired in. [source](https://api.alternative.me/fng/)
- **CryptoCompare's free API tier (100,000 calls/month, registered key, no card) includes a real `/data/social/coin/latest` endpoint returning per-coin raw social counts (Reddit subscribers/active users, Twitter followers, page views, comments) — unlike LunarCrush, this raw social data is *not* gated behind a paid plan.** This is the closest like-for-like substitute for LunarCrush's underlying social inputs within budget; it gives raw counts rather than a pre-computed Galaxy Score/AltRank, so we'd need our own simple ranking formula (e.g., week-over-week % change in follower/mention counts) to approximate AltRank's momentum ranking. [source](https://www.cryptocompare.com/coins/guides/how-to-use-our-api/)
- **Santiment confirms the same pattern as LunarCrush: real-time sentiment/social API access requires "Sanbase Max," their paid tier (~US$49+/mo), while the free Sanbase tier is time-lagged and metric-restricted.** This rules out Santiment as a free path and reinforces that CryptoCompare + Alternative.me is currently the only genuinely-free combination found. [source](https://academy.santiment.net/products-and-plans/sanapi-plans/)
- **Peer-reviewed evidence (Haase et al., *Electronic Markets*, 2025) found that *explicit crowd trading signals* (concrete buy/sell calls scraped from X, Reddit, Stocktwits, Telegram) — not blended sentiment scores — significantly predicted short-term price moves for lower-cap coins with recent negative returns, and an out-of-sample strategy using them beat both CCI30 and the S&P 500.** This suggests the real edge in "social data" may come from parsing concrete calls-to-action rather than a smoothed mood index like Galaxy Score — a reason not to over-invest in replicating AltRank exactly. [source](https://link.springer.com/article/10.1007/s12525-025-00815-6)
- **Separately, ML studies (e.g., IJERT 2025 review of sentiment-based price prediction) report sentiment-derived models reach useful accuracy mainly when sentiment is at measurable *extremes*, not as a continuously-ranked signal.** This lines up with using Alternative.me's Fear & Greed as a contrarian extreme-value trigger (e.g., only act near 0–20 "Extreme Fear" or 80–100 "Extreme Greed") rather than trying to trade its middle range. [source](https://www.ijert.org/cryptocurrency-price-prediction-using-sentiment-analysis-ijertv15is043374)

**For the AU$30 budget, practical stack:** Alternative.me Fear & Greed (free, no key, contrarian extreme-value overlay) + CryptoCompare free-tier social stats (per-coin raw counts, self-computed week-over-week momentum as an AltRank proxy) — both fit inside the existing free-tier CoinGecko/CryptoCompare stack from the 2026-07-04 digest, no new paid subscription needed.
