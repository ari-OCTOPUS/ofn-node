# Crypto — Research Digest 2026-07-05

What are the *specific numeric* MVRV Z-Score and SOPR threshold bands that define "washout/accumulation" vs "cycle-top" for BTC, and which **free** data sources expose those exact metrics so the signal can be automated under the AU$30/month ceiling? ## Findings

- **MVRV Z-Score has concrete, historically-tested bands: the "sell/top" zone is roughly Z > 6.5–7 (red), the "accumulation/bottom" zone is Z near 0 or negative (green), with a fair-value band in between — and it has marked every major BTC top/bottom since 2012, typically within ~2 weeks.** Note the *plain* MVRV Ratio (a different metric) uses ~>3.5 for tops and <1.0 for bottoms — don't confuse the two. → *For strategy:* this replaces the project's directional "Washout" hand-waving with a numeric trigger — tag "Washout = candidate" only when **MVRV Z-Score sits in the green (≤~0)** band, not merely "price is down." [source](https://www.bitcoinmagazinepro.com/charts/mvrv-zscore/) · [bands explainer](https://www.tradingcopilot.app/blog/mvrv-z-score-explained-crypto)

- **SOPR's key line is 1.0 (breakeven for the average spent coin); sustained sub-1.0 readings = coins selling at a loss / capitulation and have coincided with cycle floors, while the reliable *timing* trigger is STH-SOPR crossing back above 1.0 — but SOPR is regime-dependent: in an uptrend dips to 1.0 reset without breaking, in a downtrend 1.0 acts as resistance as holders exit at breakeven.** A single cross reverses easily; the signal is in *persistence*, not one candle. → *For strategy:* use SOPR as the **confirmation/timing overlay** on MVRV, not standalone. Define the project's "Washout = confirmed" tag as **MVRV-Z green AND SOPR persistently <1.0**, with the *turn* flagged when STH-SOPR reclaims 1.0. [source](https://docs.glassnode.com/guides-and-tutorials/metric-guides/sopr/sopr-spent-output-profit-ratio)

- **As of early July 2026 both meters sit in the historical "accumulation neighborhood": MVRV Z-Score ≈ 0.20 (near realized value, Jul 1), SOPR ≈ 0.98 (Jun 30, below breakeven), with BTC ≈ US$61k — ~51% below the Oct-2025 peak of ~US$124.8k — and ~47% of supply in profit; the realized P&L ratio hit a 43-month low that several desks frame as a buy-zone read.** *Epistemic status: aggregated from public dashboards, single-snapshot — verify live before ANY decision; on-chain prints are noisy and this is context, not a call.* → *For strategy:* this is precisely the regime the project's entry/exit rules were built to detect, so it is the moment where **discipline (pre-registered rules + human BUY verdict) matters most** — exactly what [[03 - Projects/Crypto - etoro/spacing_x_expectancy_protocol|spacing × expectancy]] guards against emotional entries. [MVRV chart](https://en.macromicro.me/charts/30335/bitcoin-mvrv-zscore) · [P&L 43-mo low](https://cryptobriefing.com/bitcoin-pnl-ratio-43-month-low-buy-signal/)

- **The on-chain half of this signal can be fully automated at AU$0 — no paid Glassnode needed.** BTCFunk exposes a **free, no-auth JSON API** (`/api/mvrv_zscore`, `/api/sopr`, `/api/exchange_flow`, plus `?summary=true` for scalar-only output ideal for bots) computed from Google's BigQuery public Bitcoin dataset; Look Into Bitcoin gives free daily MVRV Z-Score; Glassnode's free tier still exposes STH-SOPR (delayed); and BGeometrics offers a free API (8 req/hr, 15/day) **plus an MCP server (154+ metrics) that a Claude agent can connect to directly.** → *For strategy:* the washout detector (MVRV-Z + SOPR + exchange-flow) is buildable free — closes yesterday's spore #2; the tiny budget can go elsewhere (or nowhere). [BTCFunk API](https://btcfunk.com/) · [free-stack guide](https://onchainnews.blog/how-to-build-your-own-bitcoin-onchain-dashboard-using-only-free-tools/) · [BGeometrics](https://bgeometrics.com/)

- **For full data ownership there's an open-source, self-hostable path — and the academic literature says keep these metrics as *context*, not standalone alpha.** BitcoinResearchKit (BRK) computes 8,000+ metrics from a Bitcoin Core node, with a free hosted instance (bitview.space, no rate limit, JSON/CSV, Python/JS clients). Meanwhile "Blockchain Metrics and Indicators in Cryptocurrency Trading" (alphaXiv 2403.00770) constructs tradable indicators from on-chain data but treats them as regime/confirmation signals — consistent with the "sentiment/on-chain as confirming edge, not trigger" finding from 2026-07-04. → *For strategy:* on-chain metrics belong in the **confirmation layer, sized via fractional-Kelly**, never as a lone entry; epistemic tag = `verified-but-regime-dependent`, not `predictive`. [BRK](https://github.com/bitcoinresearchkit/brk) · [paper](https://www.alphaxiv.org/abs/2403.00770)
