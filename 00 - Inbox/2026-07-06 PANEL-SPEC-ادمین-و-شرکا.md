# PANEL-SPEC — پنل ادمین + پنل‌های سفارشی شرکا (وب + تلگرام)

> جلسه ۲۰. خواستهٔ آری: «داشبورد تلگرام آپدیت شود، غیرضروری‌ها حذف، ساختار یکپارچه‌تر — مرحله به مرحله». دو دور سوال (۸ سوال) جواب داده شد؛ این spec خروجی آن است. **فاز صفر بدون verdict شروع نمی‌شود.**

## تصمیم‌های قفل‌شده (جواب‌های آری، دور ۱ و ۲)

| موضوع | تصمیم آری |
|---|---|
| شکل نهایی | وب قابل‌دسترس از همه‌جای دنیا + تعاملات تلگرامی |
| کاربران | آری (ادمین/مغز اصلی انسانی) + شرکای کاری = مغز انسانی هر پروژه |
| تجربهٔ شریک | ساده و خلوت: یک گزارش، یک سوال، حس چتِ با AI؛ چند نوتیف در روز؛ پرسشنامه‌های متفاوت |
| مالکیت | پنل اصلی دست آری؛ هر شریک پنل کاستوم و فلکسیبلِ خودش (وب + تلگرام) |
| دسترسی وب | **VPS ارزان جدا** (نه tunnel روی لپ‌تاپ) |
| راه‌اندازی | شرکا هستند ولی **اول آری خودش با نقش شریک تست می‌کند** |
| چت شریک | **ترکیبی با سقف:** گزارش/پرسشنامهٔ ساختاریافته رایگان + چت آزاد سقف‌دار (موتور ارزان DeepSeek) |
| ریتم نوتیف | **کاستوم به‌ازای هر شریک + شرطیِ وضعیت پروژه** (نه cron ثابت برای همه) |

## آنچه از قبل داریم (recon همین جلسه — دوباره نساز)

- `core/authz.py`: سه نقش ADMIN / OPERATOR / VIEWER → شریک = OPERATOR، آماده.
- `panels/panel_server.py` (۴۸۷ خط): پنل وب با PIN و token و audit به‌ازای هر panel + نمونهٔ زیمان → اسکلت پنل شریک.
- ربات ادمین: ‏/status ‏/queue ‏/briefs ‏/halt ‏/resume + کارت‌های Approve/Edit/Reject و ✅/❌ تکامل.
- سه ربات کاسبی با توکن جدا → نگاشت طبیعی: **ربات هر کاسبی = درگاه تلگرامی شریک همان پروژه**؛ ادغام لازم نیست، نقش‌بندی لازم است.
- rokn A (پرسش‌های وزن‌دار با حلقهٔ یادگیری) → همان موتور «پرسشنامهٔ متفاوت» شریک.
- **[یادآوری آری 2026-07-06] پلاگین‌های Cowork را هم recon کن، نه فقط کد خودمان.** طبق ممیزی [[00 - Inbox/marketing-agent-tooling-audit-2026-07-06|marketing-agent-tooling-audit]]، لایهٔ «ساخت ایجنت» (scheduled tasks، Artifacts، skill-creator، create-cowork-plugin) همین الان متصل و آماده است: Artifacts همان الگویی است که کابین کنترل architect («fleet-live-dashboard») از قبل استفاده می‌کند؛ scheduled tasks می‌تواند ریتم نوتیف کاستومِ فاز ۱ را بدون کدنویسی جدید بدهد؛ skill-creator کاندید ساخت پرسشنامهٔ rokn A به‌ازای هر شریک است. قبل از فاز ۲ (VPS) بررسی شود کدام بخش پنل واقعاً نیاز به کد سفارشی دارد و کدام را این پلاگین‌ها پوشش می‌دهند.

## معماری هدف (یک بند)

مغز و سکرت‌ها روی لپ‌تاپ می‌مانند. VPS فقط «آینهٔ گنگ + صندوق»: پنل وب استاتیک/سبک + صف پیام (گزارش‌ها push می‌شوند، جواب‌ها/فرم‌ها pull می‌شوند). هیچ کلید LLM/تلگرام روی VPS نیست؛ اگر VPS هک شد، حداکثر دادهٔ پنل لو می‌رود نه مغز [منطقی — verify امنیتی در فاز ۲]. تلگرام مسیر دوم همه‌چیز است و از روز اول جهانی کار می‌کند.

## فازها (هر فاز: build → test → گزارش → verdict آری)

- **فاز ۰ — تمیزکاری پنل ادمین (لپ‌تاپ، ~نیم‌روز):** متن‌های ربات ادمین کوتاه/فارسی/انسانی؛ مرتب‌سازی کارت‌ها؛ حذف/مخفی‌سازی هرچه استفاده نمی‌شود (فهرست دقیق حین کار، با تأیید تک‌به‌تک). خروجی: ربات ادمینِ خلوت.
- **فاز ۱ — پنل شریک روی تلگرام (لپ‌تاپ، ۱–۲ روز):** نقش OPERATOR با chat_id + PIN؛ سه جریان: گزارش روزانه · پرسشنامهٔ rokn A · چت آزاد سقف‌دار (پیش‌فرض ۱۰ پیام/روز DeepSeek [حدس معقول — verdict]). config نوتیف به‌ازای شریک (ساعت‌ها + تریگرهای شرطی: صف پر، ددلاین، سکوت N روزه). **تست: خود آری یک هفته شریکِ قلابی.**
- **فاز ۲ — وب روی VPS (۱–۲ روز):** سخت‌سازی panel_server (HTTPS، rate-limit، بدون secret) + پروتکل push/pull با مغز لپ‌تاپ. انتخاب VPS و هزینهٔ دقیق = verdict (برآورد ~$4–6/ماه [منطقی، verify موقع خرید]).
- **فاز ۳ — شریک واقعی اول:** دعوت یک نفر، یک پروژه؛ حلقهٔ بازخورد دو هفته؛ بعد کلون برای بقیه.

**شرط مرگ فاز ۱:** اگر تا ۷ روز بعد از ساخت، خود آری روزانه استفاده‌اش نکرد → توقف و بازطراحی، نه فاز ۲.

## verdictهای باز (قبل از شروع)

۱. ترتیب با ۰۷/۲۰: فاز ۰ سبک است و می‌تواند قبل از پیچ بیاید؛ فاز ۱ به بعد، بعد از پیچ [پیشنهاد]. ۲. سقف چت آزاد شریک (۱۰/روز؟) و سقف بودجهٔ ماهانهٔ هر شریک. ۳. اولین پروژه برای پنل شریک (زیمان؟). ۴. تأیید برآورد VPS و انتخاب provider/کشور. ۵. کدام بخش پنل (نوتیف/پرسشنامه/داشبورد) با پلاگین‌های Cowork (scheduled tasks/Artifacts/skill-creator) جایگزین کد سفارشی VPS شود، و کدام حتماً باید کد خودمان بماند (چون مغز/سکرت باید روی لپ‌تاپ بماند)؟ [یادآوری آری ۲۰۲۶-۰۷-۰۶]
