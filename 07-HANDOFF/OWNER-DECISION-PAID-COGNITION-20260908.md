# OWNER DECISION — مغزِ paid ارگانیسم (OCTOPUS_PAID_COGNITION)

وضعیت: `open, requires: owner_decision` · ثبت: 2026-09-08 · لِین: FAULT-LLMLEARN-20260908
GOV_VERSION=V8 · LADDER=L2

## سؤال (یک کلمه‌ای)
آیا حلقه‌های خودکارِ ارگانیسم اجازهٔ تماسِ paid (deepseek-v4-flash، ~$0.00003/تماس)
داشته باشند؟ یعنی اضافه‌شدنِ `OCTOPUS_PAID_COGNITION=1` (+ مقدارِ `OCTOPUS_RUN_ID`)
به محیطِ اجراییِ دیمن.

## چرا الان روی میز است
- رأی ثبت‌شدهٔ مالک: «مغز = API» (D-1 و بستنِ دورِ ۲ از FX-1 — دوباره‌پرسیدنی نیست).
- ولی نردبانِ GOV-V8 «خرجِ API با سقفِ روزانه» را قابلیتِ **L3** می‌داند و سطحِ فعلی **L2**
  است؛ روشن‌کردنِ این بیت توسط ایجنت = بالا بردنِ پله بدونِ شرطِ خودش (ممنوع، AGENTS §5).
  بندِ scope §4 هم تغییرِ runtime-flagهای ارگانیسم در هر دو جهت را بدونِ رأی صریح نمی‌دهد.
- وضعیت فعلی: مسیر paid بعد از فیکسِ FX سالم است (تأییدِ زندهٔ امروز: OPERATIONAL، رسید
  `paid-primary-1788830740590`)، ولی تماس‌های دیمن به گاردِ cognition می‌خورند
  (`PAID_COGNITION_PAUSED`) → مغزِ ارگانیسم عملاً qwen محلیِ 1.5b است، همان که
  مالک با «مدل API همین امروز» خواست عوضش کند.
