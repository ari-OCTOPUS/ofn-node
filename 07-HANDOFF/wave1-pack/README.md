# بستهٔ اسکن شکاف و ساخت موازی — OCTOPUS

خروجی مرحلهٔ ۰: کشف مفاهیمی که نوشته شده‌اند ولی کد ندارند، مرتب‌سازی مفهومی
آن‌ها در چهار موج، و دستور کار موازی برای ایجنت‌ها.

## فایل‌ها

| فایل | چیست |
|---|---|
| `STAGE-00-SCAN-REPORT.md` | گزارش این مرحله، شامل بازبینی عدد ۴۵٪ |
| `CONCEPT-CODE-GAP.csv` | ثبت ۵۰ مفهوم با ردیف، موج، وابستگی، گیت |
| `BUILD-WAVES.md` | ترتیب مفهومی و مرزهای موازی‌سازی |
| `EDGE-CONTRACT.md` | طراحی مفهومی مرز هسته↔بردها |
| `SUPERVISION-PROTOCOL.md` | چه چیزی هر لِین تحویل می‌دهد تا قابل بررسی باشد |
| `megaprompts/` | یک مأموریت به‌ازای هر لِین + پیش‌درآمد مشترک |
| `tools/gap_scan.py` | بازتولید ثبت از روی مخزن واقعی |
| `gap-scan.png` | توزیع شکاف بر حسب ردیف و لایه |

## چطور شروع کنید — امشب

چهار لِین موج ۱ **همزمان** شروع می‌شوند. هیچ فایل مشترکی ندارند:

```
cursor -w w1-spine   # مالکیت: _ops/events/
cursor -w w1-money   # مالکیت: src/nbb_cp/api/
cursor -w w1-scale   # مالکیت: metrics/
cursor -w w1-free    # فقط‌خواندنی
```

به هر ایجنت بدهید: `megaprompts/00-SHARED-PREAMBLE.md` + فایل لِین خودش.
هیچ ایجنتی نباید دو لِین بگیرد.

## قاعدهٔ توقف

هر لِین که فایلی خارج از مسیر مالکیتش لمس کند، **متوقف می‌شود و گزارش می‌دهد**.
این هشدار نیست، شرط توقف است. دلیلش ساده است: چهار ایجنت موازی روی یک مخزن،
بدون تفکیک مالکیت، merge conflict تولید می‌کنند نه پیشرفت.

## گیت بین موج ۱ و ۲

موج ۲ شروع نمی‌شود تا هر چهار لِین موج ۱ بستهٔ شواهد بدهند و من ارزیابی کنم.
W2-EDGE به‌طور خاص وابستگی سخت به Envelope دارد — اگر W1-SPINE تحویل نداده،
W2-EDGE شروع نمی‌شود.

## محدودیت صادقانهٔ این بسته

ثبت شکاف از روی **اسناد** ساخته شده، پس سطح دو است نه سطح یک. برای تبدیلش به
شاهد runtime، `tools/gap_scan.py` را روی مخزن واقعی اجرا کنید. اسکریپت داخل خود
این بسته اجرا شد و ۱۰۰٪ concept-only گزارش داد — که درست است، چون مسیرهای کد
واقعی اینجا نیستند. همین نتیجه اثبات می‌کند اسکریپت از فایل‌سیستم می‌خواند نه از
سند.

عدد قابل دفاع برای «مفهوم بدون کد» **۴۹٫۵٪** است با برچسب `derived-from-chart`،
نه ۴۵٪ و نه `verified`.
