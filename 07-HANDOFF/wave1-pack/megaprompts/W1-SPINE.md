# لِین W1-SPINE — ستون فقرات رویداد

> پیش‌درآمد مشترک (`00-SHARED-PREAMBLE.md`) را قبل از این بگذار.

**لِین:** W1-SPINE
**مالکیت انحصاری:** `_ops/events/` و `tests/events/`
**ممنوع:** `src/nbb_cp/`، `_ops/observatory/`، `metrics/`
**وابستگی:** هیچ. از دقیقهٔ اول شروع می‌شود.
**worktree:** جدا

## چرا این لِین اول است

بین هستهٔ OCTOPUS و بردها هیچ قراردادی وجود ندارد. Envelope قرار بود آن مرز باشد،
نوشته شد، ساخته نشد. تا ساخته نشود، هر برد جدید یک مسیر اختصاصی می‌سازد و هزینهٔ
ادغام درجه‌دو می‌شود. تو آن مرز را می‌سازی.

## آیتم‌ها

**G-01 — Envelope.** یک schema با این فیلدها و نه بیشتر:
`event_id` · `sequence` · `parent_event_id` · `emitted_at` · `source` ·
`payload` · `may_authorize` · `applied` · `redaction_applied` · `evidence_refs`

قواعد سخت روی schema:
- `may_authorize` و `applied` هر دو پیش‌فرض `false` و **فقط هسته** می‌تواند
  `applied` را عوض کند. یک تست ساختاری بنویس که ثابت کند هیچ ماژول لبه‌ای
  نمی‌تواند آن را بنویسد.
- `event_id` کلید idempotency است. دو رویداد با یک `event_id` = یک رویداد.
- `sequence` یکنواخت صعودی، بدون شکاف مجاز.
- فیلد ناشناخته = رد، نه نادیده‌گرفتن. deny-by-default همان قاعدهٔ allowlist.

**G-02 — مینت run_id.** ورودی‌های مینت: `approval` · `proposal_hash` ·
`policy_version` · `state_version`. یک برد یا ماژول لبه **حق ندارد** خودش
`run_id` بسازد یا خودش را به یک run نسبت دهد. این مسیر self-elevation است و باید
ساختاراً بسته شود، نه با دستور.

**G-03 — Run Store.** append-only، `sequence` یکنواخت، idempotency روی
`event_id`. بازنویسی یا بازچینش یک سطر موجود = خطا، نه هشدار.

**G-04 — چرخهٔ حیات.** `RUN_CREATED` و `RUN_COMPLETED`. یک run بدون
`RUN_COMPLETED` پس از timeout به `RUN_ABANDONED` می‌رود، نه اینکه باز بماند.

## معیار پذیرش — قبل از نوشتن کد در فایل بنویس و hash بگیر

1. دو بار replay یک ورودی ضبط‌شده، بایت‌به‌بایت یکسان. نشد، منبع آنتروپی پنهان را
   پیدا کن و حذف کن.
2. ارسال دوبارهٔ یک `event_id` هیچ سطر جدیدی نمی‌سازد.
3. تلاش یک ماژول لبه برای نوشتن `applied: true` رد می‌شود و در تست اثبات می‌شود.
4. شکاف در `sequence` تشخیص داده می‌شود.
5. فیلد ناشناخته در Envelope رد می‌شود.

هر پنج مورد باید **تست منفی** داشته باشد، نه فقط تست مثبت. E2 با تست مثبت
به‌دست می‌آید؛ برای E3 مورد منفی و مرزی لازم است.

## مرزها

- کتابخانهٔ جدید اضافه نکن. stdlib کافی است. اگر فکر می‌کنی نیست، در
  `07-HANDOFF/` توجیه بنویس و با stdlib ادامه بده.
- به `src/nbb_cp/` دست نزن — لِین W1-MONEY آنجاست.
- قالب رویداد موازی نساز. یک Envelope، یک نسخه.
- SSE، WebSocket، NATS، Temporal، Qdrant، GraphRAG: **در حوزهٔ تو نیستند.**
  حکم قبلی Trial یا Defer است و این لِین آن را باز نمی‌کند.
