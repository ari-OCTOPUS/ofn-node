# MAG-03 — چرا تعدادِ دور بی‌اثر است

```
R ∝ N²  ·  V ∝ N  ⇒  SNR ∝ N/N = ثابت
```

برای حجمِ سیم‌پیچیِ ثابت: سطح‌مقطعِ سیم ∝ 1/N، طولِ کل ∝ N ⇒ R ∝ N².

**اجرا شد:** برای N = ۲۰۰۰ / ۴۰۰۰ / ۸۰۰۰ / ۱۶۰۰۰ عددِ SNR دقیقاً **۵.۱۹** درآمد.

⇒ N فقط **امپدانس** را تعیین می‌کند. آن را به `R_opt = V_n/I_n` تقویت‌کننده بخوران (~۱kΩ برای LT1028).
اهرمِ واقعیِ حساسیت: **طولِ میله**، نه تعدادِ دور.
