# MAG-08 — چرا PLV ابزارِ غلط است

```
PLV = |mean(e^{iΔφ})|
```

دو نوسانگرِ **کاملاً مستقل** با صفر اتصال:

| اختلافِ فرکانس | PLV |
|---|---|
| ۰.۰۰ Hz | **۰.۹۰۷ ± ۰.۰۱۳** |
| ۰.۰۵ Hz | ۰.۶۸۹ |
| ۰.۵۰ Hz | ۰.۰۴۹ |

و دو نویزِ سفیدِ مستقل با پنجرهٔ ۴ ثانیه: PLV میانه **۰.۱۳۵**، صدکِ ۹۵ **۰.۲۸۲** — نه صفر.

**PLV می‌پرسد «هم‌فرکانس‌اید؟» نه «به‌هم وصل‌اید؟».**
سوروگیتِ شیفتِ زمانی هم کار نمی‌کند — PLV نسبت به شیفتِ ثابت تغییرناپذیر است.

**ابزارِ درست:** رگرسیونِ out-of-sample با holdout — آیا کانالِ میدان چیزی را پیش‌بینی
می‌کند که `hour` نمی‌کند؟
