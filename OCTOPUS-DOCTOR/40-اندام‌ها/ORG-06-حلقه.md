# ORG-06 — حلقه 🟡

> [!abstract] استعاره → کد
> **حلقه** ⟶ `doctor/daemon.py::Daemon.cycle()`

این چیزی است که «ماژول» را به **عضوِ زندهٔ ارگانیسم** تبدیل می‌کند. تا وقتی کسی باید
دستی دستور بزند، دکتر یک ابزار است. وقتی خودش هر روز می‌بیند، می‌فهمد، می‌پرسد و
منتظرِ رأی می‌ماند — بخشی از اختاپوس است.

## چرخهٔ عمرِ ماموریت

```
proposed ──✅ نیت──▶ running ──سوئیت سبز──▶ awaiting-merge ──✅ دیف──▶ merged
    │                   │                                        │
    └──❌──▶ rejected    └──قرمز──▶ failed                        └──❌──▶ rejected
```

## پنج انضباطی که در کد اجرا می‌شوند

| # | انضباط | چرا |
|---|---|---|
| ۱ | **هم‌زمان فقط یک ماموریتِ باز** | بدونِ این، دکتر تبدیل به سیلِ کارت می‌شود و کسی نمی‌خواندش |
| ۲ | هر گام فقط با رأیِ صریح | و `None` (بی‌رأی) با «رد» **یکی نیست** |
| ۳ | `dry_run` پیش‌فرض روشن | چرخه کامل می‌چرخد، هیچ merge نمی‌شود |
| ۴ | merge دو قفل دارد: رأی **و** `OCTOPUS_DOCTOR_MAY_MERGE=1` | یک قفل، یک روز اشتباهی باز می‌ماند |
| ۵ | حیاتی‌های دکتر با منشأ ثبت می‌شوند | [[R-07-قانونِ-عضویت]] |

## چیزی که تست ثابت می‌کند

کلِ حلقه — از اسکن تا رأی تا کارتِ دیف — **صفر بایت** در درختِ ارگانیسم تغییر می‌دهد.
تنها استثنا `MissionRunner.merge` است، و آن هم فقط بعد از دو رأیِ ✅ و روی درختِ **تمیز**،
و اگر سوئیت قرمز شود فایل‌ها بایت‌به‌بایت برمی‌گردند.

## اجرا

```powershell
python doctor\cli.py day F:\backup\_ops                 # dry-run
python doctor\cli.py day F:\backup\_ops --live --apply  # با دست و با merge
```
