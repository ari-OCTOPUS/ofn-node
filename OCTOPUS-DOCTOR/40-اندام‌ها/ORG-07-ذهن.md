# ORG-07 — ذهن 🟡

> [!abstract] استعاره → کد
> **ناخودآگاهِ جمعی** ⟶ `doctor/mind.py::CollectiveUnconscious`

## ترجمهٔ یونگ به کد

| یونگ | اینجا | چرا این ترجمه درست است |
|---|---|---|
| خودآگاه | `Context Bundle`ِ همین لحظه | آنچه در پنجره است |
| ناخودآگاهِ شخصی | اپیزودهای هر actor | تجربهٔ خودِ آن لِگ، قابلِ بازیابی |
| **ناخودآگاهِ جمعی** | `CollectiveUnconscious` | هیچ actorی مالکش نیست؛ همه از آن نمونه می‌گیرند |
| کهن‌الگو | `Archetype` | **خاطره نیست — آمادگیِ پاسخ است** |
| سایه | `Shadow` | آنچه مرتب رد می‌شود و هیچ‌جا ننوشته |
| فردیت‌یابی | `Shadow.themes()` در Context | یکپارچه‌کردنِ ردشده‌ها با خودآگاه |
| تورّم (inflation) | `MAX_BIAS` + لایهٔ شکاک | ← [[R-08-قانونِ-ناخودآگاه]] |

## اصلِ معماری

**لایه‌ها با مقیاسِ زمانی تعریف می‌شوند، نه با «هوش».** هر لایه دورهٔ کندتر و میدانِ
دیدِ پهن‌تری از لایهٔ زیرش دارد. و اتصالشان **فراخوانِ تابع نیست** — لایهٔ بالا فقط
`prior` و `precision` لایهٔ پایین را تنظیم می‌کند.

| لایه | مقیاس | کارش |
|---|---|---|
| L0 رفلکس | ثانیه | کلیدِ توقف، circuit breaker. **فکر نمی‌کند** |
| L1 ادراک | ۱۵ دقیقه | `scanner.py` |
| L2 اپیزود | روز | `diagnose` / یک ماموریت |
| L3 الگو | هفته | تکرار را می‌بیند |
| L4 کهن‌الگو | ماه | رنگ می‌دهد، تصمیم نمی‌گیرد |
| L5 منشور | ∞ | فقط رأیِ مالک |

## چرخهٔ تقطیر

```
اپیزود ──┐
اپیزود ──┼─▶ امضای مشترک ──▶ الگو ──[≥۲ actor و ≥۳ روز]──▶ کهن‌الگو
اپیزود ──┘                                    │
                                              ├─[برون‌زاد<۳۴٪]──▶ ساکت
                                              ├─[شاهدِ خلاف]────▶ ساکت
                                              └─[۳۰ روز بی‌تأیید]▶ محو
```

## اجرا

```powershell
python doctor\cli.py mind      # کهن‌الگوهای رأی‌دار، ساکت‌ها و **دلیلِ سکوتشان**
```

گزارش همیشه `muted_reasons` دارد — یعنی می‌بینی چه چیزی را می‌داند ولی به آن رأی نمی‌دهد.
این مهم‌تر از فهرستِ باورهای فعال است.
