# 🐙 دکترِ اختاپوس

یک والتِ Obsidian که **حافظهٔ دکتر** است، و یک ماژولِ پایتون که با آن **فکر می‌کند**.

مغز: `fugu.py` · چشم: `scanner.py` · انگشت‌ها: `propose.py` · صدا: `channel.py`
حلقه: `daemon.py` · ذهن: `mind.py` (ناخودآگاهِ جمعی) · **مسیریاب: `router.py`**
۶۴ نوت · **۱۴۸/۱۴۸ تست سبز** · stdlib خالص (بدونِ حتی openai SDK)

```
python doctor/cli.py triage                  # آفلاین، بی‌خطر، همیشه کار می‌کند
python doctor/cli.py round   F:\backup\_ops  # چشم ⟶ والت (فقط‌خواندنی)
python doctor/cli.py ask     "چرا قلب ترمز خورده؟"
python doctor/cli.py diagnose
python doctor/cli.py propose "علتِ افتادنِ لِگ را ثبت کن"   # پچِ گیت‌خورده — اعمال نمی‌کند
python doctor/cli.py day     F:\backup\_ops   # یک پاسِ کاملِ حلقه (dry-run)
python doctor/cli.py request "یک پا اضافه کن که رزونانسِ شومان را رصد کند"
python doctor/cli.py mind                      # کهن‌الگوها، سایه، و دلیلِ سکوتِ ساکت‌ها
python doctor/cli.py outbox                    # سلامتِ کانال — بدونِ هیچ رازی
```

سه چیزی که این ماژول **هرگز** نمی‌کند: در `_ops` نمی‌نویسد · پچ اعمال نمی‌کند ·
بدونِ رأیِ صریحِ مالک merge نمی‌کند.

## چرا این‌طور ساخته شده

**۱ — لایهٔ چندایجنتی روی Fugu نساختیم.**
Fugu خودش `TRINITY` است: نقش‌های Thinker/Worker/Verifier را بینِ متخصص‌ها پخش می‌کند و
`Conductor` با RL هماهنگی را کشف کرده. ساختنِ ارکستراتورِ دوم روی آن، دوباره‌کاری است.
کارِ ما فقط ساختِ **Context Bundle** دقیق است. ← [[BRAIN-fugu]]

**۲ — دکتر نباید بیماریِ بیمار را بگیرد.**
قانونِ [[R-01-قانونِ-خودارجاعی]] در پرامپتِ سیستمِ دکتر قفل شده. هر سنجهٔ درون‌زاد
(شمارندهٔ ضربان، تعدادِ کشف، mtime، docstring) حق شهادت ندارد. `ingest` هر سنجهٔ
درون‌زاد یا بی‌رسید را در جدولِ خودِ نوت **flag** می‌کند.

**۳ — fail-closed، هرگز mock.**
بدونِ `SAKANA_API_KEY` دکتر **جواب نمی‌سازد** — می‌گوید چرا نتوانست. سهمیه هم با
شکستِ کلید مصرف نمی‌شود.

**۴ — اسکنِ نو معادله را overwrite نمی‌کند.**
تعارض فقط flag می‌شود. قوانین و معادلات با هیچ ورودیِ بیرونی بازنویسی نمی‌شوند — تست دارد.

**۵ — بازیابیِ ساده و شفاف.**
امتیازِ کلمه‌ای، بدونِ embedding. وقتی والت بزرگ شد، جای وصل‌کردنِ `sqlite-vec` است —
نه زودتر. `[UNKNOWN]` بودنِ کیفیتِ retrieval بدتر از سادگی است.
