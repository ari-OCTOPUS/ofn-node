# EXPERIENCE-LEDGER — حافظهٔ انباشتی چرخهٔ خودبهبودی

> **حلقهٔ بسته:** مشاهده → درس → پیشنهاد → verdict آری → اعمال → سنجش → (دوباره مشاهده).
> این نوت تنها حافظهٔ canonical تجربهٔ کل چرخه است — **append-only**: هیچ ردیفی حذف یا بازنویسی نمی‌شود، فقط ستون «وضعیت» به‌روز می‌شود. ساخته‌شده با دستور مستقیم آری («consistent circle of self improvement»، بامداد 2026-07-05).

## بازوهای چرخه (چه چیزی کجا می‌ریزد)

- **مشاهده/پیشنهاد:** لاین‌های selfimprove (~۱٬۰۰۸ اجرا/روز → دیجست‌ها) · تابلوی تمرکز هر ۳ ساعت (log خودبهبودی) · حلقهٔ بهبود [[00 - Inbox/Prompt - System Dashboard Artifact|پرامپت داشبورد]] · جلسات تعاملی (HANDOFF).
- **انباشت:** درس‌های قابل‌اقدام (kind=regress/suppress/observe مهم) به‌صورت ردیف اینجا append می‌شوند — توسط تسک `brain-focus-board` یا جلسهٔ تعاملی.
- **verdict:** تسک هفتگی `experience-review` (یکشنبه ۲۱:۳۰) خلاصهٔ pending-verdictها را با notification برای آری می‌فرستد؛ آری وضعیت را به applied/rejected می‌برد (یا در چت verdict می‌دهد).
- **اعمال:** فقط در جلسهٔ تعاملی، طبق autonomy همان حوزه (تغییر اسکریپت/پرامپت canonical = verdict).
- **سنجش:** بخش «چرخهٔ خودبهبودی» تابلو (شمار درس‌ها به تفکیک وضعیت + روند سلامت). قاعدهٔ سنجش: اثر چرخه را از گیت‌های انسانی (rotation) جدا بسنج.
