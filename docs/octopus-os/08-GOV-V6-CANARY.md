```text
GOV_V6_BEHAVIOR = ASSERTED_NOT_PROVEN
```

واحدهای `tests/test_gov_v6_gate.py` سناریوها را در سطح کد قفل کرده‌اند و شواهد

هنوز ثبت نشده است. تا آن آزمون، این سند می‌گوید «ادعا شده»، نه «اثبات شده».

## آیین (بعد از merge شدن بستهٔ حاکمیتی)

۱. یک PR کاناری باز کن با تغییر بی‌اثر در `ofn/agents/` (مثلاً یک کامنت
   تک‌خطی در یک docstring). نویسنده نباید aram-ui یا Elahe-z باشد.
۲. این سه مشاهده را با timestamp ثبت کن:
```text
بدون هیچ رأی          → require-independent-approval باید قرمز بماند
رأی نویسنده (خود-تأیید) → باید قرمز بماند
رأی aram-ui یا Elahe-z  → باید سبز شود (یکی به‌تنهایی کافی)
```
۳. هر مشاهده با شمارهٔ PR + sha چک + timestamp در همین سند ضمیمه شود.
۴. وقتی هر سه ثبت شد، خط وضعیت را به
   `GOV_V6_BEHAVIOR = PROVEN (receipts: <سه لینک>)`
   ارتقا بده — تستِ قفل‌کنندهٔ این سند (`tests/test_gov_v6_canary.py`)
   تنها همین دو املا را می‌پذیرد، پس جعل وضعیت قرمز می‌شود.

## یادداشت

- رأی رباتِ تنها دیگر قابل تولید مستقیم نیست (فیلتر [bot] روی main)، بنابراین
  «رأی ربات تنها قرمز بماند» را همان شواهد تاریخی #102 + تست واحد پوشش می‌دهد.
- کاناری فقط وقتی معنا دارد که PR مسیر حساس را لمس کند؛ PR فقط-docs به مسیر
  not-applicable (#118) می‌رود و هیچ‌چیز دربارهٔ رأی اثبات نمی‌کند.
