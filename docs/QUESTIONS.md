# سؤال‌ها برای پرورش دستیار
- UI: تم تاریک/روشن، رنگ‌ها، لحن، صدا یا فقط متن؟
- اهداف: آرام‌سازی، خواب، تمرکز، درد، عادت، اعتمادبه‌نفس، یادگیری؟
- محدودیت‌ها: چه کلمات/تصاویر/تکنیک‌هایی را نمی‌خواهی؟
- جلسه‌ها: ۲، ۵، ۱۰ یا ۱۵ دقیقه؟
- منابع: مقاله، پروتکل، خلاصه، معادله، تعریف متغیرها، دامنه معتبر و مثال عددی را بفرست.
- دیپلوی: بات/دامنه/Cloudflare route جدا می‌خواهی؟
