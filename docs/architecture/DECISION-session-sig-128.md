# DecisionRecord — امضای session ۱۲۸ بیتی

**یافته ۱۸ (debt) · تاریخ: ۲۰۲۶-۰۸-۱۰**

## وضعیت
`ofn/kernel/auth.py` امضای session را با `hmac-sha256(...).hexdigest()[:32]`
می‌سازد — یعنی ۳۲ hex = **۱۲۸ بیت** از ۲۵۶ بیت کامل.

## چرا کافی است
- HMAC-SHA256 با کلید ۱۲۸ بیتی: brute-force از نظر عملی غیرممکن است
  (۲^۱۲۸ ترکیب). هیچ کلاس حملهٔ شناخته‌شده‌ای روی ۱۲۸ بیت اول HMAC-SHA256
  وجود ندارد که truncation را ضعیف‌تر از full digest کند.
- session ها کوتاه‌عمرند (ttl_s محدود) — پنجرهٔ حمله حتی کوچک‌تر.
- token ها در URL/هدر منتقل می‌شوند؛ کوتاه‌تر بودن = payload کوچک‌تر.

## حکم
**۱۲۸ بیت باقی می‌ماند** و به‌عنوان تصمیم صریح مستند می‌شود. تغییر به
full digest ممکن است ولی سودی ندارد — و هر تغییری session های موجود را
بی‌اعتبار می‌کند (نیاز به re-login همه).
