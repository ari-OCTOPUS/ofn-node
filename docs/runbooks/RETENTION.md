# Runbook — رشد داده و retention

**وقتی:** دیسک برد کم می‌آید، یا پنل مالک رشد inbox/outbox/ledger نشان می‌دهد.

## معنی
- inbox/outbox/ledger جداول append-only هستند. روی برد ۴GB رشدشان محدود
  نشده (یافته ۳۵).
- **ledger هرگز پاک نمی‌شود** — زنجیرهٔ هش تاریخچه است و حذفش معادل
  بازنویسی تاریخ است. آرشیو، نه حذف.

## اندازه‌گیری
```bash
df -h /home/ari/.local/share/ofn
du -sh /home/ari/.local/share/ofn/*.sqlite
```

## سیاست پیشنهادی (با حکم آری)
- inbox: آیتم‌های `processed` قدیمی‌تر از N روز → جدول `inbox_archive` + checksum.
- outbox: آیتم‌های `sent` قدیمی‌تر از N روز → جدول `outbox_archive`.
- ledger: هرگز حذف نمی‌شود؛ اگر لازم شد، DB کامل آرشیو و فشرده می‌شود
  (در جای دیگر، نه در state_dir).

## بدون حکم چه کنم
- فقط اندازه بگیر و گزارش بده. حذف/آرشیو داده = تصمیم آری.

## هشدار
- هرگز فایل `-wal`/`-shm` را دستی پاک نکن.
- آرشیو یعنی COPY + حذف از جدول اصلی — نه فقط حذف.
