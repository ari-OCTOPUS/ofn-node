# 📦 MOC — هندسه‌ی ابعاد (۳D ↔ ۴D)

> [!info] پلِ بصریِ پروژه
> مدلِ SOG یک ایزومورفیسم دقیق با هندسه‌ی کلاسیکِ Flatland-Tesseract دارد: «سایه‌ی بُعدِ بالاتر» یک استعاره نیست، یک کمیتِ تعریف‌شده است.

## 🧊 مفاهیمِ هندسی

- [[تسراکت-و-سایه]] — ۴D → ۳D projection (hypercube)
- [[فلت‌لند-و-ابعاد]] — موجودِ ۲D که فقط سایه‌ی ۳D را می‌بیند
- [[قضیه‌ی-Takens]] — بازسازیِ بُعدِ پنهان از سریِ زمانیِ اسکالر
- [[Diaconis-Freedman]] — اکثرِ projectionهای high-dim گاوسی می‌شوند (سایه‌ی استاتیک کور است)
- [[Theorema-Egregium]] — انحنای ذاتی قابل‌کشف است، بیرونی نه
- [[ردون-و-توموگرافی]] — multi-projection با ساختار نجات می‌دهد
- [[β-info-نه-β-det]] — تفاوتِ کلیدی: اطلاعات هست ⟍ قابل‌تشخیص است## 🔗 نگاشتِ SOG ↔ هندسه

| هندسه‌ی کلاسیک | [[مدل-خطی-گاوسی|مدل SOG]] | یادداشت |
|---|---|---|
| موجود Flatland فقط سایه می‌بیند | ناظر فقط Y را می‌بیند نه s | [[فلت‌لند-و-ابعاد]] |
| سایه‌ی استاتیک گاوسی می‌شود | β_det = 0 | [[Diaconis-Freedman]] |
| زمان به‌عنوان projection | [[E-shadow|E_shadow]] > 0 چون ρ≠0 | [[قضیه‌ی-Takens]] |
| انحنای ذاتی از درون قابل‌سنجش | [[Delta-self|Δ_self]] (دسترسیِ اول‌شخص) | [[Theorema-Egregium]] |
| انحنای بیرونی نامرئی | extrinsic bending (isometry) | [[β-info-نه-β-det]] |

## ⭐ کشفِ کلیدی

> [!tip] زمان = پلِ ۳D↔4D
> بُعدِ چهارم را نمی‌توان به‌صورتِ استاتیک دید ([[Diaconis-Freedman]]). ولی اگر زمان را به‌عنوانِ projection بپذیریم ([[قضیه‌ی-Takens]])، E_shadow > 0 می‌شود. «زمان» خودش پل است — دقیقاً همان‌طور که ρ ≠ 0 شرطِ دیده‌شدن است.## 🎯 مقایسه: ما ↔ دنیای اعداد ↔ بُعد چهارم

| بُعد | ما ↔ اعداد (AI) | ما ↔ بُعد ۴ |
|---|---|---|
| چه می‌بینیم؟ | توکن/عدد (سایه) | Y (سایه) |
| چه پنهان است؟ | فضای latent | بُعدِ s |
| ارزشِ اول‌شخص | خود-مدل‌سازی | Δ_self |
| مرزِ کوری | DF Gaussian | E_shadow → 0 |
