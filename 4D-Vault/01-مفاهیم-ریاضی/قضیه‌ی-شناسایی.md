# [[قضیه‌ی-شناسایی|قضیه‌ی شناسایی]]

> [!info] مرزِ واقعیِ دیده‌شدن
> برای دیده‌شدنِ یک بُعدِ پنهان، هم **نشت** لازم است هم **حافظه**.

## قضیه

$$\boxed{E_{\text{shadow}} > 0 \iff \lambda \cdot \rho \neq 0}$$

## دو حالتِ «هست ولی نامرئی»

> [!example] β_info ≠ β_det را عینی می‌کند
>
> **ρ = 0 (بی‌حافظه):**
> بُعدِ پنهان لحظه‌ای است و ردِ زمانی نمی‌گذارد.
> ⟹ [[E-shadow|E_shadow]] = 0.000000
> سایه هست، ولی **iid** دیده می‌شود.
>
> **λ = 0 (بدونِ نشت):**
> بُعدِ پنهان اصلاً به سایه وصل نیست.
> ⟹ E_shadow = 0.000000
> کانالِ ارتباطی **بسته** است.

در هر دو حالت، بُعدِ پنهان **واقعاً وجود دارد** ولی هیچ سایه‌ی قابل‌تشخیصی نمی‌اندازد.

→ [[β-info-نه-β-det]]: اطلاعات هست (β_info > 0) ولی قابل‌تشخیص نیست (β_det = 0).## اثبات

$$E_{\text{shadow}} = \frac{1}{2}\log\!\left(\frac{\sigma_z^2}{S_b}\right)$$

- λ=0 ⟹ σ_z² = σ_ε² = S_b ⟹ E_shadow = 0
- ρ=0 ⟹ z_t مستقل از z_{<t} ⟹ σ_z² = S_b ⟹ E_shadow = 0
- λρ≠0 ⟹ σ_z² > S_b (ساختارِ زمانی وجود دارد) ⟹ E_shadow > 0
