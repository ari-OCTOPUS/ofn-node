# ردون و توموگرافی

> [!info] چند projection با ساختار نجات می‌دهد
> یک سایه کور است ([[Diaconis-Freedman]])، ولی **چند projection از زوایای مختلف** می‌تواند ساختار را بازسازی کند.

## قضیه‌ی Cauchy

میانگینِ حجمِ سایه ∝ surface measure:
$$\overline{V}_{\text{shadow}} \propto \text{Surface measure}$$

## قضیه‌ی Alexandrov

اجسامِ **متقارنِ مرکزی** از brightness function هایشان یکتا قابل بازسازی هستند.

> [!caution] محدودیت
> برای اجسامِ عمومی (غیرِ متقارن)، عدمِ‌یکتایی اثبات‌شده است.
> → Gardner, *Geometric Tomography*## جدولِ identifiability

| functional | شرطِ identifiability | معادلِ β_det |
|---|---|---|
| حجمِ سایه (Cauchy) | متقارنِ مرکزی | > 0 |
| brightness function | متقارنِ مرکزی | > 0 |
| اجسامِ عمومی | عدم‌یکتایی | = 0 |
| multi-angle (tomography) | کافی، ساختاردار | > 0 |

## پل به مدل

> [!abstract]+
> اگر چند projection از زوایای مختلف داشته باشی (مثلِ tomography پزشکی)، می‌توانی ساختارِ سه‌بعدی را بازسازی کنی.
> ولی اگر فقط یک projection داری، [[Diaconis-Freedman]] می‌گوید کور است.
