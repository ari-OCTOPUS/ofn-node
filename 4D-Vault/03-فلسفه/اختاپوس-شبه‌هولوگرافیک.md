# 🐙 اختاپوسِ شبه‌هولوگرافیک

> [!info] استعاره‌ی مرکزیِ مدل
> یک سیستم که از یک قلبِ مرکزی شاخک می‌اندازد، هر شاخک یک کانال است، و همه‌چیز به همه وصل است — ولی با نشت.

## چرا «شبه» هولوگرافیک؟

> [!caution]
> هولوگرافیِ واقعی یعنی رابطه‌ی **تقریباً lossless** و بازیافت‌پذیر.
> ولی مدلِ ما نویز، نشت و کانالِ **lossy** دارد.
>
> پس عنوانِ دقیق‌تر: **Leaky Holographic Octopus**.## اجزا

| جزء | نماد | معنا |
|---|---|---|
| قلبِ مرکزی | H | حالتِ پنهان / منبع |
| شاخک‌ها | کانال‌ها | عملگرهای اثرگذاری |
| حلقه‌ها | قیود | invarianceها، regularization |
| نقاطِ انتهایی | متریک‌ها | مشاهدات |
| شاخک‌های نقطه‌چین | lossy | کانال‌های تلفاتی |
| ستاره | هدف | loss function |
| نویز | ξ | تخریبِ اطلاعات |
| خودارجاعی | حلقه‌های بازخورد | عامل رویِ خودش |

## معادله‌ی well-posed

$$d\Psi_t = -L_G \Psi_t\,dt + B(\Psi_t)\,dW_t + U_t\,dt$$

| نماد | معنا |
|---|---|
| Ψ_t | حالتِ کلِ سیستم |
| L_G | لاپلاسینِ گرافِ اختاپوس (انتشار روی شبکه) |
| B(Ψ_t)dW_t | نویزِ تصادفی / نشتِ اطلاعات |
| U_t | مداخله، هدف، یا ورودیِ بیرونی |

## تفسیر

> [!abstract]+
> سیستم روی گرافِ خودش پخش و هموار می‌شود، نویز اطلاعات را تخریب می‌کند، و مداخله می‌تواند مسیر را عوض کند.## منبع
