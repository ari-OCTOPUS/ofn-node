# 📐 مدلِ خطی-گاوسیِ SOG

> [!info] قلبِ کمیِ پروژه
> دنیای پنهان یک حالتِ انباشتی دارد که با خودش هم‌بسته است و نویز می‌گیرد؛ ما فقط یک تصویرِ نوفه‌دار از آن می‌بینیم.

## معادلات

$$s_{t+1} = \rho \cdot s_t + m_t + \zeta_t, \quad \zeta \sim \mathcal{N}(0, \sigma_\zeta^2)$$
$$Y_t = b_t + \lambda \cdot s_t + \varepsilon_t, \quad \varepsilon \sim \mathcal{N}(0, \sigma_\varepsilon^2)$$## نمادها

| نماد | معنا | نقش |
|---|---|---|
| s | حالتِ پنهان | **بُعدِ پنهان** (با حافظه ρ) |
| Y | مشاهدات | **سایه‌ای که می‌بینیم** |
| ρ | پایداریِ AR | حافظه |
| λ | شدتِ نشت | چقدر بُعد لو می‌رود |
| m | ورودیِ کنترل | سیاست |
| b | بایاس | متغیرِ هر episode |
| ε | نوفه‌ی مشاهده | کدورتِ پرده |
| ζ | نوفه‌ی فرآیند | تصادفی‌بودنِ بُعد |
| **σ_d** | **دیترِ خصوصی** | **آنچه «خود» را از «دیگری» جدا می‌کند** |

## نقش م (دوتر)

m_t شامل دیترِ خصوصی d_t است. این همان **درجه‌ی آزادیِ خصوصی** است که [[Delta-self]] را می‌سازد.## گام‌های تحلیلی

۱. حلِ [[DARE-معادله‌ی-ریکاتی]] ⟹ P، سپس [[کف-کالمن]] ⟹ S
۲. بازوی blind: همان DARE با σ_ζ'² = σ_ζ² + σ_d² ⟹ S_b
۳. [[Delta-self]] = ½log(S_b/S)
۴. σ_z² = λ²(σ_ζ²+σ_d²)/(1−ρ²) + σ_ε²
۵. [[E-shadow]] = ½log(σ_z²/S_b)
۶. [[اتحاد-chain-rule]] جمع می‌بندد
