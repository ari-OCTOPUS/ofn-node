# 🎛️ داده‌ی مصنوعی

> [!info] داده‌های کنترل‌شده با ساختارِ شناخته‌شده
> برایِ اعتبارسنجیِ pipeline قبل از داده‌ی واقعی.

## کاتالوگ

| نام | توضیح | انتظار |
|---|---|---|
| Gaussian iid | نویز خالص ([[null model]]) | [[E-shadow|E_shadow]]≈0 |
| AR(1) ρ=0.7 | حافظه قوی | E_shadow>0 |
| AR(1)+noise | نزدیک‌ترین به [[مدل-خطی-گاوسی]] | E_shadow>0 |
| ARMA(1,1) | ساختارِ دقیقِ سایه‌ی SOG | E_shadow>0 |
| Mixture Gaussian | غیرگوسی — تست کاذب | weak |
| Logistic map | آشوبِ قطعی | non-linear |
