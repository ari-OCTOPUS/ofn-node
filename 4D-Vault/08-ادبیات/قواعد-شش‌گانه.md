# 📋 قواعد شش‌گانه‌ی پروژه

> [!info] قوانینِ سختِ پروژه (از handoff پیوست C)
> این قواعد برای همه‌ی workerها و تمامِ تحلیل‌ها نافذ‌اند.## قواعد

۱) **null model الزامی**
 هیچ یافته‌ای بدونِ null model؛ Δ_MDL>Δ و β_det>0 لازم است نه فقط β_info>0.

۲) **هر عدد بازتولیدپذیر**
 هر عددِ کمّی مشتق‌شده و مستقلاً بازتولیدپذیر؛ عددِ بی‌اشتقاق رد.

۳) **web-search پیش از novelty**
 پیش از هر ادعای novelty، جست‌وجوی وب اجباری؛ اول نقشه‌ی ادبیات ledger چک شود.

۴) **instrument ≠ hypothesis**
 instrument-validation با hypothesis-claim قاطی نشود.

۵) **مسیرهای ردشده ثبت**
 مسیرهای رقیبِ ردشده صریح ثبت شوند.

۶) **فلسفه فقط narrative**
 فریمِ فلسفی فقط narrative است؛ ادعای فنی فقط روی SOG/MDL/excess-loss.
